# Канонические скрипты сборки документов (`scripts/`)

В этом каталоге содержатся готовые, проверенные и стандартизированные исполняемые скрипты для сборки научно-технических отчетов по ГОСТ 7.32 и стандарту кафедры АТП.

---

## Состав каталога

1. **[`build_report_docx.py`](build_report_docx.py)** — сквозной 11-стадийный конвейер сборки документа Word (`.docx`) и PDF (`.pdf`) из академического Markdown (`.md`):
   - Очистка веб-тегов, преобразование формул и изображений.
   - Трансляция в OOXML через Pandoc AST.
   - Формирование титульного листа кафедры АТП (14 pt regular, «Москва, 2026»).
   - Принудительная настройка формата листа A4 (210 × 297 мм) и полей 30/15/20/20 мм для всех секций.
   - Динамическое оглавление `TOC \o "1-2" \h \z \u` без разрыва страницы.
   - Стилизация глав Heading 1 (с мягким переносом `<w:br/>`), подразделов Heading 2/3.
   - Раскладка формул по центру полосы (4677 twips) с номерами у правого края (9354 twips).
   - Таблицы: строго 14 pt Times New Roman, двухосевое центрирование, `tblHeader`, `cantSplit`.
   - Масштабирование рисунков (165 × 155 мм) со свойством `keep_with_next`.
   - Замена длинных тире на средние (` – `), очистка формул от паразитной жирности.
   - Финализация в Word COM: сброс красной строки оглавления `FirstLineIndent = 0` у `wdStyleTOC1` (-20) и `wdStyleTOC2` (-21).
   - Экспорт в PDF высшего полиграфического качества.

2. **[`export_report_pdf.py`](export_report_pdf.py)** — автономная утилита экспорта готового Word (`.docx`) в PDF (`.pdf`) через MS Word COM API:
   - Изоляция во временном ASCII-каталоге Windows (исключает зависание на кириллических путях).
   - Обновление динамических полей и оглавления (`doc.Fields.Update()`, `doc.TablesOfContents(1).Update()`).
   - Экспорт через `ExportAsFixedFormat` (`wdExportFormatPDF = 17`).

## Быстрый запуск из терминала

### Сборка отчета (DOCX + PDF)
```bash
python scripts/build_report_docx.py --input Отчет.md
```

С расширенными параметрами титульного листа:
```bash
python scripts/build_report_docx.py \
  --input "Отчет_ДЗ3.md" \
  --output-docx "Отчет_ДЗ3.docx" \
  --output-pdf "Отчет_ДЗ3.pdf" \
  --work-type "по домашнему заданию № 3" \
  --discipline "«Оптимизация и оптимальное управление»" \
  --theme "Идентификация и оптимизация параметров технологического процесса" \
  --group "студент группы АТ-23-01" \
  --author "Гимранов Э. А." \
  --supervisor-role "профессор кафедры АТП" \
  --supervisor-name "Тараканов Д. В."
```

### Экспорт готового Word в PDF
```bash
python scripts/export_report_pdf.py --input "Отчет_ДЗ3.docx" --output "Отчет_ДЗ3.pdf"
```

## Использование как модуля в Python

```python
from scripts.build_report_docx import build_report

build_report(
    input_md="Отчет.md",
    output_docx="Отчет.docx",
    output_pdf="Отчет.pdf",
    theme="Идентификация параметров модели",
)
```
