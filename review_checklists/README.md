# Каталог универсальных чек-листов для код-ревью

В этой папке собраны модульные инженерные критерии («кубики») для детальной проверки исходного кода на C++ и Python. Они подключаются через основной модуль [`../code_review.md`](../code_review.md).

## Принцип гибкой комплектации проверки

Проверка собирается из кубиков по мере необходимости:
- Если проверяется архитектура классов — подключаются `structs.md` и `rule_of_7.md`.
- Если проверяется надежность и качество — подключаются `tests.md`, `dry.md`, `calcs.md`.
- Если проверяется оформление — подключаются `naming.md`, `comments.md`, `namespace.md`.

## Универсальные кубики инженерного качества

| Файл кубика | Проверяемый аспект | Ключевые требования |
|---|---|---|
| [`naming.md`](naming.md) | **Именование сущностей** | `snake_case` для функций и переменных, суффикс `_t` для C++ типов, отсутствие транслита, CamelCase только для Google Test. |
| [`comments.md`](comments.md) | **Документирование и комментарии** | Doxygen (`///`, `@brief`) в `.h` для C++, docstring `"""` для Python, комментарии только по неочевидной логике, формулы вместо абстрактных ссылок, размерности величин. |
| [`structs.md`](structs.md) | **Структуры данных и инкапсуляция** | Инициализация полей `NaN` (Fail Fast), designated initializers (C++20) / `kw_only` (Python), производные величины через const-методы/@property, бессистемные вычисления свободными функциями, статические фабрики. |
| [`namespace.md`](namespace.md) | **Пространства имен и модули** | Запрет `using namespace std;`, точка с запятой `;` после открывающей скобки `{` пространства имен, логическая изоляция подсистем. |
| [`calcs.md`](calcs.md) | **Физико-математические константы** | Использование `M_PI`, единая именованная константа ускорения свободного падения $g$, устранение магических чисел. |
| [`tests.md`](tests.md) | **Структура и культура тестов** | Паттерн AAA (Arrange / Act / Assert), запрет оборачивания `TEST` в `namespace`, вынос повторяющихся тестовых данных, обязательный тест эталонного расчета (Golden Master). |
| [`dry.md`](dry.md) | **Принцип Don't Repeat Yourself** | Вынос повторяющихся вычислений и валидаций в хелперы, переиспользование базовых классов через `super()`. |
| [`duplicates_occams_razor.md`](duplicates_occams_razor.md) | **Бритва Оккама и устранение дублей** | Осознанное разделение вариативных AAA-матриц сценариев и реального неоправданного дублирования логики. |
| [`rule_of_7.md`](rule_of_7.md) | **Когнитивная сложность ($7 \pm 2$)** | Метрики сложности классов (A/B/C), ограничение количества полей и методов (не более 7), декомпозиция крупных сущностей. |
| [`restrict_binary.md`](restrict_binary.md) | **Чистота репозитория** | В git коммитятся только исходники и текст, запрет сборных бинарников, исполняемых файлов и артефактов IDE. |
