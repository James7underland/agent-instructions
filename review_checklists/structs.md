# Чек-лист: Структуры данных и инкапсуляция

> Этот документ определяет универсальные критерии проверки организации структур данных (`struct`/`class`). Применяется при код-ревью и проектировании на C++ и Python.

---

## 1. Обязательные требования

1. **Запрет позиционной агрегатной инициализации (C++):**
   - Запрещена инициализация по порядку полей вида `point_t{10.0, 20.0, 0.5}`.
   - Обязательно использовать поэлементное присваивание или обозначенные инициализаторы (designated initializers, C++20):
     ```cpp
     point_t p{.x = 10.0, .y = 20.0, .z = 0.5};
     ```
   - *Для Python:* использование `kw_only=True` в `@dataclass`.

2. **Инициализация невалидными значениями (Fail Fast):**
   - Все численные поля с плавающей точкой по умолчанию инициализируются `NaN`:
     * C++: `std::numeric_limits<double>::quiet_NaN()`
     * Python: `math.nan`
   - Запрещено использовать нули или правдоподобные числа по умолчанию, маскирующие забытую инициализацию.

3. **Производные величины — через методы / свойства:**
   - Параметры, однозначно вычисляемые из основных полей структуры (площадь сечения через диаметр, относительная шероховатость, динамическая вязкость через кинематическую и плотность), **не должны храниться как отдельные поля**.
   - Они оформляются как:
     * C++: константные методы `double get_cross_section_area() const;`
     * Python: свойства с декоратором `@property def cross_section_area(self) -> float:`.
   - *Обоснование:* исключает рассинхронизацию данных при изменении базовых полей.

4. **Вспомогательные бессистемные расчеты — свободными функциями:**
   - Вычисления и формулы, не зависящие от внутреннего состояния конкретного объекта, выносятся в свободные функции модуля или пространства имен, а не «зашиваются» методами в структуру.

5. **Статические фабрики для типовых наборов данных:**
   - Для структур с типовыми или учебными наборами параметров реализуются статические фабричные методы (`standard_pipe()`, `default_water()`), чтобы исключить повторяющиеся простыни инициализации в тестах.

6. **Разделение структур данных и классов-решателей:**
   - Пассивные структуры параметров отделяются от вычислительных классов-солверов, инкапсулирующих алгоритм и хранящих результат.
