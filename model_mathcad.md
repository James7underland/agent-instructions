# Инженерные расчеты в Mathcad 13 (`model_mathcad.md`)

> Модуль прикладного слоя для автоматизации инженерных расчетов, генерации расчетных листов `.xmcd`, взаимодействия через COM-интерфейс и выпуска отчетов в MS Word по ГОСТ.
> Путеводитель по библиотеке — [`README.md`](README.md).
> Полная рабочая реализация и инструментарий скилла — [`skills/mathcad13/SKILL.md`](skills/mathcad13/SKILL.md).

> 🛑 **ЭКСПРЕСС-ИНВАРИАНТЫ MATHCAD 13 (GUARDRAILS TOP-5 ДЛЯ НЕЙРОСЕТИ):**
> 1. **Валидный XML схемы Math20:** Листы `.xmcd` формируются со строгим соблюдением структуры пространств имен Mathcad XML и расчетом геометрии регионов (`scripts/xmcd.py`) без взаимных наложений.
> 2. **32-битный COM-интерфейс (`mc.ps1`):** Запуск и управление процессом `Mathcad.Application` выполняются исключительно через 32-битный PowerShell (`SysWOW64\powershell.exe`).
> 3. **Контроль физических размерностей:** Все переменные сопровождаются согласованными единицами измерения (с, м, Па, рад/с, кг); не допускать скрытых размерностных невязок.
> 4. **Инженерная графика с сеткой (`mcplot.py`):** Графики характеристик строятся с обязательной координатной сеткой, физическими размерностями на осях и контрастной палитрой.
> 5. **Экспорт отчетов по ГОСТ (`report.py`):** Выгрузка расчетов в MS Word (`.docx`) выполняется с соблюдением ГОСТ 7.32 (шрифт Times New Roman 14 пт, формулы OMML/PNG, поля 30-20-10-20 мм).

---

## 1. Назначение и сфера применения

Модуль подключается при решении задач:
- Создание расчетных листов Mathcad 13 (`.xmcd`) с нуля по текстовой постановке задачи;
- Чтение, синтаксический разбор и валидация существующих файлов `.xmcd`, `.mcd`, `.xmct`;
- Прямое манипулирование XML-схемой Math20 (`scripts/xmcd.py`) без обязательного наличия запущенной среды;
- Автоматический пересчет формул, выгрузка числовых значений переменных и отслеживание кодов ошибок через 32-битный COM-интерфейс `Mathcad.Application` (`scripts/mc.ps1`);
- Построение инженерных графиков с координатной сеткой и настраиваемым оформлением (`scripts/mcplot.py`, `scripts/mcsheet.py`, `scripts/mcfig.py`);
- Экспорт расчетных листов в документы MS Word (`.docx`) с полями и оформлением по ГОСТ (`scripts/report.py`).

## 3. Регламент безопасной работы

1. **Неприкосновенность системных каталогов:**
   - Запрещено выполнять запись в каталог установки Mathcad (`Program Files (x86)\Mathsoft\Mathcad 13`). Примеры и шаблоны копируются в локальную рабочую директорию.
2. **Резервирование данных пользователя:**
   - Перед любой модификацией исходного файла создается резервная копия вида `имя.bak-ГГГГММДД-ЧЧММСС.xmcd`.
   - Результат сохраняется в новый файл (`_calc.xmcd`), перезапись оригинала допустима только по прямому указанию.
3. **Безопасное управление процессами:**
   - Завершению подлежат исключительно процессы `mathcad.exe -Embedding`, инициализированные автоматизацией. Сессии GUI пользователя не прерываются.
4. **Обязательная верификация пересчетом:**
   - Любой сгенерированный или измененный лист `.xmcd` подлежит обязательному тестовому пересчету через `mc.ps1` с проверкой счетчика ошибок (`error_count == 0`).
