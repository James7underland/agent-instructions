# Файлы данных ТАУ-3

Все текстовые файлы — **cp1251**, строки CRLF. Программа ищет файлы сначала в `C:\TAY_3\`, затем в своём
каталоге (так задумано для запуска с CD). **Если `C:\TAY_3` существует — программы будут читать/писать туда!**
Сейчас его нет; не создавать.

| Файл | Кто пишет/читает | Суть |
|---|---|---|
| `<PROG>.VRT` | каждая программа | «вариант»: исходные данные (иногда и результаты). Читается при старте, если на вопрос «Использовать данные предыдущего счета?» ответить Да; перезаписывается **сразу после ввода** (не только при выходе) |
| `<PROG>.tab` | меню окна «В файл / на принтер» → «в файл» | текстовый отчёт таблицы/формулы (перезаписать/дописать). `tau.py tofile` |
| `pageNN.bmp` | клавиши F5 (экран) / F6 (активное окно) / F7 (график) | снимки; нумерация сквозная 01..99 для всех программ |
| `PROGRAM.LST` | Tay_3.exe | список программ диспетчера: имя до первого пробела + комментарий |
| `GALERY.LST`, `PORTRAIT\*.BMP` | Galery.exe | `#N`, имя файла, ФИО, годы, текст |
| `PRONI.DAT` | Proni.exe | пары `t R(t)`, t≥0 возрастают; пишется пунктом «Записать в файл» |
| `AMPLPH.DAT` | Identf.exe (по АФХ) | `ω Re Im`, 10..50 строк |
| `TRANSF.DAT` | Identf.exe (по переходной) | `t h(t)`, 10..50 строк |
| `LOGAM.DAT` | Identf.exe (по ЛАЧХ) | `ω 20lg|W| arg W`, 10..50 строк |
| `PHASPL.LSW` | Phaspl.exe | точки линии переключения `x1 x2` (квазиоптимальное управление) |

`scripts/vrt.py show|roundtrip` распознаёт формат автоматически; все 22 штатных VRT проходят round-trip.

## 1. «Многочлены» (poly): LINSYS, ANACON, OPTIM, IDENTF, RTLZ
Последовательность блоков-многочленов, затем «хвост» программы:
```
    2                                                       ← порядок n (I5)
 3.60000000000000E+0000                                     ← a0 (старший коэффициент)
 2.00000000000000E+0000 -2.77777777777778E-0001 -4.47903208238808E-0001   ← a1  Re(r1) Im(r1)
 1.00000000000000E+0000 -2.77777777777778E-0001  4.47903208238808E-0001   ← a2  Re(r2) Im(r2)
```
Числа — Delphi `%.14E` с 4-значной экспонентой, разделитель — пробел (у положительных ещё ведущий пробел).
Коэффициенты по убыванию степеней; корни — вещественные, затем сопряжённые пары (сначала −Im).
- **LINSYS**: 4 блока: знаменатель W, числитель W, знаменатель R, числитель R. Штатно W=1.8/(3.6p²+2p+1), R=1.
- **ANACON**: блок знаменателя объекта (числитель ≡1), затем строки `p`, `q1..qn` (`1.0000`).
- **OPTIM**: блок знаменателя, строки `M` и `X°1..n`, затем строки звена регулятора в формате «звеньев» (`*R22 …`).
- **RTLZ**: несколько блоков (знаменатель/числитель для задач Лапласа и Z).
- **IDENTF**: блоки знаменатель/числитель + строка `K0 t D1 D2` (4 числа E-формата), повторяется для задач.
`vrt.py poly OUT --den "…" --num "…"` строит блоки (корни считает сам). Нужно ли программе точное совпадение корней
с коэффициентами — см. known-issues (проверено для LINSYS).

## 2. «Звенья» (elem): CONTROL, CASCAD, IMPULS, LINSYS2, LINSYS3, MVACS2, NLINSYS, PHASPL, SPECTR, ASYMPT
Одна строка = одно звено определённого типа (программа хранит по одному варианту на каждый тип):
```
колонка 0      : '*' — этот тип выбран для звена (вариант выбран), ' ' — запомненный, но не выбранный
[1 : 1+NW]     : имя звена (W, R, G, H, N, f, g, v, z, T, D, P, S\_1, W\_11 …; «\_» = нижний индекс)
[1+NW : 3+NW]  : номер типа звена в библиотеке окна «Элемент схемы» (2 символа, выравнивание вправо)
далее          : параметры, поля по 8 символов (пустое поле = 0; допустимы буквы A, B, C, D — задаются позже)
```
Ширина имени NW: 1 — CONTROL, IMPULS, LINSYS2, LINSYS3, NLINSYS, PHASPL; 2 — SPECTR; 4 — CASCAD, ASYMPT; 5 — MVACS2.
Порядок параметров = порядок строк в окне «Параметры» для этого типа (см. references/elements/ — каталог
библиотек звеньев, снятый с экрана). Пример CONTROL: `*R 21.008   0.6563` — регулятор R типа 2 с параметрами
(1.008, 0.6563); `*T 10.355` в IMPULS — период квантования 0.355.
`vrt.py set-elem CONTROL.vrt R 2 1.5 0.7` — выбрать тип и параметры звена (остальные типы этого звена снимаются с «*»).

## 3. «Отчёт» (report): ANACON2, ANACON3, KALMAN, OPTIM2
Человекочитаемый текст «ДАННЫЕ И РЕЗУЛЬТАТЫ СЧЕТА» с размерами задачи и матрицами A, B, Q, P, … (и результатами).
Эти программы **читают** данные из этого текста (справка: «файл vrt предназначен для чтения»). Правка — сохраняя
разметку строк («Матрица A», числа через пробелы). KALMAN пишет файл только по пункту «Запомнить вариант».

## 4. Прочие (table)
- **QPOL.VRT**: первая строка — порядки 6 многочленов B0..B5 (A и B1..B5), далее строки коэффициентов (F12.6),
  по строке на каждую степень (с учётом запаздываний t1..t5 — см. справку «Таблица коэфф. квазиполинома»).
- **MULPOL.VRT**: порядки многочленов A и B (−1 = не заданы).
- **WATT.VRT**: столбец значений параметров модели Уатта (порядок — как в окне «Задание параметров»).
