# Проверка возможностей ТАУ-3 (2026-09-24/25)

## 1. Обход всех программ (crawl.py, 2 прохода)
23 программы с меню × все пункты главного меню (≈170 вызовов) + вручную TAY_3 и GALERY. **Ни одного падения.**
Снимки: `examples/sheets/<prog>.png`, отчёты: `Работа\crawl\<prog>\report.json`, сводка: `ui-map.md`.
Во 2-м проходе буквенные параметры = 1, X° = 1, tрег = 10 → графики содержательные.

MVACS2, ASYMPT — только «строится/без ошибок». Для них check.py даёт инструменты (closed, freq, routh, lqrm, ztf).

## 3. Способы ввода — проверены
- таблицы ПФ (LINSYS: порядок + коэффициенты + OK), MULPOL (одна сетка);
- формы «Значения»/«Xo»/«tрег»/«Число точек» (`fill`);
- радиогруппы (`radio`), списки (`select` в диспетчере), кнопки, всплывающие меню всех окон;
- щелчки по схеме (буквы звеньев) → окно «Элемент схемы», перебор библиотеки;
- вывод: `tofile` (формулы, таблицы корней), снимки окон, VRT «Данные и результаты» (ANACON2).
