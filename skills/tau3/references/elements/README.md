# Библиотеки звеньев программ со структурными схемами

Снято `scripts/elements.py` (картинки `<prog>/<буква>_<код>.png`, сводка `<prog>/index.md`).
**Код типа в VRT** — поле сразу после имени звена. Коды — непрерывный диапазон, но не всегда с 1
(LINSYS3: W 6…13, R 4…5; LINSYS2: W 6, R 4…5). Соответствие проверено по значениям параметров в штатных VRT.
Параметры в VRT идут в порядке строк окна «Параметры». Буквы A, B (C, D) вместо чисел — задаются при построении графиков.

- CONTROL — подробно в `control/README.md` (W, R, G, H: 12 типов; N: 7; f, g, v, z: 5).
- CASCAD, MVACS2, ASYMPT, SPECTR — не снимались; по справке библиотеки аналогичны CONTROL. Снять:
  `python elements.py Cascad "W1=x,y" …` (координаты букв — по снимку главного окна `tau.py shot --win main`).

## IMPULS (импульсная САР с цифровым регулятором)
| звено | код | вид | параметры |
|---|---|---|---|
| T (⊥, квантователь) | 1 | x(nT) при t=nT; T — период квантования | T |
| D (цифровой регулятор) | 1 | D(z)=K1 + K2·1/(1−z⁻¹) + K3(1−z⁻¹) — цифровой ПИД | K1, K2, K3 |
| | 2 | D(z)=K(b0+b1z⁻¹+…+b5z⁻⁵)/(1+a1z⁻¹+…+a5z⁻⁵) | K, b0…b5, a1…a5 |
| P (п, код-аналог) | 1 | x(nT) при nT<t<(n+1)T, если h=0; h·[x(nT)/h] (квантование по уровню), если h>0 | h |
| N | 1 | N(x)=x (линейная) | — |
| | 2 | насыщение: c при x>a, Kx при |x|<a, −c при x<−a (c=Ka) | K, a |
| W | 1 | K e^(−τp)/(Tp+1) | K, T, τ |
| | 2 | K e^(−τp)/(p(Tp+1)) | K, T, τ |
| | 3 | K(T3p+1)e^(−τp)/(p(T1p+1)(T2p+1)) | K, T1, T2, T3, τ |
| | 4 | K(T3p+1)(T4p+1)e^(−τp)/(p²(T1p+1)(T2p+1)) | K, T1, T2, T3, T4, τ |
| | 5 | K e^(−τp)/(T1²p²+2λT1p+1) | K, T1, λ, τ |
| | 6 | K(T2p+1)e^(−τp)/(p(T1²p²+2λT1p+1)) | K, T1, T2, λ, τ |
| | 7 | K(T4p+1)e^(−τp)/((T1p+1)(T2p+1)(T3p+1)) | K, T1, T2, T3, T4, τ |
| H | 1 | K | K |
| f, g | 1 | a0+a1t+a2t² с отсечкой ±M | a0, a1, a2, M |
| | 2 | a1 sin ω1t + a2 sin ω2t + a3 sin ω3t | a1, ω1, a2, ω2, a3, ω3 |
| | 3 | a при t<t1, 0 при t>t1 | t1, a |
Штатный VRT: T=0.355; D тип 1 (K1=B, K2=A); W тип 7 (K=1, T1=0.28, T2=0.59, T3=1.42); H=1; f=1(t).

## LINSYS2 (запаздывание)
| звено | код | вид | параметры |
|---|---|---|---|
| R | 4 | K{K1 + K2/p + K3·p/(Tp+1)} | K1, K2, K3, T (K — буква, при построении) |
| | 5 | K(b0p²+b1p+1)/(a0p²+a1p+a2) | b0, b1, a0, a1, a2 |
| W | 6 | K0(T4p+1)e^(−τp)/((T3p+1)(T2²p²+T1p+1)) | K0, T1, T2, T3, T4, τ |
| f, g | 1 | a0+a1t+a2t² с отсечкой ±M | a0, a1, a2, M |
| | 2 | a sin ωt | a, ω |
| | 3 | a при t<t1, 0 при t>t1 | t1, a |
Штатно: W = e^(−0.4p)/(0.5p+1) (K0=1, T3=0.5, τ=0.4), R — ПИД с K2=1 (И-регулятор K/p).

## NLINSYS (абсолютная устойчивость, автоколебания)
| звено | код | вид | параметры |
|---|---|---|---|
| N | 1 | идеальное двухпозиционное реле ±c с зоной b (картинка) | c, b |
| | 2 | трёхпозиционное реле с гистерезисом | c, b1, b2 |
| | 3 | трёхпозиционное реле с гистерезисом (вариант) | c, b1, b2 |
| | 4 | люфт (гистерезис с наклоном) | c, b1, b2 |
| | 5 | нестационарное: N(x,t)=K(t)x, K(t)=K1+(K2−K1)|sin Ωt| | K1, K2, Ω |
| | 6 | зона нечувствительности b1 + насыщение c | c, b1, b2 |
| | 7 | кусочно-линейная (два излома) | c1, b1, c2, b2, K |
| | 8 | реле с гистерезисом ±c, петля ±b | c, b |
| W | 1 | K(b0p⁴+…+b3p+1)e^(−τp)/(a0p⁵+…+a4p+a5) | K, b0…b3, a0…a5, τ |
| f | 1 | a(1−e^(−bt)) | a, b |
| | 2 | a0+a1t+a2t² с отсечкой ±M | a0, a1, a2, M |
| | 3 | a sin(ωt+φ) | a, ω, φ |
| | 4 | a при t<t1, 0 при t>t1 | t1, a |
Описания N 1–4, 6–8 — по картинкам статических характеристик (`nlinsys/N_0k.png`); точный смысл — справка
094_Нелинейный_элемент_NLINSYS.md. Штатно: N код 6 (c=1), W код 1 (b3=1, a3=1 …), f код 2.
