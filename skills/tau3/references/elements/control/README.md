# CONTROL — библиотека звеньев (текстом; картинки — `<буква>_<тип>.png`, сводка — index.md)

Номер типа = второе поле строки VRT (`*W12…`), параметры в VRT идут в порядке строк окна «Параметры».
Проверено: штатный `*R 21.008   0.6563` = тип 2 с K1=1.008, K2=0.6563 (видно в окне), `*W12…` = тип 12.

## W, R, G, H — одинаковая библиотека из 12 типов
| тип | передаточная функция | параметры (порядок полей VRT) |
|---|---|---|
| 1 | K | K |
| 2 | K1 + K2/p + K3·p/(Tp+1)  (ПИД с реальным дифф.) | K1, K2, K3, T |
| 3 | K/(Tp+1) | K, T |
| 4 | K(Tp+1)e^(−τp) / (p(T1p+1)(T2p+1)) | K, T, T1, T2, τ |
| 5 | K e^(−τp) / ((T1p+1)(T2p+1)) | K, τ, T1, T2 |
| 6 | K(Tp+1)/p | K, T |
| 7 | K(T1p+1)(T2p+1) / (p(Tp+1)) | K, T, T1, T2 |
| 8 | K e^(−τp) / (p(Tp+1)(T1²p²+2λT1p+1)) | K, T, T1, λ, τ |
| 9 | K(T1p+1)(T2p+1)e^(−τp) / ((T3p+1)(T4²p²+2λT4p+1)) | K, τ, T1, T2, T3, T4, λ |
| 10 | 1/(Tp+1) | T |
| 11 | p/(Tp+1) | T |
| 12 | K·(b0p⁸+…+b8)/(a0p⁹+…+a9) — общий вид | K, b0…b8, a0…a9 (20 полей) |
Запаздывание в расчётах заменяется аппроксимацией Паде (порядок 2/4 — «Параметры счета»).
Штатный W: тип 12, K=1, b8=1, a6=0.234584, a7=1.4006, a8=2.29, a9=1 → W = 1/(0.2346p³+1.4006p²+2.29p+1).

## N — нелинейный элемент, 7 типов (по картинкам статических характеристик)
| тип | вид | параметры |
|---|---|---|
| 1 | N(x)=x — линейная система | — |
| 2 | зона нечувствительности + насыщение (участки с наклоном) | c, a, b, α |
| 3 | двухпозиционное реле с гистерезисом (±c, ширина петли a) | c, a |
| 4 | двухпозиционное реле с гистерезисом (другое направление обхода петли) | c, a |
| 5 | трёхпозиционное реле с гистерезисом | c, a, b |
| 6 | трёхпозиционное реле с гистерезисом (вариант) | c, a, b |
| 7 | N(x)=a1x+a2x²+a3x³+a4x⁴+a5x⁵ | a1…a5 |
Точный смысл a, b для типов 2–6 — на картинках `N_0k.png` и в справке «Нелинейный элемент (NLINSYS)».

## f, g, v, z — воздействия, 5 типов
| тип | f(t) | параметры |
|---|---|---|
| 1 | a0 + a1·t + a2·t² с отсечкой по ±M | a0, a1, a2, M |
| 2 | a(1 − e^(−bt)) | a, b |
| 3 | a1 sin(ω1t+φ1) + a2 sin(ω2t+φ2) + a3 sin(ω3t+φ3) | a1, ω1, φ1, a2, ω2, φ2, a3, ω3, φ3 |
| 4 | a при t<t1, 0 при t>t1 (импульс) | t1, a |
| 5 | случайная ступенчатая функция: значения от −a до a на интервалах длительностью 0…τ | τ, a |
Штатно: f — тип 1, a0=1 (единичная ступень); g, v, z — тип 1 с нулями (нет возмущений).
