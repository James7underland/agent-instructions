# Программы ТАУ-3 — что умеет каждая

Подробности меню/окон — `ui-map.md`; снимки всех окон — `examples/sheets/<prog>.png`; справка —
`help/NNN_Программа_<PROG>.md`. «Ввод»: T — таблицы ПФ (TParmForm), С — структурная схема + библиотека звеньев
(`elements/`), М — матрицы (мастер TDRForm), О — особый.

## Общие окна (одинаковые во всех программах)
- `TGraForm` окно-график: меню Выбор области · Таблица корней / Аналитич. ф-ла / Резерв · Повторить · Закрыть ·
  Главное окно; слева иногда кнопки/стрелки сдвига, снизу — координаты точки по щелчку.
- `TTabRForm` таблица коэффициентов и корней — `tofile`; `TAnalFnForm` формулы — `tofile`.
- `TValForm` «Значения» (буквы A, B, K, L, λ; диапазоны от/до/шаг) — `fill`; `TWForm` «Частоты» (пусто = авто);
  `TXForm` «Нач. значение Xo»; `TTimForm` «Время регулирования»/«Число точек»/«Число корней»; `TChoicFnForm`
  выбор функций для графика (ComboBox — `select`); `TRazmForm` «Разомкнуть систему» (радиокнопки — `radio`).
- `TSchtForm` параметры счета (порядок Паде 2/4, шаг 0.01…, знаков в таблицах, R/N для корней квазиполинома).
- `TUstForm` «Проверьте установки» (в файл/на принтер, перезаписать/дописать) — только через `tofile`.
