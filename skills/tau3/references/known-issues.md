# Грабли и приёмы (ТАУ-3) — читать перед работой

## Окружение
- Программы — 32-битные Delphi (VCL, ~2004–2005), не DPI-aware. Экран 2560×1440 при 150% (логически 1707×960).
  `tau.py` переводит свой процесс в DPI-unaware → все координаты **логические**, совпадают с тем, что видит программа
  и с пикселями снимков PrintWindow (снимки чёткие, без масштабирования).
- Python x64 + pywinauto предупреждает «32-bit application should be automated using 32-bit Python» — игнорировать,
  win32-сообщения работают (предупреждения подавлены в tau.py).
- Справка `TAY_3.HLP` (WinHelp) в Windows 11 не открывается (F1 в программах бесполезна) → читать
  `references/help/*.md` (декомпилировано `scripts/hlp.py`, Hall-сжатие фраз поддержано).
- Запускать только из рабочей копии `ТАУ3 Claude\Работа\TAY_3\` (программы пишут VRT/tab/bmp рядом с exe).
  Оригинал — `ТАУ3 Claude\TAY_3\` (+ zip-бэкап `TAY_3_orig_20260924.zip`). Не создавать `C:\TAY_3` — туда программы
  переключат чтение/запись.

## Управление GUI (всё без мыши и фокуса, через оконные сообщения — пользователю не мешает)
- **Меню — всплывающие** (TPopupMenu по правой кнопке на окне), главного меню Win32 нет. `tau.py menu` шлёт
  WM_CONTEXTMENU, читает HMENU (MN_GETHMENU), закрывает Esc и выполняет пункт WM_COMMAND(id) в скрытое окно
  `TPUtilWindow` (PopupList VCL). id пунктов стабильны в пределах запуска.
- Запуск: заставка `TAboutForm` (кнопка OK) → вопрос `TMessageForm` «Использовать данные предыдущего счета?»
  (Yes — загрузить VRT; No — базовый вариант с нулями, **данные VRT будут потеряны**). `tau.py launch --prev yes|no`.
- **Текст сообщений Delphi (TMessageForm) — в TLabel без окна**: API его не читает. `tau.py answer` / `ls` сохраняют
  снимок диалога (`shot` в JSON) — смотреть картинку. Заголовки: Confirm / Information / Warning / Error.
- Текст полей чужого процесса — только через WM_GETTEXT (`gettext`), GetWindowText возвращает пусто.
- **Поля ввода применяются по OnExit** (порядок многочлена и др.): WM_SETTEXT + Tab НЕ работает (Tab не доходит),
  работает **CM_EXIT (0xB01B)** — VCL-сообщение прямо в поле. `tau.py set` делает клик→текст→CM_EXIT.
- **TStringGrid в ТАУ-3 не редактируется сам** (FixedCols = все столбцы). Щелчок по ячейке (OnMouseDown) ставит
  поверх неё общий TEdit (EditV) с текущим значением; значение фиксируется при щелчке в другую ячейку/кнопку OK.
  `tau.py grid R,C=V …` — геометрия ячеек определяется по линиям сетки на снимке, ввод через этот TEdit.
  Строки за пределами текущего порядка не открываются: сначала `set` порядок (CM_EXIT), потом `grid`.
- Кнопка OK под таблицей = «конец ввода»: пересчитывает корни ↔ коэффициенты. Без неё окно не закроется/не применит.
- Окна-графики `TGraForm` рисуются на канве: числа только со снимка, из «Аналитич. формулы» (TAnalFnForm → `tofile`)
  или таблиц (TTabRForm → `tofile`). Запись в файл: `<PROG>.tab` рядом с exe (cp1251).
- Нажатие OK «в файл» даёт Information «Таблица записана в файл X.TAB» — `tofile` закрывает его сам.
- **Никогда не выбирать «на принтер»** (откроется диалог печати Windows).
- Формы после закрытия не уничтожаются, а прячутся (Delphi) — hwnd окна-графика переиспользуется при повторном
  открытии; ориентироваться на класс/заголовок, а не на hwnd между запусками.
- Пункты меню бывают серыми (`disabled`) в зависимости от режима: LINSYS — «Задание п.ф. регулятора» только для
  замкнутой системы; «Периодический сигнал» — только при выбранной задаче «Периодический сигнал» (Выбор задачи).
  Вызов «чужого» пункта (id неактивного подменю) открывает старое окно с неверным заголовком — не доверять.

## Численные особенности
- Кратные корни считаются с погрешностью ~1e-4: (p+1)³ → −0.99991, −1.00004±0.00008j (сохраняются в VRT так же).
- Шаг счёта кривых по умолчанию 0.01 (LINSYS), число знаков в таблицах 6 — «Настройка параметров счета».
- Разработчик: «не для научных и инженерных расчётов», параметры в диапазоне ~0.01–100, степень многочленов ≤ 20
  (с учётом Паде), порядок объекта OPTIM/ANACON ≤ 5, PRONI ≤ 12 точек (чётное), IDENTF 10..50 точек в файлах.

## Обходчик (crawl.py)
- Нажимает OK во всех модальных формах → буквенные параметры/начальные условия остаются пустыми (=0): поэтому
  у ANACON/OPTIM «Процесс управления» при X°=0 — пустой график. Для осмысленных графиков вводить данные явно.
- Galery.exe и Tay_3.exe не имеют TMForm — обходятся вручную.

## Находки при обходе (2026-09-25)
- **«Cannot make a visible window modal»** (#32770, кнопка «ОК» кириллицей) — MULPOL «Ввод коэффициентов», OPTIM
  (фазовый портрет, данные), IDENTF «Выбор задачи». Появляется и при прямом WM_COMMAND без открытия popup →
  поведение самой программы. Нажать ОК (`answer OK` — латиница/кириллица распознаются), форма работает дальше.
- Коды типов звеньев в VRT — непрерывный диапазон, но **не всегда с 1** (LINSYS3: W 6…13, R 4…5; LINSYS2: W 6).
  Проверять по `references/elements/<prog>/index.md`.
- Звено с единственным типом не имеет стрелок перебора в «Элемент схемы».
- Щёлкать по букве звена нужно точно (±10 px): координаты брать со снимка главного окна (`--wxy`).
- В режиме «Формирование элементов схемы» одновременно открыты TSchtForm, TElemForm, TParamForm; повторный щелчок
  по другой букве переключает звено.
- Диспетчер Tay_3 при «Выбор» запускает программу и **завершается**; после выхода из программы запускается новый
  Tay_3 (другой pid). «Выход из программы» в любой программе → Warning «Выполнение программы прекращается» OK/Cancel.
- PRONI: перед «Метод Прони» выполнить «Задание графика функции» → «ввести из файла» (иначе точки в t=0, формула
  пустая). Число точек N (чётное) включает t=0, точки равномерно на [0, tmax].
- Текстовые формулы в .tab есть не везде (PRONI «Аналитическая функция» — только на экране; смотреть снимок).
- NLINSYS штатный VRT: у W K=0 → линейные ЛАЧХ/АЧХ: «Отсутствует числитель передаточной функции».
- ASYMPT штатный вариант неустойчив при L=1 → «Исходная система неустойчива» для временных характеристик.
- При выводе JSON с кириллицей через pipe в `python -c` задавать `PYTHONIOENCODING=utf-8` (иначе «кракозябры»).
- Обход (crawl.py) может перезаписать VRT рабочей копии (MULPOL, OPTIM) — после обхода вернуть из оригинала.

## Найдено 2026-09-25 (курсовая по ТАУ)
- **`tau.py launch` без `--dir` искал программы в `<skills_dir>\Работа\TAY_3`** → путь скилла брался
  через junction → исправлено `os.path.realpath(__file__)` (бэкап tau.py.bak-…).
- **LINSYS, корневой годограф по произвольному параметру**: записать VRT `vrt.py poly LINSYS.VRT --den A --num B
  --den 1 --num 1` (W = B/A, R = 1), «Выбор системы» → радио `TRadioGroup#1` = 1 (замкнутая), `TRadioGroup#0` = 0
  (исследование) → OK → «Корневой годограф» → `fill 0 Kmax шаг --ok OK`. Характеристическое уравнение A + K·B = 0.
- **«Выбор области» (TZoomForm)**: `TEdit#3` — X от, `#2` — X до, `#1` — Y от, `#0` — Y до (`set … -- -0.8` для
  отрицательных), затем OK. Сетка всегда 5×5, ноль лежит на линии — пределы выбирать кратными шагу.
- **Таблица корней при заданном K**: меню окна «Таблица корней» → TValForm (K) → `fill 0.05 --ok OK` → `tofile --win TTabRForm`.
- Снимок окна-графика содержит серую левую панель и заголовок: для отчёта обрезать по полю графика
  (для 853×640: box (255, 36, 832, 548)).

## PHASPL (2026-09-25, курсовая: релейная система 2-го порядка)
- Вкладка «Релейное управление» — `click --win main --xy 405,10` (вкладки: 60,10 / 250,10 / 405,10); меню меняется
  («Выбор нелинейного элемента» вместо «Задание линии переключения»).
- VRT (формат «звеньев», имя 1 символ): `*W 3K T1 T2 τ` — объект K/((T1p+1)(T2p+1))·e^(−τp) (поля по 8 символов);
  `N` — нелинейный элемент: тип 1 идеальное реле (f), 2 реле с зоной нечувствительности (a, f), 3–6 с гистерезисом.
  `vrt.py set-elem PHASPL.vrt W 3 3.9375 2.2 4.4`, `set-elem PHASPL.vrt N 2 3 0`. Реле выдаёт ±1 → амплитуду c
  закладывать в K. На вход реле подаётся −(x1 + f·x2) — f задаёт линию переключения (местная ОС).
- `fill --win TXForm -- -6 2 --ok OK` не нажимает OK → отдельно `click --win TXForm --ctl OK`.
- Несколько траекторий: `click --win TGraForm --wxy X,Y` (точка начала) + `click --ctl Пуск`; поле графика в
  снимке 853×640: x 321…801, y 37…517. «Выбор области» даёт 5 интервалов сетки (−8…8 → −8…12).
- Окно «Процесс управления» открывается частично за экраном (y = 640) → снимок наполовину белый: сдвинуть окно
  `win32gui.MoveWindow(h, 853, 200, 853, 640, True)`. Процесс обрывается после ~50 переключений (скользящий режим).
- Цвет траектории — по знаку управления (синий u = +1, зелёный u = −1), линии переключения красные.
