# Таблица коэфф. и корней

Таблица коэффициентов и корней многочленов

В таблице приведены коэффициенты (расположенные в порядке убывания степеней) и корни знаменателя и числителя дробно-рациональной функции.

Как правило, в этой таблице описывается передаточная функция для замкнутой или для разомкнутой системы, в зависимости от того, какая из этих систем использовалась в том окне программы, из которого вызвана на просмотр таблица.

Корни в таблице отсортированы по степени возрастания устойчивости, т.е. для непрерывных систем по убыванию вещественной части, а для импульсных систем по убыванию модуля.

Для импульсных систем неустойчивые корни в таблице отмечены звездочкой.

В меню этого окна есть пункты

«Вывод в файл / на принтер»

«Размер шрифта»

Повторить

Таблица может быть записана в дисковый файл (с именем программы и расширением tab) или распечатана на принтере.

Данные в таблице приведены для «выбранных» в данный момент в программе значений буквенных параметров (они указаны внизу таблицы), но можно изменить эти значения, вызвав пункт меню "Повторить".

Изменения, сделанные в Таблице, в другие окна не передаются.

В окне есть кнопка для включения / выключения режима «Уточнение значений».

В программе ASYMPT

в таблице приводятся корни характеристического уравнения замкнутой системы и коэффициенты передаточной функции объекта для параметров L и K, если эта таблица вызвана из окна "Корневой годограф" и для корня исходной системы (L < infin). Если же таблица вызвана для корня вырожденной системы (L = infin) или из окна "Годограф вырожд. сист.", то в ней приводятся данные для вырожденной системы.

В программе LINSYS2

корни характеристического уравнения замкнутой системы и коэффициенты передаточной функции объекта показаны в отдельных таблицах.

В "Таблице корней" приведены корни характеристического уравнения (квазиполинома) замкнутой системы

A(p) + K B(p) exp(-tp) = 0,

вычисленные двумя способами: с использованием подпрограммы вычисления корней аналитической функции (см. раздел «Нахождение корней аналитической функции»), или, используя аппроксимацию, по программе вычисления корней многочлена.

Если запаздывание отсутствует, то корни вычисляются по программе вычисления корней многочлена.

Данные в таблице приведены для установленного в программе коэффициента усиления K, но можно изменить его значение, вызвав пункт меню "Повторить".

В "Таблице коэффициентов" приведены коэффициенты знаменателя A(p) и числителя B(p) (при K=1) передаточной функции разомкнутой системы (без аппроксимации и с ее использованием). В таблице t - запаздывание, n - порядок многочлена, коэффициенты расположены по убыванию степеней сверху вниз.

В программе LINSYS3

в таблице показаны корни характеристического уравнения замкнутой системы.

Корни вычисляются с использованием подпрограммы вычисления корней аналитической функции. Для некоторых передаточных функций корни находятся и другим способом: используя аппроксимацию, по программе вычисления корней многочлена.

Примечание.

Аппроксимация применяется только для передаточных функций с номерами 2, 3 и 4 (см. раздел «Особые звенья»).

Данные в таблице приведены для установленного в программе коэффициента усиления K, но можно изменить его значение, вызвав пункт меню "Повторить".

В программе MVACS2

корни характеристического уравнения замкнутой системы и коэффициенты этого уравнения объекта показаны в отдельных таблицах.

В "Таблице корней" (вызываемой только из окна "Корневой годограф") приведены корни характеристического уравнения (квазиполинома) для замкнутой системы или для сепаратной подсистемы.

Для систем без запаздывания и для импульсных систем корни находятся при помощи подпрограммы решения алгебраических уравнений, иначе используется программа нахождения нулей аналитических функций.

Корни ищутся в круге радиуса R, не более N корней (параметры R и N задаются при «настройке параметров счета»), но если будет найдено больше 20 корней, то из них отбираются 20 идущих по порядку.

Для удобства оценки степени устойчивости для импульсной системы в таблице приводятся модули корней

Программа QPOL

В таблице, вызываемой из окна "Корни квазиполинома", приведены корни квазиполинома. Сообщается, сколько всего корней содержится в круге заданного радиуса R, но это число, полученное приближенным вычислением контурного интеграла, может быть неточным.

Для сравнения приводятся корни многочлена, который получается при замене запаздываний аппроксимацией Паде.

В программе SPECTR

в таблице, вызываемой из окна "Спектральные функции", приводятся коэффициенты знаменателя и числителя передаточной или спектральной функции и их корни. Функция для показа в таблице выбирается из открывающегося списка.

Для программы RTLZ

вызывается таблица «Z-преобразования». Программа запрашивает период квантования T и запаздывание t. Нужно ввести эти параметры нажать кнопку OK, чтобы закрыть окно ввода.

Значения T и t будут указаны внизу таблицы. Эти значения можно изменить, вызвав пункт меню "Повторить".

См. также раздел «Таблица коэффициентов квазиполинома».
