# Z-передаточн. функции (MVACS)

Z-передаточные функции (для программы MVACS)

Этот раздел только для импульсных систем.

Для импульсных систем функции W(p) заменяются преобразованными функциями

[рис. bm105]Программа вычисляет Z-преобразование передаточной функции, используя представление дробно-рациональной функции в виде суммы элементарных звеньев и таблицу соответствия между преобразованием Лапласа и Z-преобразованием.В четырех таблицах приведены порядки и коэффициенты (расположенные в порядке убывания степеней) знаменателей и числителей z-передаточных функций для звеньев, описывающих объект многосвязной системы. Если числитель имеет неустойчивые корни, то колонка коэффициентов отмечена звездочкой.

В меню окна есть пункты

«Вывод в файл / на принтер»

Повторить

Данные в таблице приведены для «выбранных» в данный момент в программе значений буквенных параметров, но можно изменить эти значения, вызвав пункт меню "Повторить".

В окне имеется кнопка для включения / выключения режима «Уточнение значений».
