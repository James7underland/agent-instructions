# Выбранные значения

Выбранные значения

В программе существуют "выбранные значения" букв A, B (в отдельных программах могут быть другие буквы).

Это либо их единственные значения, либо те значения из их диапазона, которые были указаны на графике (в таблице Рауса) мышью и зафиксированы кнопкой выбора, либо первые значения в диапазонах.

Значения, выбранные в одном окне, передаются в другие окна программы (кроме значений, измененных в Таблице).
