# Амплитудно-частотная характеристика

Амплитудно-частотная характеристика

Строится амплитудно-частотная характеристика замкнутой системы.

Перед тем, как построить график, программа запрашивает значения буквенных параметров.

В «таблице», вызываемой из этого окна, приводятся данные (коэффициенты передаточных функций и их корни) для замкнутой системы.

В программе ASYMPT

строится АЧХ для исходной и для вырожденной системы.

В программе LINSYS

для замкнутой системы запрашивается значение коэффициента K. Если система разомкнутая, то строится АЧХ разомкнутой системы.

В программе QPOL

строится АЧХ формальной САУ, передаточная функция которой W(p)=B(p)/A(p) выбрана таким образом, чтобы ее характеристическое уравнение имело вид заданного квазиполинома.

В меню окна есть пункт "Аппроксимация Паде". При нажатии этого пункта на графике для сравнения строится та же кривая, но вычисленная с использованием аппроксимации. Этот пункт не действует, если нет запаздывания.

При повторном нажатии этого пункта меню рисование кривой сравнения отменяется.

В программе SPECTR

для 2-й задачи строится АЧХ передаточной функции фильтра Винера.
