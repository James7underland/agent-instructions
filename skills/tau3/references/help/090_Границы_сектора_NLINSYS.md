# Границы сектора (NLINSYS)

Границы сектора (в программе NLINSYS)

На панели "Границы сектора" нажатием кнопки выбирается вариант A или B. Если выбран вариант A, то вводится только верхняя граница сектора 

m, а нижняя граница полагается равной нулю. Если выбран вариант B, то вводятся нижняя и верхняя границы сектора m1 и m2, причем проверяется (при нажатии кнопок OK или Границы) выполнение условий 0<m1<m2. Можно ввести символ * (звездочка), который означает вертикальный наклон границы.

Для ввода данных доступны только окошки соответствующего варианта.

Одновременно с панелью "Границы сектора" на экран выводится график
