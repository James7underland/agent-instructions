# Программа MVACS2

Программа MVACS2

Линейная двусвязная САР

Программа предназначена для исследования двусвязной САР, структурная схема которой для выбранного варианта задачи изображена в Главном окне. На схеме:

W11, W22, W12, W21 – собственные и перекрестные звенья объекта,

R11, R22 – регуляторы,

Q12, Q21 – компенсирующие звенья (для автономного управления),

^ – блок квантования сигнала с периодом квантования Т (для импульсной системы),

п – преобразователь код-аналог (для импульсной системы),

f1, f2 – задающие воздействия,

g1, g2 – входные воздействия,

y1, y2 – выходные сигналы,

u1, u2 – дополнительные точки, выход из которых может отслеживаться при построении процесса регулирования.

Примечания.

1. В Главном меню присутствует только один из пунктов "ЛАЧХ, ЛФЧХ" или "Z-передаточные функции" в зависимости от выбора варианта задачи. Первый пункт для непрерывных систем, второй – для импульсных систем.

2. Если генеральные обратные связи разомкнуты, то вместо пункта "Процесс регулирования" в меню присутствует пункт "Переходный процесс".

3. В программе MVACS2 аппроксимация Паде не используется.

Размыкание обратных связей

Вы можете разомкнуть / замкнуть генеральные обратные связи системы. Размыкание связей в данной программе оказывает влияние только на график "Процесс регулирования". Это дает возможность построить переходный процесс объекта.
