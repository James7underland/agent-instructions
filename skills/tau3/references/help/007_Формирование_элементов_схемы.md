# Формирование элементов схемы

Формирование элементов схемы

В программах ТАУ-3 используются (в основном) три различных способа ввода числовых данных для проведения расчетов в зависимости от постановки задачи.

1. Главное окно программы содержит изображение структурной схемы САУ. Для каждого элемента схемы нужно выбрать передаточную функцию из числа предусмотренных в программе, а для выбранной функции - задать значения входящих в ее описание буквенных коэффициентов. Также нужно задать входные воздействия (они задаются как функции времени или, если это случайные воздействия, своими спектральными функциями). Этот способ описан в данном разделе.

2. Передаточные функции звеньев структурной схемы – дробно-рациональные функции общего вида. Коэффициенты многочленов числителя и знаменателя (или корней этих многочленов) задаются в табличной форме. См. раздел «Задание передаточной функции».

3. Управляемая система описывается дифференциальными уравнениями в матричной форме, нужно ввести коэффициенты матриц. См. раздел «Ввод данных (матрицы)».

Перед входом в этот раздел программа сообщает, что в случае, если параметры будут изменены, то все имеющиеся на экране окна-графики будут закрыты. Если Вы согласны, нажмите кнопку OK, а если это не входит в Ваши планы, то нажмите кнопку Cancel (отменить). На время ввода параметров окна-графики будут скрыты, но снова откроются при входе в любой другой раздел (кроме «Просмотра параметров»), если Вы ничего не ввели и не поменяли тип элементов.

Для ввода параметров:

1. Нажмите букву на структурной схеме в Главном окне, чтобы выбрать передаточную функцию, нелинейное звено или входное воздействие, параметры которых нужно задать.

2. С помощью кнопок-стрелок под окном "Элемент схемы", найдите в библиотеке нужный Вам тип элемента, отмеченного на схеме. Для фиксации этого выбора нажмите кнопку OK (кнопка выбора) внизу окна. Один из типов элемента всегда будет отмечен надписью "Вариант выбран".

3. В окне "Параметры" введите значения параметров. Для активизации поля ввода щелкните мышью в соответствующей строке списка параметров. Появится текстовый курсор.

Чтобы выйти из режима "Формирование элементов схемы" (если данные введены без ошибок), нужно закрыть окно "Элемент схемы" или вызвать любой другой пункт Главного меню.

Программа выявляет «ошибки ввода» данных.

Внимание! Отсутствие значения параметра равносильно нулевому значению.

В этой же части программы производится «настройка параметров счета».

Наряду с числовыми параметрами в некоторых программах допускаются буквенные параметры A, B (латинские) и др. Их значения определяются позже при построении графиков.

В программах CASCAD, CONTROL, IMPULS. и MVACS2

допускается также ввод букв C, D. Последние две буквы используются только для задания функций времени, их численные значения устанавливаются при построении графика "Процесс регулирования" и "Поиск минимума".

Примечания к программе MVACS2.

Для компенсирующих звеньев буквенные параметры не вводятся. В режиме проверки робастности ввод параметров регуляторов (и периода квантования) заблокирован.

В программе SPECTR

буквенные значения A или B можно использовать только при задании параметров регулятора.

Примечания.

1. Если в программе задаются всего один или два элемента (OPTIM, PHASPL), то их выбор происходит не так, как указано в п.1, а при помощи отдельных пунктов меню. В этом случае вместо названия окна "Элемент схемы" используется указание на конкретный элемент (объект, регулятор или нелинейность).

2. В ряде программ значения некоторых параметров не задаются вместе с остальными, а определяются позже при построении графиков, как и значения A и B.
