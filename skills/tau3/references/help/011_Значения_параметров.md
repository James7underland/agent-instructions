# Значения параметров

Значения параметров

При задании параметров системы некоторые из них получили буквенные значения. До начала расчетов нужно присвоить этим буквам числовые значения или ряд числовых значений. В последнем случае задаются начальное значение, шаг изменения параметра и значение, по достижении которого ряд заканчивается (от, до, шаг). По окончании ввода нажмите кнопку OK (конец ввода).

Внимание!

Независимо от введенного значения "до" число вариантов параметра в "Критерии Рауса" не больше 20-ти, в "Корневом годографе" не больше 200, а в остальных случаях не больше 50-ти. Только в программе ASYMPT в окне "Корневой годограф" число вариантов параметра L увеличено до 1000.

В программе LINSYS2 (и в программе LINSYS3 для передаточных функций 2, 3 и 4) число вариантов параметров K и l  не больше 25.
