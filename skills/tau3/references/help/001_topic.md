# 

Программы на компакт-диске

Можно запускать программы ТАУ-3 с компакт-диска, не переписывая их на жесткий диск компьютера. В этом случае те временные файлы, которые создаются во время работы программ (задаваемые параметры задачи, табличные данные, рисунки и др.) будут записываться в каталог C:\TAY_3. Если такого каталога нет, то он будет создан.

Программы, запускаемые с компакт-диска, ищут нужные им файлы данных сначала в каталоге C:\TAY_3, а затем, если не находят, то в своем каталоге.

Если файлы комплекта ТАУ-3 переписаны в каталог жесткого диска, то создаваемые программами временные файлы (о которых сказано выше) будут записываться в тот же каталог.

Примечание.

При списывании с компакт-диска файлы могут получить атрибут “только для чтения”. Этот атрибут с временных файлов нужно убрать, иначе попытка их повторной записи вызовет сбой в работе программы.
