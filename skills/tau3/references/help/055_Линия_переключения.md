# Линия переключения

Задание линии переключения

Этот пункт только для случая выбора квазиоптимального управления.

Линия переключения может быть введена из файла (если такой файл имеется) или построена на графике. Она располагается во 2-м и 4-м квадрантах симметрично относительно начала координат (задается только ветвь кривой  x1 > 0,  x2 < 0) и начинается всегда в начале координат (эта точку указывать не нужно, она порождается автоматически).

Чтобы отметить на графике новую точку кривой, нужно щелкнуть в этом месте мышью. Каждая следующая точка рисуется правее предыдущей точки и соединяется с ней отрезком.

Последнее звено кривой можно удалить, нажав на концевую точку.

Если линия введена из файла, ее также можно редактировать, как указано выше.

Чтобы записать вновь построенную или измененную линию переключения в файл, нужно использовать пункт меню "Записать в файл".

Линия переключения сохраняется в файле с названием программы и расширением lsw. В каждой строке этого файла - пара координат  x1,  x2  через пробел (x1 > 0  возрастают,  x2 < 0), не более 50 строк.

Если линия переключения изменена, но не запомнена, то она используется при построении других графиков, но при повторном вызове из файла будет загружена предыдущая кривая.
