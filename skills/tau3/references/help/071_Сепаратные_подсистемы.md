# Сепаратные подсистемы

Сепаратные подсистемы

Если выбран вариант "Автономное управление" и режим проверки робастности не установлен, то двусвязная система распадается на две сепаратные подсистемы. Схема эквивалентной системы представлена в отдельном окне.

На всех графиках (кроме графика "Процесс регулирования") кривые строятся для одной из сепаратных подсистем по выбору.

См. раздел «Выбор варианта задачи»
