# 

Уточнение значений (кнопка)

В окнах некоторых таблиц есть кнопка с изображением увеличительного стекла. Нажатие этой кнопки включает режим уточненного просмотра данных. Если (при включенном режиме) нажать мышью в клетке таблицы, содержащей число, то над этой клеткой откроется окошко, в котором это число будет показано в "научной форме" (с мантиссой и порядком) с большим числом знаков после десятичной точки.

Выключается режим повторным нажатием той же кнопки.
