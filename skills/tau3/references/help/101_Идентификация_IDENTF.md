# Идентификация (IDENTF)

Идентификация (для программы IDENTF)

Назначение программы - восстановление неизвестной передаточной функции

[рис. bm128]Если исходные данные определяются, исходя из заданной передаточной функции, то пункт "Идентификация" неактивен, пока не будут построены графики (АФХ и переходная функция или ЛАЧХ и ЛФЧХ, соответственно), так как в этом случае во время рисования графиков вычисляются экспериментальные данные, по которым должна проводиться идентификация.

Методы идентификации

Метод идентификации многочленов A(p) и B(p) зависит от того, для какого графика она проводится, а коэффициент K0 и запаздывание t  определяются непосредственно по графикам, как указано в разделе «Выбор задачи».

Идентификация по АФХ

Если расчеты проводятся для АФХ, то коэффициенты многочленов A(p) и B(p) передаточной функции ищутся по методу наименьших квадратов с использованием уравнений

[рис. bm129]где p = jw, а частоты w принимают заданные значения, число которых от 10 до 50.В этих уравнениях, во-первых, разделяются действительная и мнимая части, во-вторых, уравнения нормируются, делятся на наибольший по модулю коэффициент.Идентификация по передаточной функцииВ случае, когда передаточная функция восстанавливается по известной переходной функции, программа может применить один из трех методов.

1. Пересчет на АФХ. Преобразование Лапласа весовой функции

[рис. bm130]где p = jw, а частоты w (для удобства сравнения) взяты те же, для которых задана АФХ, находится, используя численное интегрирование по схемеЗдесьгде T - момент выхода на стационарный режим: h(t) = K0 при t >T, N = 200 (при помощи аппроксимации сплайнами на кривой h(t) находится 200 равноотстоящих точек).

Затем коэффициенты передаточной функции ищутся по методу наименьших квадратов, как описано выше.

2. Метод моментов (название условное). Также находится преобразование Лапласа весовой функции, но для такого числа действительных значений p, которое нужно для определения неизвестных коэффициентов.

3. Метод Прони разработан специально для подбора эмпирических формул в виде суммы комплексных экспонент. Этот метод хорошо работает, если [рис. bm133] где N - число измерений, а n - заданное число экспонент, но есть вариант и для  (комбинация с методом наименьших квадратов), который используется в этой программе.

Классический вариант метода Прони описан в книге Я.С. Безиковича "Приближенные вычисления", М.-Л., Гостехиздат, 1949.

От стандартной схемы есть два отличия. Во-первых, метод применяется к функции 1 - h(t)/K0. Это исключает из поиска экспоненту с показателем 0 и в дальнейшем обеспечивает выход результирующей кривой на уровень h(t) = K0 . Во-вторых, добавляется условие: сумма коэффициентов при экспонентах равна 1. При этом условии порядок числителя передаточной функции будет меньше, чем порядок знаменателя.

Примечания.

1. Все методы, особенно метод Прони, очень чувствительны к погрешностям измерения. Если при задании точек используется случайная помеха, то результаты невоспроизводимы, они могут значительно отличаться в разных реализациях.

2. Во всех методах находятся коэффициенты передаточной функции, а порядки нужно угадать. Признаком неудачного подбора порядков многочленов A(p) и B(p) являются малые коэффициенты при старших степенях p и большие корни многочленов, а также несовпадение экспериментальных и расчетных кривых.

В методе Прони задается число экспонент, сумма которых аппроксимирует кривую h(t), а полученный в результате порядок объекта может быть как больше, так и меньше этого числа.

3. В методах 1, 2, использующих интегрирование, предполагается, что h(T)=K0 , где T - правый конец интервала, на котором определена функция h(t). Поэтому эти методы неприменимы для слабо затухающих колебательных процессов, так как (по условиям программы) в промежутке (t, T) не может быть более 50 измерений. В то же время, метод Прони может дать хороший результат и в том случае, когда задан небольшой отрезок функции h(t).

Сообщения об ошибках

В отдельных случаях программа может выдать сообщение об ошибке в расчетах, что свидетельствует о плохих исходных данных.

Для идентификации передаточной функции может использоваться метод наименьших квадратов. Если порядки знаменателя и числителя выбраны неудачно (или по другим причинам), при вычислениях может образоваться вырожденная матрица. В этом случае результат не может быть получен. Метод Прони не работает, если [рис. bm135]. Решение также расценивается как неверное, если будет получен порядок объекта больше 5.

Идентификация по ЛАЧХ

Экспериментальная ЛАЧХ аппроксимируется ломаной линией, звенья которой имеют наклон кратный 20 дцб на декаду. Анализ этой ломаной позволяет выделить множители 1-го и 2-го порядков в числителе и знаменателе передаточной функции. Идеи такого подхода изложены, например, в книге "Теория автоматического управления", под ред. А.В. Нетушила, М., Высшая школа, 1976.

Метод в большой степени эвристический и не гарантирует получение результата. Могут выдаваться сообщения об ошибках анализа: "Много звеньев", "Нет звеньев" или "ЛАЧХ слишком сложная".

Примечание.

Раздел программы «Проведение прямых» предназначен для такого же анализа графика ЛАЧХ, но проводимого не программой, а пользователем-студентом.

Идентификация по АФХ или по передаточной функции

Перед идентификацией программа запрашивает порядок знаменателя и числителя передаточной функции. Порядок знаменателя не должен быть больше 5, порядок числителя меньше порядка знаменателя.

После расчета в таблицах "Знаменатель" и "Числитель" будут приведены коэффициенты и корни многочленов A(p) и B(p). Многочлены нормируются таким образом, чтобы последний по старшинству ненулевой коэффициент был равен 1.

В таблице "Ошибка решения" приведены данные:

- среднеквадратичная ошибка для АФХ,

- максимальная ошибка для АФХ,

- среднеквадратичная ошибка для переходной функции,

- максимальная ошибка для переходной функции.

Если какие-то из этих данных в таблицу не вписаны, значит, они слишком велики.

Признаком неудачного подбора порядков многочленов A(p) и B(p) являются малые коэффициенты при старших степенях p, большие корни многочленов, большие ошибки. Чтобы провести расчет с другими порядками, используйте пункт меню "Повторить".

Примечание.

Если задача решается по методу Прони, то программа запрашивает не порядок многочленов, а число экспонент (не больше 5), суммой которых аппроксимируется переходная функция (не считая постоянного слагаемого K0). Найденный этим методом порядок объекта может отличаться от заданного числа экспонент.
