# Поиск минимума

Поиск минимума

В некоторых программах предусмотрена подпрограмма поиска оптимальных параметров регулятора.

Программы CONTROL, IMPULS

Программа запрашивает диапазоны изменения величин A, B (начальное значение, конечное значение и шаг изменения параметра, но не более 50-ти значений по каждой из величин).

Программа также запрашивает время регулирования tрег. Если время регулирования не задать (оставить поле ввода пустым) то для устойчивой линейной системы это время программа находит, исходя из корней характеристического уравнения. Для неустойчивых линейных систем и для нелинейных систем расчет не производится, если время tрег не задано.

На заданном множестве вариантов параметров ищутся те варианты, при которых достигается минимум:

1. интеграла от модуля рассогласования (ошибки) e(t) = f(t) - y(t),

2. интеграла от квадрата рассогласования (ошибки),

3. времени регулирования (в том случае, если оно не задано).

Счет можно прекратить, нажав клавишу Esc.

Если ни один вариант не просчитан по причинам, указанным выше, то выдается сообщение.

Примечание.

Поиск минимума производится в том же окне, в котором строится график "Процесс регулирования", поэтому при вызове поиска минимума "Процесс регулирования" закрывается.

Программа CASCAD

Отличие от программы CONTROL состоит только в том, что рассогласование обозначается e1(t) для системы 1 и e2(t) для системы 2.

Программа SPECTR (1-я задача)

Программа запрашивает диапазоны изменения параметров регулятора A,B (начальное значение, конечное значение, шаг изменения параметра, но не более 50-ти значений по каждой из величин).

Для параметров в заданных диапазонах вычисляется дисперсия ошибки выхода Se(w). Счет можно прекратить, нажав клавишу Esc. Находятся параметры регулятора, для которых дисперсия минимальна. При подсчете числа вариантов пропускаются те, для которых дисперсия бесконечна или программа не смогла ее вычислить.

Сообщение "Ни один вариант не просчитан" означает, что ни при каких параметрах дисперсия не найдена.

Результаты расчетов представлены в таблице. Таблица может быть записана в дисковый файл (с именем программы и расширением tab) или распечатана на принтере.
