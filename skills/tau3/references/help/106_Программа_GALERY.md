# Программа GALERY

Программа GALERY

История авторегулирования в портретах

Программа служит для просмотра фотографий, которые хранятся в графических файлах в формате bmp. Эти файлы размещаются в подкаталоге PORTRAIT каталога, содержащего программы ТАУ-3.

Программа использует информационный файл с названием программы и расширением lst (galery.lst), в котором содержится описание графических файлов.

Для смены фотографий используйте кнопки Вперед и Назад, для выхода из программы – кнопку Выход (или ключ F10).

В файле lst для каждого описываемого файла приведена следующая информация:

- номер файла, перед которым стоит значок # (номера должны идти в порядке возрастания),

- ФИО ученого, изображенного на фотографии,

- годы его жизни,

- пояснительный текст с разбивкой на строки (длина строк не имеет значения, а общая длина текста определяется величиной окна, в котором он будет показан).
