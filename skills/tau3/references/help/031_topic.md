# 

Запаздывание велико для выбранного масштаба

При расчете процесса регулирования для системы с запаздыванием предыдущие значения функций запоминаются в буфере, для которого отведено определенное место в памяти. Количество запоминаемых данных зависит от величины запаздывания и от масштаба, выбранного на графике по оси  t  (чем мельче масштаб, тем больше относительная величина запаздывания). Предупреждение означает, что данные не помещаются в буфере.
