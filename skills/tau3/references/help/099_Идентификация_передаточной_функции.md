# Идентификация передаточной функции

Программа IDENTF

Идентификация передаточной функции

Программа дает возможность сравнить результаты нескольких методов идентификации передаточной функции

[рис. bm127]по заданным графикам АФХ, переходной функции или ЛАЧХ. Графики могут быть введены из файлов или рассчитаны по заданной передаточной функции с добавлением помех.Объект должен быть устойчивым.Порядок знаменателя передаточной функции не больше 5, порядок числителя меньше порядка знаменателя.

Главное меню программы:

«Выбор задачи»

«Задание передаточной функции» (b)

«Записать данные в файл» (b)

«Настройка параметров счета»

«Ампл. фазовая хар-ка» (1,2)

«Переходная функция» (1,2)

«График ЛАЧХ» (3)

«График ЛФЧХ» (3)

«Идентификация»

«Коррекция передаточной функции» (1,2)

«Расчетная передаточная функция» (3)

«Выход из программы»

Некоторые пункты входят в меню в зависимости от выбора задачи. Пункты, помеченные указателем (1,2), присутствуют в случае идентификации по АФХ или по переходной функции, пункты (3) - в случае идентификации по ЛАЧХ. Пункты (b), отсутствуют, если данные вводятся из файла.

Некоторые пункты меню неактивны до тех пор, пока не будут выполнены другие связанные с ними пункты.
