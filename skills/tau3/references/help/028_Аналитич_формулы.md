Программа IDENTF

В таблице приведено аналитическое выражение для переходной функции h(t), полученное при помощи обратного преобразования Лапласа по найденной передаточной функции без учета запаздывания.

Программа LINSYS

Пункт меню "Аналитич. формулы" имеется в окнах "Весовая функция", "Переходная функция", "Установившийся процесс" и "Ряд Фурье входа".

Для первых двух окон на просмотр вызывается таблица, в которой приведены аналитические выражения для функций y(t) и u(t), полученных при помощи обратного преобразования Лапласа.

Примечание.

Функция u(t) не строится для разомкнутой системы и не для любых данных в случае замкнутой системы.

В таблице приведены также преобразования Лапласа этих функций - знаменатель (общий для них) и числители дробно-рациональных функций от p.

Для окна в разделе "Периодический сигнал" приводятся тригонометрические разложения входного и выходного сигналов (не более 5 ненулевых слагаемых).

Программа LINSYS2

Из окна "Переходный процесс" вызывается на просмотр таблица, в которой приведены аналитические выражения для функций y(t) и u(t), полученных при помощи обратного преобразования Лапласа. Для этого вычисляются вычеты по найденным корням характеристического уравнения (см. раздел «Таблица корней»).

Если передаточная функция объекта имеет запаздывание, то это запаздывание показывается на графике, но не учитываются в аналитической формуле для y(t).

Формулы получены для установленного в программе коэффициента усиления K.

Программа PRONI

Приведено аналитическое выражение функции, найденной по методу Прони.

Программа QPOL

В числителе функции W(p)=B(p)/A(p) может быть несколько слагаемых с запаздыванием. Наименьшее из них выносится за скобки. Это запаздывание строится на графике "Переходный процесс", но не учитывается при вычислении обратного преобразования Лапласа и не отражено в аналитической формуле.

Программа RTLZ

Из окна "Обратное преобразов. Лапласа - формула" на просмотр вызывается таблица, в которой приведено аналитическое выражение для функции y(t), полученной при помощи обратного преобразования Лапласа.

Из окна "Обратное Z-преобразов. - формула" на просмотр вызывается таблица, в которой приведено аналитическое выражение для дискретной функции y[n], полученной при помощи обратного Z-преобразования.

В меню окна с аналитическими формулами есть пункт «Вывод в файл / на принтер».
