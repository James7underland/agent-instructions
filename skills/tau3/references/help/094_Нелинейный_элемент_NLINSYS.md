# Нелинейный элемент (NLINSYS)

Нелинейный элемент (NLNSYS)

В этом окне изображена статическая характеристика нелинейного звена. Если нелинейный элемент - реле с опережением, то в заголовке окна добавлено пояснение.

Один из нелинейных элементов в программе - динамический, он изображен на графике условно, в виде сектора.

Окно "Нелинейный элемент" не вызывается самостоятельно, а всегда вместе с окном из раздела "Исследование нелинейной системы" (автоматически или по команде меню).

В некоторых разделах программы через начало координат «проводится прямая», которую можно поворачивать мышью или курсорными клавишами - граница сектора.

Сбоку графика помещается кнопка, которая включает и выключает проведение прямых. На кнопке имеется надпись X, 1 или 2, которая меняется при нажатии на эту кнопку. Для варианта A (см. раздел «Границы сектора») надпись 1 включает рисование верхней границы сектора. Для варианта B надпись 1 включает рисование нижней границы, а надпись 2 включает рисование верхней границы. Надпись X показывает, что рисование выключено.
