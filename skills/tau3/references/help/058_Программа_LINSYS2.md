# Программа LINSYS2

Программа LINSYS2

Линейные системы с запаздыванием

Программа предназначена для сравнения различных способов аппроксимации запаздывания в линейных системах. Структурная схема САР изображена в Главном окне.

На схеме:

W - объект,

R - регулятор,

f, g - входные сигналы, задающее и возмущающее воздействия,

y - выходной сигнал,

e, u - дополнительные точки, выход из которых может отслеживаться при построении процесса регулирования (e = f – y).

В программе есть два буквенных параметра: коэффициент усиления регулятора K и параметр l, который используется для построения ряда графиков.

В меню окон-графиков (кроме графика "Переходный процесс"), имеется пункт "Аппроксимация". При вызове этого пункта кривая, уже нарисованная на графике, строится еще раз, но другим способом - с использованием выбранной аппроксимации запаздывания. Чтобы отменить рисование этой дополнительной кривой, нужно вызвать пункт меню "Аппроксимация" повторно.

Если в объекте нет запаздывания, то пункт меню "Аппроксимация" не активен.
