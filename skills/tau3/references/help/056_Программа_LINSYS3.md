# Программа LINSYS3

Программа LINSYS3

Линейные системы с особыми звеньями

Программа предназначена для исследования САР с нестандартными (особыми) звеньями и для сравнения различных способов аппроксимации трансцендентных функций, входящих в описание передаточных функций этих звеньев. Структурная схема САР изображена в Главном окне.

На схеме:

W - объект,

R - регулятор,

f, g - входные сигналы, задающее и возмущающее воздействия,

y - выходной сигнал,

e, u - дополнительные точки, выход из которых может отслеживаться при построении процесса регулирования (e = f – y).

В программе есть два буквенных параметра: коэффициент усиления регулятора K и параметр l, который используется для построения ряда графиков.

В меню окон-графиков имеется пункт "Аппроксимация". При вызове этого пункта кривая, уже нарисованная на графике, строится еще раз, но другим способом - с использованием выбранной аппроксимации. Чтобы отменить рисование этой дополнительной кривой, нужно вызвать пункт меню "Аппроксимация" повторно.

Примечание.

Аппроксимация производится только для трех из восьми предусмотренных в программе особых звеньев (2, 3 и 4, см. раздел «Особые звенья»). Для остальных особых звеньев пункт меню "Аппроксимация" не Якубовича""""""""""""""""""""
