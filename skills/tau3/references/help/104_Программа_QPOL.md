# Программа QPOL

Программа QPOL

Исследование квазиполинома

Сервисная программа, предназначенная для:

-  нахождения корней квазиполинома A(p)+B(p), где B(p)=B1(p)exp(-t1p)+...+B5(p)exp(-t5p),

-  исследования замкнутой системы, для которой передаточная функция разомкнутой системы равна W(p)=B(p)/A(p).

Главное меню программы:

«Коэффициенты квазиполинома»

«Настройка параметров счета»

«Корни квазиполинома»

«Переходный процесс»

«Ампл. част.хар-ка»

«Критерий Найквиста»

«ЛАЧХ, ЛФЧХ»

«Выход из программы»

В программе QPOL вычисления производятся двумя способами: без использования аппроксимации Паде и с использованием аппроксимации (для оценки эффективности ее применения).
