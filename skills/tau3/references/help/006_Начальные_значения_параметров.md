# Начальные значения параметров

Начальные значения параметров

Вы можете использовать параметры, оставшиеся от предыдущего запуска программы. После окончания работы программа запоминает по одному варианту для каждого типа функции.

Данные запоминаются в файле, имя которого состоит из названия программы и расширения vrt.

Некоторые программы хранят информацию в кодированном виде, но в ряде случаев (указанных ниже) это текстовый файл, в нем содержатся как введенные данные, так и полученные в результате счета.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

Использовать данные предыдущего счета?

Вы ответите "Да", то любые данные впоследствии можно будет изменить за исключением «размеров» (для систем, описываемых дифференциальными уравнениями в матричной форме).

Если же Вы ответите "Нет", то установится базовый вариант, в котором большинство параметров равно нулю. Данные предыдущей работы при этом теряются.

Программы, в которых файл vrt предназначен для чтения: ANACON2, ANACON3, KALMAN, OPTIM2.

Запомнить вариант (для программы KALMAN)

Только в программе KALMAN данные задачи не запоминаются автоматически, а требуется вызов пункта меню "Запомнить вариант".

Образуется текстовый файл, который можно читать и распечатать на принтере. Запись в файл возможно произвести только после того, как все нужные для этого данные будут посчитаны и проверены.
