# Таблица коэфф. квазиполинома

Таблица коэффициентов квазиполинома

Программа MVACS2

В таблице приведены коэффициенты характеристического уравнения замкнутой системы или одной из сепаратных подсистем (в случае автономности).

Характеристическое уравнение в левой части содержит квазиполином

[рис. bm106]для непрерывной системы с запаздыванием или обычный многочлендля непрерывной системы без запаздывания и для импульсной системы (в последнем случае многочлены от переменной z).

При построении частотных характеристик передаточная функция объекта W(p)=B(p)/A(p), где B(p) - все слагаемые квазиполинома кроме A(p). Многочлен A(p) имеет порядок выше, чем порядки B1(p), B2(p),...

В столбцах таблицы приведены коэффициенты многочленов A(p), B1(p), B2(p),... по убыванию степеней, в строке t приведены соответствующие этим многочленам запаздывания, в строке n – порядки многочленов.

В меню этого окна есть пункты

«Вывод в файл / на принтер»

«Размер шрифта»

Повторить

Данные в таблице приведены для «выбранных» в данный момент в программе значений буквенных параметров, но можно изменить эти значения, вызвав пункт меню "Повторить".

Изменения, сделанные в Таблице, в другие окна не передаются.

В окне есть кнопка для включения / выключения режима «Уточнение значений».

См. также раздел «Таблица коэфф. и корней многочленов»

Программа QPOL

Здесь таблица устроена так же, как в программе MVACS2, но таблица служит не только для просмотра данных, но, главным образом, для их ввода.

Нужно задать параметры функции

[рис. bm108]порядки и коэффициенты многочленов A(p), B1(p), … , B5(p), запаздывания. Сначала нужно задавать порядок многочлена, так как это определяет, сколько полей будет доступно для ввода коэффициентов. В столбцах таблицы записываются коэффициенты многочленов (по убыванию степеней), в строке t - соответствующие этим многочленам запаздывания, в строке n – порядки многочленов.

Внимание! Отсутствие значения параметра равносильно нулевому значению.

Программа выявляет «ошибки ввода» данных.

Перед закрытием таблицы программа, во-первых, проверяет правильность ее заполнения:

1. Многочлен A(p) должен иметь порядок выше, чем остальные многочлены.

2. Старший коэффициент многочлена должен быть ненулевым.

3. Некоторые столбцы таблицы можно оставить пустыми (признак этого - нулевой порядок и нулевой старший коэффициент). Но хотя бы один из многочленов B1(p), … , B5(p) должен присутствовать.

Во-вторых, программа приводит в соответствие порядки многочленов с числом их коэффициентов и приведение подобных членов, если заданы одинаковые запаздывания.

В окне имеется кнопка OK (конец ввода), при нажатии на которую программа выполняет указанные выше действия, но окно таблицы не закрывается.
