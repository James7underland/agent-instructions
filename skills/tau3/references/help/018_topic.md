# 

Продолжить

Рисование можно оборвать, нажав Esc, тогда будет построена только часть кривой переходного процесса. Если вызвать пункт меню "Продолжить", рисование возобновится. Если же кривая была доведена до правой границы поля графика, которой соответствует время T, то будут построены кривые для интервала времени (T,2T), затем для интервала (2T,3T) и т.д.
