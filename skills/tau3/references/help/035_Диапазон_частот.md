# Диапазон частот

Диапазон частот

На АФХ (кривой Найквиста) можно отметить ряд точек. Для этого задаются начальная частота, шаг ее изменения и конечное значение (но не более 50-ти значений). Если щелкнуть мышью в точке кривой, которая соответствует одной из отмеченных частот, то значение частоты появится в нижней части окна.

После ввода данных нажмите кнопку OK (конец ввода). Если не нужно отмечать частоты, оставьте все поля ввода пустыми.

Программа IDENTF

В этой программе окно задания диапазона частот (времен) используется в том случае, если источником ввода данных служит передаточная функция, и необходимо для создания массивов экспериментальных точек. Поэтому программа требует, чтобы по крайней мере поле "шаг" было заполнено. Поле начальной частоты не заполняется (оно показано незаполненным, но начальная частота равна 0.0001 при вызове из окна АФХ и 0.01 при вызове из окна ЛАЧХ или ЛФЧХ).

Перед построением графика переходной функции вызывается окно задания диапазона моментов времени, действующее так же как окно задания диапазона частот для АФХ. Только в поле "от" указывается значение запаздывания t.

Окно "Частоты" вызывается также перед построением графиков ЛАЧХ или ЛФЧХ (для того из графиков, который строится первым). Рекомендуемые значения: "до" 100, "шаг" 2. Точки на графике не отмечаются.

Примечание.

Поскольку графики ЛАЧХ и ЛФЧХ строятся в логарифмическом масштабе, то и шаг изменения частот меняется по логарифмическому закону. А значение "шаг", которое задается пользователем, служит только для определения числа точек.

Программа NLINSYS

В одном из разделов этой программы ("Метод Гольдфарба") можно отметить ряд точек на АФХ и на кривой J(a).
