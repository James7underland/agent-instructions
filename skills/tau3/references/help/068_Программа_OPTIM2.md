# Программа OPTIM2

Программа OPTIM2

Оптимальное быстродействие

Несколько управляющих воздействий

«Задача быстродействия» состоит в нахождении ограниченного управления, которое переводит объект из начального состояния X° в состояние равновесия (начало координат) за наименьшее возможное время tрег (время регулирования).

В Главном окне приведена постановка задачи.

Примечания.

1. Каждый компонент векторного управления по модулю не превосходит M=1.

2. Порядок объекта не превышает 5.

Повторить счет

«Выход из программы»

Оптимальная траектория рассчитывается для заданных коэффициентов уравнений и начального состояния объекта. Пока эти параметры не изменились (даже если они были введены при предыдущем запуске) пересчета не происходит. Если нужно повторить счет, не меняя параметры, то это можно сделать, используя соответствующий пункт меню.
