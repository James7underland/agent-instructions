# Модели системы (WATT)

Модель системы (для программы WATT)

Эта часть программы содержит три страницы диаграмм, содержащих подвижные элементы.

На первой странице представлено две диаграммы: "Паровой двигатель" и "Центробежный измеритель скорости". Здесь можно менять положение заслонки или частоту вращения вала при помощи курсорных клавиш "направо" и "налево". Для простоты изменения происходят одновременно на обеих диаграммах.

На второй странице представлена диаграмма "Система регулирования двигатель – регулятор Уатта". Для имитации процесса регулирования нужно увеличить (уменьшить) нагрузку при помощи курсорных клавиш и нажать Enter.

На третьей странице приведены математические уравнения системы в форме, которую предложил Л.С. Понтрягин (см. его книгу "Обыкновенные дифференциальные уравнения", ФМ, М., 1961).

Страницы листаются при помощи клавиш PgDn, PgUp, конец просмотра - клавиша Esc.
