# Выбор аппроксимации

Выбор аппроксимации

Программа LINSYS2

Вы можете выбрать один из предлагаемых способов аппроксимации запаздывания в передаточной функции:

а) «аппроксимация Паде» порядка 1 - 4,

б) аппроксимация отрезком ряда Тейлора порядка 1 – 4 (многочлен добавляется в знаменатель передаточной функции объекта)

[рис. bm89]в) заменаЧтобы выбрать способ аппроксимации, нажмите нужную кнопку-переключатель, а затем кнопку OK.

Для всех графиков (кроме "Переходного процесса") можно сравнить точную кривую с кривой, получаемой при помощи выбранной аппроксимации.

Программа LINSYS3

Функции ch(z), z sh(z), I0(z) можно аппроксимировать, разлагая их в ряд

[рис. bm91]или в произведениегде z1, z2,    - корни функции f(z).Выберите вариант аппроксимации, щелкнув мышью в нужной позиции, и задайте порядок аппроксимации. Он равен числу сомножителей в произведении или числу ненулевых слагаемых ряда (свободный член в подсчет не входит).

Порядок можно задавать в пределах от 2 до 20, но фактически он будет меньше 20, так как порядок системы ограничен числом 20.

Нажмите кнопку OK, чтобы закрыть окно выбора.

Для всех графиков можно сравнить точную кривую с кривой, получаемой при помощи выбранной аппроксимации. Но пункт "Аппроксимация" действует только для тех передаточных функций, в определении которых участвуют упомянутые выше трансцендентные функции (см. раздел «Особые звенья»).

Примечания.

1. Коэффициенты разложения в ряд и корни функций взяты из "Справочника по специальным функциям с формулами, графиками и математическими таблицами" под ред. М. Абрамовица, М., Наука, 1979.

2. В качестве точного значения функции Бесселя I0(z) берется 40 членов ее разложения в ряд.
