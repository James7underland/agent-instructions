# Программа RTLZ

Программа RTLZ

Обратное преобразование Лапласа и обратное Z-преобразование

Программа предназначена:

1. для вычисления обратного преобразования Лапласа от дробно-рациональной передаточной функции,

2. для нахождения обратного Z-преобразования.
