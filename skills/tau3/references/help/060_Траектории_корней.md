# Траектории корней

Траектории корней

Траектории корней это линии, которые прочерчивают корни характеристического уравнения при изменении параметра K от 0 до бесконечности.

Программа запрашивает диапазон значений l и для каждого фиксированного значения l из этого диапазона вычисляет частоты w (при l = 0  это критические частоты), при которых вертикаль при l + j w пересекает траектории корней, и соответствующие этим частотам коэффициенты усиления K. Точки p = l + j w  (для w <100, не более 10 точек для каждого l) рисуются на комплексной плоскости.

Пересечения находятся при помощи построения «фазо-частотной характеристики» разомкнутой системы arg M(l + j w). Значения w, соответствующие arg M(l + j w) = -2k+1 (k = 1, 2,..), находятся сначала грубо (фазовая характеристика проходится с большим шагом), затем уточняются по методу секущих.

Если нажать мышью в точке, отмеченной на плоскости, то внизу окна появится соответствующее значение коэффициента K. Чтобы "выбрать" значение l этой точки, нажмите кнопку OK (кнопка выбора «значения»).

Из меню этого окна вызывается «таблица частот».
