# Задание передаточной функции

Задание передаточной функции

В программах ТАУ-3 принято три различных способа ввода числовых данных для проведения расчетов в зависимости от постановки задачи.

1. Главное окно программы содержит изображение структурной схемы САУ. Для каждого элемента схемы нужно передаточную функцию из числа предусмотренных в программе, а для выбранной функции - задать значения входящих в ее описание буквенных коэффициентов. Также нужно задать входные воздействия (они задаются как функции времени или, если это случайные воздействия, своими спектральными функциями). См. раздел «Формирование элементов схемы».

2. Передаточные функции звеньев структурной схемы – дробно-рациональные функции общего вида. Коэффициенты многочленов числителя и знаменателя (или корней этих многочленов) задаются в табличной форме. Этот способ описан в данном разделе.

3. Управляемая система описывается дифференциальными уравнениями в матричной форме, нужно ввести коэффициенты матриц. См. раздел «Ввод данных (матрицы)».

В окне задания передаточной функции две таблицы – для знаменателя и для числителя. Под каждой из таблиц расположена кнопка OK ("конец ввода").

В некоторых программах (LINSYS, OPTIM, IDENTF, RTLZ) в окне имеется изображение передаточной функции в виде отношения двух многочленов.

Меню этого окна

Ввод коэфф. многочлена

Ввод корней многочлена

«Вывод в файл / на принтер»

«Размер шрифта»

Закрыть

Передаточную функцию в виде таблиц можно задавать двумя способами, вводя либо коэффициенты многочленов, либо их корни. Выбор способа осуществляется через меню (выбранный способ отмечен в меню галочкой). В соответствии с этим выбором в таблице доступны для ввода либо коэффициенты, либо корни многочлена, но в любом случае нужно сначала задать порядок многочлена (в окне ввода в верхней части таблицы). Максимальный порядок многочлена зависит от программы (для LINSYS, OPTIM и IDENTF этот порядок равен 5, для RTLZ равен 20).

Чтобы активизировать поле ввода, щелкните по нему мышью.

После ввода данных нажмите кнопку OK ("конец ввода").

Каждая из таблиц содержит три группы данных: порядок, коэффициенты и корни многочленов. Нажатие кнопки "конец ввода" приводит эти данные в соответствие друг другу. Поэтому, если какие-то данные были изменены, то программа требует нажатия кнопки OK перед закрытием окна, перед выполнением любой команды меню, перед включением режима уточненного просмотра.

После нажатия этой кнопки вычисляются корни многочлена, если был установлен ввод коэффициентов, либо находится многочлен с заданными корнями, если был установлен ввод корней. В последнем случае многочлен нормируется таким образом, чтобы последний по старшинству ненулевой коэффициент был равен 1. При вводе данных в таблицу учитывается установленный порядок многочлена.

Примечание.

Чтобы очистить таблицу, нужно задать порядок многочлена 0 и нажать кнопку OK.

В окне есть кнопка для включения / выключения режима «Уточнение значений».

Отмена режима уточнения значений происходит при нажатии любой кнопке в окне или при вызове меню.

Правила заполнения таблиц

1. Пустое поле равносильно нулю.

2. Старший коэффициент многочлена не должен быть нулем.

3. Вместе с комплексным числом (корнем) в следующей строке должно быть введено комплексно-сопряженное число (строки должны отличаться только знаком мнимой части).

4. Числа в первых n строках таблицы корней (n – степень многочлена) образуют правильный набор. (Например, если задана степень многочлена 3, введены два вещественных корня, затем пара комплексно-сопряженных, то это ошибка.)

При нарушении пунктов 2 - 4 программа выдает сообщение об ошибке. Программа также сообщает об «ошибках ввода» чисел.

Программа ANACON

В этой программе числитель всегда равен 1, так что в окне задания передаточной функции только одна таблица с указанными выше свойствами – для знаменателя.

Но в окне помещается и вторая таблица – для ввода коэффициентов функционала p, q1, … , qn (n – порядок объекта). Программа требует, чтобы было введено p > 0.

Примечание.

Хотя для гарантированного получения решения нужно, чтобы числа q1, … , qn были неотрицательными, но это условие не является обязательным, и программа не следит за его выполнением.

Для активизации поля ввода щелкните мышью в соответствующей строке вектора. Гостехиздат"""""""""""""""""""""""""""""""""""

Программа OPTIM

В этой программе числитель всегда равен 1, так что в окне задания передаточной функции только одна таблица с указанными выше свойствами – для знаменателя.

Но в окне помещается и вторая таблица – для ввода коэффициента M и координат начального состояния объекта X°. Для активизации поля ввода щелкните мышью в соответствующей строке вектора. Появится текстовый курсор. По окончании ввода нажмите кнопку OK (конец ввода).

Программа IDENTF

В окне задания передаточной функции две таблицы – для знаменателя и для числителя. И имеется еще одна таблица для задания коэффициента K0 (это число должно быть положительным), запаздывания t и двух дисперсий: Dафх и Dпф или Dлах и Dлфх в зависимости от выбора задачи. Изменение этих параметров фиксируется кнопкой OK для числителя.

Дополнительные правила заполнения таблиц

5. Для идентификации по АФХ или переходной функции корни знаменателя не должны быть чисто мнимыми, а также не допускаются нулевые корни числителя и знаменателя.

6. Порядок числителя должен быть меньше порядка знаменателя, иначе программа дает сообщение: "Передаточная функция не реализуема".

В программе IDENTF есть еще два окна "Коррекция п. ф." и "Расчетная п. ф.", которые имеет вид, устройство и правила заполнения таблиц такие же, как окно "Задание п. ф." (в них нет только таблицы для ввода K0 и t).
