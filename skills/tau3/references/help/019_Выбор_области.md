# Выбор области

Выбор области на графике

Часть плоскости, видимую на графике, можно изменить, устанавливая значения координат по оси абсцисс (по горизонтали) и по оси ординат (по вертикали). Для ввода числа щелкните мышью в поле ввода - появится текстовый курсор. После ввода всех данных нажмите кнопку OK (конец ввода).

Размеры графика, установленные в окне "Выбор области", сохраняются до тех пор, пока это окно с графиком не будет закрыто.

Примечание.

График всегда разделен линиями на 5 равных частей по горизонтали и по вертикали. Координаты на линиях деления кратны 0.01. Если точка начала координат находится в пределах графика, то она лежит на пересечении этих линий.
