# Выбор функций для графика

Выбор функции для рисования на графике

При построении графиков "Процесс регулирования" и "Фазовый портрет" нужно выбрать одну или две функции времени (или одну-две координаты фазового состояния). Окончив выбор функций, нажмите кнопку OK.

Программы ASYMPT, CASCAD, CONTROL, IMPULS

На графике "Процесс регулирования" может строиться одна или две функции времени, первая из которых всегда y(t), а вторая выбирается из выпадающего списка. Чтобы выбрать функцию, нужно нажать (щелкнуть мышью) букву в списке. Если вторая функция не нужна, то укажите в списке букву y. В программе CASCAD кроме функций, обозначенных на схеме, в списке присутствуют еще функции n1 и n2 (последняя для системы 2). Эти функции замеряются на выходе нелинейных элементов N1 и N2 соответственно.

Программа MVACS2

На графике строятся две функции времени, которые выбираются из двух выпадающих списков. Кроме функций, показанных на схеме, в списках присутствуют функции e1 = f1 - y1 и e2 = f2 - y2.

Программы ANACON, OPTIM и OPTIM2

Для графика "Процесс управления" выбирается одна функция (фазовая координата) в программе OPTIM или две функции (фазовая координата и координата управления) в программах ANACON, OPTIM2.

Для графика "Фазовый портрет" нужно выбрать две разные координаты плоскости, на которую будет проектироваться фазовая траектория.

Координаты выбирается из выпадающих списков. Окончив выбор, нажмите кнопку OK.

Программа PHASPL

Здесь для графика "Процесс управления" нужно выбрать одну из двух функций  x1  или  x2,  а второй изображаемой функцией является управляющее воздействие  u.

Программа LINSYS2 и LINSYS3

Здесь одно или два окошка для выбора функций. В первом выбирается одна из функций y, u или e = f – y, а во втором – одна из функций f, g  и еще имеется пустая строка, при выборе которой вторая функция не рисуется.

Примечание.

Одно окно для выбора функции в программе LINSYS2, раздел "Переходный процесс".

Программа KALMAN

На графике может строиться одна или две функции времени. Эти функции – элементы векторов или матриц.

Примечание.

Могут быть выбраны функции: x - вектор состояния, y - вектор выхода, u - вектор управления, z - оценка состояния x, e = x - z - ошибка оценки состояния. Для стохастических систем на графике можно строить элементы матриц K и S (см. «Выбор задачи»).

Открывается окно, в котором две панели для ввода 1-й и 2-й функции. Под каждой панелью находятся две или три кнопки. Первая кнопка – для ввода буквы, вторая – для ввода первого индекса, третья - для ввода второго индекса (эта кнопка присутствует только для букв K и S).

Чтобы задать функцию, нужно установить в окошке ее имя (букву) и индекс(ы). Для этого нужно сначала указать при помощи кнопки-переключателя позицию, которую Вы хотели бы изменить. Изменение производится нажатием кнопок-стрелок "вверх" и "вниз". Окончив выбор функций, нажмите кнопку OK.

Примечание.

В целях экономии места в индексах вместо 10 пишется 0.

Если нужно, чтобы рисовалась одна функция, установите ее в обоих окошках.

Программы ANACON2 и ANACON3

Здесь способ выбора функций такой же, как в программе KALMAN, но для графика "Процесс управления" могут быть выбраны только функции x - вектор состояния, u - вектор управления, а для программы ANACON3 (задача 1) на графике можно строить также элементы матрицы R.

Если рисуется график "Фазовый портрет", то выбираются только координаты вектора состояния (это должны быть две разные координаты), первая кнопка под панелями выбора функции отсутствует.

Программа SPECTR

На графике "Процесс регулирования" может строиться одна или две функции времени, первая из которых всегда y(t), а вторая выбирается из выпадающего списка.

На графике "Спектральные функции" строятся две спектральные функции. Если в программе предусмотрен показ более чем двух функций, то выбор одной из них фиксирован, а другая выбирается из открывающегося списка (фиксированная функция – первая в этом списке).

Программа WATT

На графике "Процесс регулирования" в режиме "Линеаризованная система" выбирается только одна функция, второй рисуется линеаризованный процесс. В противном случае может строиться одна или две функции времени.

Для графика "Фазовый портрет" нужно выбрать две координаты (из трех координат x1, x2, x3), определяющие проекцию фазовой кривой. Это должны быть две разные координаты.
