# Критерий Найквиста

Критерий Найквиста

На комплексной плоскости строится кривая Найквиста - ветвь амплитудно-фазовой характеристики (АФХ) разомкнутой системы для w > 0.

Перед тем, как построить график, программа запрашивает значения буквенных параметров, «диапазон частот», которые нужно отметить на кривой, затем (только в программах CONTROL и CASCAD) предлагает выбрать, в какой точке «разомкнуть систему».

На осях графика откладываются значения A(w)= Re M(jw) и B(w)= Im M(jw), где M - передаточная функция разомкнутой системы.

Примечания.

1. Кривая строится с постоянным шагом по параметру ln w  в диапазоне частот от 0.0001 до 10000.

2. Для этого графика всегда устанавливается одинаковый масштаб по осям.

В программах CONTROL и CASCAD

на этом же графике может быть построена модифицированная АФХ для исследования нелинейной системы по критерию В.-М. Попова: на осях откладываются значения A(w) и wB(w).

Кривая строится по соответствующей команде меню. Повторный вызов команды отменяет рисование этой кривой.

В «таблице», вызываемой из этого окна, приводятся данные (коэффициенты передаточных функций и их корни) для разомкнутой системы.

В этих же программах CONTROL и CASCAD возле окна "Критерий Найквиста", имеется кнопка, включающая (и выключающая) полукруг с делениями для измерения запаса по фаз

«»

Если используется метод пересчета переходной функции в АФХ, то расчетные точки также выводятся на графике.

В меню окна имеется пункт "Сравнение", при вызове которого рисуется график АФХ для передаточной функции, которая приведена в окне "Идентификация" (или "Коррекция п. ф."). Повторный вызов команды отменяет рисование этой кривой.

При вызове пункта меню "Повторить" программа спрашивает:

Отмечать частоты на АФХ?         Да     Нет

При ответе "Нет" точки, по которым построена АФХ, рисоваться не будут.

В программе IMPULS

меню содержит пункт "Найквист-2". На одном графике с кривой Найквиста строится приближенная АФХ, вычисляемая на основе представления z-передаточной функции разомкнутой системы в виде ряда (см. раздел «Импульсная система»). Требуется задать число N (при этом будет вычисляться 2N+1 слагаемых ряда). Повторный вызов команды отменяет рисование этой кривой.

В программе IMPULS данные в таблицах приведены для z-передаточной функции объекта.

В программе LINSYS2

из меню окна вызывается «таблица частот».

В программе LINSYS3,

если задан диапазон частот, то рисуется только часть кривой Найквиста между начальной и конечной частотами.

В программе MVACS2

В случае автономности программа запрашивает номер сепаратной системы.

На графике строится кривая Найквиста формальной односвязной САУ, передаточная функция которой W(p)=B(p)/A(p) выбрана таким образом, чтобы ее характеристическое уравнение совпадало с характеристическим уравнением исследуемой двусвязной САУ:

[рис. bm11]В таблице, вызываемой из этого окна, приводятся коэффициенты характеристического уравнения замкнутой системы (или сепаратной подсистемы).В программе QPOLстроится кривая Найквиста формальной САУ, передаточная функция которой W(p)=B(p)/A(p) выбрана таким образом, чтобы ее характеристическое уравнение имело вид квазиполинома, приведенного выше.В меню окна есть пункт "Аппроксимация Паде". При нажатии этого пункта на графике для сравнения строится та же кривая, но вычисленная с использованием аппроксимации. Этот пункт не действует, если нет запаздывания.

При повторном нажатии этого пункта меню рисование кривой сравнения отменяется.
