# Программа ASYMPT

Программа ASYMPT

Асимптотические свойства линейных систем

Программа предназначена для исследования асимптотических свойств САР при неограниченном увеличении коэффициента усиления. Структурная схема САР для выбранного варианта задачи изображена в Главном окне. На схеме:

W0, W1, W2, W3 – звенья объекта,

R0, R1, R2, R3 – звенья регулятора,

H1, H2, H3 – обратные связи,

f – задающее воздействие,

y – выходной сигнал,

y° – выходной сигнал вырожденной системы.

В отдельном окне (или в том же окне для схемы 1) показана вырожденная система, в которую переходит исходная система при неограниченном увеличении параметра L.

Звено W0 может иметь запаздывание, которое во всех вычислениях заменяется «аппроксимацией Паде».

В программе есть два буквенных параметра: K  - коэффициент усиления регулятора R0, и L – параметр, который специальным образом входит в коэффициенты регуляторов R1, R2, R3.

Выбор системы

Пользователю предлагается на выбор 4 структурные схемы объектов возрастающей сложности. Чтобы выбрать объект для исследования, нужно нажать мышью кнопку нужного варианта или щелкнуть по схеме. Затем нужно закрыть окно выбора системы.

В дальнейшем на экране рисуется схема замкнутой системы, соответствующей выбранному объекту, а также схема вырожденной системы.
