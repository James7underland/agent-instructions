# Программа ANACON3

Программа ANACON3

Аналитическое конструирование регуляторов

Конечное время регулирования

Программа решает «линейно-квадратичную задачу оптимизации» на конечном интервале времени, постановка которой приведена в Главном окне программы.

Задача решается в двух вариантах:

Задача 1. Свободный правый конец траектории.

Решается по методу Калмана.

Задача 2. Приведение в начало координат.

Решение основано на принципе максимума.
