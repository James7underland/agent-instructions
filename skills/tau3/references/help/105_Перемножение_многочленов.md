# Перемножение многочленов

Программа MULPOL

Перемножение многочленов

Сервисная программа, предназначенная для перемножения многочленов.

Главное меню программы:

Ввод коэффициентов многочленов

«Настройка параметров счета»

«Выход из программы»

Ввод коэффициентов многочленов

В окне ввода коэффициентов имеется таблица, в двух столбцы которой нужно вписать порядки и коэффициенты многочленов A и B. Сначала нужно задать порядок многочлена, так как это определяет, сколько полей будет доступно для ввода. Коэффициенты вводятся, начиная со старших степеней.

Чтобы активизировать поле ввода, щелкните по нему мышью. После занесения данных нажмите кнопку со знаком умножения справа от таблицы. Будут выданы порядок и коэффициенты многочлена X = AB.

Программа сообщает об «ошибках ввода» чисел. Умножение не производится, если порядок многочлена X получается > 20.

При нажатии кнопки умножения проверяется ввод данных (в частности, приводятся в соответствие заданный порядок и число введенных коэффициентов). Поэтому, если какие-то данные были изменены, то программа требует нажатия кнопки умножения перед закрытием окна, перед выполнением любой команды меню, перед нажатием любой другой кнопки, перед включением режима уточненного просмотра.

В окне есть кнопка для включения / выключения режима «Уточнение значений».

Отмена режима уточнения значений происходит при нажатии любой кнопке в окне или при вызове меню.

Справа от таблицы имеются еще четыре кнопки с надписями: "0 ® A", "0 ® B", "X ® A", "X ® B". Они служат соответственно для очистки (обнуления) многочленов A и B или для занесения многочлена X в A или в B (для многократного умножения). Перед выполнением действия программа запрашивает неустойчивого"""

Внимание! Пустое поле ввода равносильно нулю.
