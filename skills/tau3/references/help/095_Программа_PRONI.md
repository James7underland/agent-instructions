Программа PRONI

Аппроксимация по методу Прони

Небольшая сервисная программа для аппроксимации функций, заданных в табличной форме.

Метод Прони

Функция, которую нужно аппроксимировать, вводится из файла proni.dat. Строки этого файла содержат пары координат t и R(t), разделенные пробелом, числа t неотрицательные и идут в порядке возрастания, всего не более 50 пар чисел. Первая пара чисел обязательно должна быть 0 0. Программа выдает сообщение, если нет этого файла.

По заданным точкам на графике проводится гладкая кривая.

Программа запрашивает число точек, которое должно быть четным и (в этой программе) не больше 12. Эти точки равномерно располагаются на заданном интервале значений t, а значения функции снимаются со сглаженной кривой. По методу Прони рассчитывается аппроксим

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

В меню окна-графика есть пункт «Аналитическая формула».

Метод Прони описан в книге Я.С. Безиковича "Приближенные вычисления", М.-Л., Гостехиздат, 1949.

Примечания.

1. Метод Прони может использоваться для нахождения аналитического выражения для корреляционных функций или для временных переходных процессов.

2. Метод хорошо восстанавливает таблично заданную функцию только при условиях:

а) исходные данные достаточно точны,

б) правильно указано число точек (оно должно быть равно числу слагаемых функции, которую требуется восстановить).

Задание графика функции

Функцию R(t) можно ввести из файла (если такой файл имеется) или построить на графике.

График начинается всегда в начале координат (эта точку указывать не нужно, она порождается автоматически).

Чтобы отметить на графике новую точку кривой, нужно щелкнуть в этом месте мышью. Каждая следующая точка рисуется правее предыдущей точки и соединяется с ней отрезком. Точку 0 0 указывать не нужно, она порождается автоматически.

Последнее звено кривой можно удалить, нажав на концевую точку.

Если линия введена из файла, ее также можно редактировать, как указано выше.

Чтобы записать вновь построенную или измененную кривую в файл, нужно использовать пункт меню "Записать в файл". Кривая сохраняется в файле proni.dat (см. выше).

Если функция изменена, но не запомнена, то она используется при построении графика "Метод Прони", но при повторном вызове из файла будет загружена предыдущая функция.
