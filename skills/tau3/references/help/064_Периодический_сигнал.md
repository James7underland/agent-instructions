# Периодический сигнал

Периодический сигнал

В этой части программы «LINSYS» изучается прохождение периодического сигнала через линейную систему.

Выбор входного воздействия

С помощью полосы прокрутки в окне "Выбор воздействия", выберите одну из периодических функций. Ранее выбранная функция при прокрутке отмечена надписью "Вариант выбран".

В окошках ввода задайте значения амплитуды A и периода T функции входа.

Примечания.

1. Амплитуда и период общие для всех входных воздействий.

2. Эти значения не могут быть нулевыми (сообщение об ошибке выдается при рисовании графиков).

3. Программа сообщает об «ошибках ввода» чисел.

Для фиксации выбора функции нажмите кнопку OK (кнопка выбора) внизу окна.

Ряд Фурье входа

На графике строится входное воздействие f(t) и отрезок его разложения в ряд Фурье fn(t). Число членов разложения n (от 1 до 99) программа запрашивает.

Установившийся процесс

На графике строится реакция системы на входное воздействие в виде отрезка ряда Фурье (программа запрашивает число членов ряда) в установившемся режиме.

Для случая замкнутой системы запрашивается также значение коэффициента K.
