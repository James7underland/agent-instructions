# Критерий Рауса

Критерий Рауса

Программа запрашивает диапазоны изменения величин A, B (начальное значение, конечное значение и шаг изменения параметра). Для каждого варианта значений A, B из заданных диапазонов (но не более чем для 20-ти значений по каждой из величин) находится число неустойчивых корней по методу Рауса. Результаты записываются в таблицу, которую можно записать в файл (с именем программы и расширением tab) или распечатать на принтере.

Прочерк в таблице означает отсутствие данных (метод не дает результата).

Для импульсной системы, чтобы применить к многочлену от z метод Рауса, этот многочлен подвергается преобразованию z = (p+1)/(p-1), которое переводит правую полуплоскость в единичный круг.

Если указать клетку в таблице мышью, то внизу окна появятся значения A и B, для которых число корней в этой клетке было получено. Чтобы выбрать эти значения, нажмите кнопку OK («кнопку выбора значения»).

Это окно не принадлежит к окнам-графикам, но имеет с ними много общего.
