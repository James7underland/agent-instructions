# Размеры задачи

Размеры задачи

Для программ ANACON2, ANACON3, KALMAN, OPTIM2.

Программа запрашивает размеры двух или (для KALMAN) трех векторов: вектора состояния  x  ([x]=n),  вектора управления  u  ([u]=r)  и (для KALMAN) вектора выхода  y  ([y]=m).  Размеры остальных векторов и матриц определяются этими тремя: матрица  A  имеет размеры  nxn,  B  - размеры  nxr,  C  - размеры  mxn, и т.д. Ограничения:  n  не больше 10,  r  и  m  не больше  n. Для ANACON3 число n не больше 5. Для OPTIM2 число n не больше 5 и не меньше 2, r < n.

Размеры нужно ввести в окошках и нажать кнопку OK.

Примечания.

1. Если выставить недопустимые значения размеров, то программа заменит эти значения, и панель ввода не закроется при нажатии OK.

2 Если используются данные предыдущего счета, то размеры не запрашиваются, а берутся из файла vrt.

2. Размер вектора обычно обозначают [ ], например, [x] это размер вектора x.

Установленные размеры задачи не меняются до конца работы программы.
