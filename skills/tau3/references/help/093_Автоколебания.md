# Автоколебания

Автоколебания

В этом разделе рассмотрены две темы.

Метод Л.С. Гольдфарба

Строятся графики, показывающие использование метода Л.С. Гольдфарба (метод гармонического баланса).

Для этих графиков используется то же окно, что для графиков-критериев (в том числе и для критерия Найквиста).

Перед тем, как построить графики, программа запрашивает значения буквенных параметров, которые нужно отметить на кривых. Это «диапазон частот» w и диапазон параметра a, о котором будет сказано ниже.

Диапазон параметров используется для того, чтобы, нажав на точку курсором мыши, определить значение соответствующего ей параметров. Но в данном случае есть более простой способ определения параметров на кривых, о котором также будет сказано ниже.

Первая кривая, которая рисуется на комплексной плоскости, это кривая Найквиста - ветвь амплитудно-фазовой характеристики (АФХ) разомкнутой системы для w > 0 (см. «Критерий Найквиста»). На осях графика откладываются значения A(w) = Re W(jw) и B(w) = Im W(jw), где W - передаточная функция объекта.

Вторая кривая на комплексной плоскости это J(a) = –1/ Wн(a), где Wн(a) = q(a) + j q’(a) - коэффициент гармонической линеаризации нелинейной характеристики.

Описание метода определения автоколебаний и таблицу функций q(a) и q’(a) для основных нелинейностей см. в книге "Сборник задач по теории автоматического регулирования и управления" под ред. В.А. Бесекерского, М., Наука, 1978.

Примечание.

Для двух нелинейностей, рассматриваемых в программе, коэффициент гармонической линеаризации в книге не приводится.

Пересечение двух этих кривых на плоскости определяет параметры a и w автоколебаний (a - амплитуда, w - частота), которые устанавливаются в системе

[рис. bm123]Точку пересечения кривых можно определить при помощи курсора, но только в том случае, если диапазоны точек на кривых не заданы (окошки ввода значений параметров оставлены пустыми). Если навести курсор на одну из кривых, то появится панель с соответствующим значением параметра. Там, где кривые пересекаются, показываются параметры точки пересечения. Панель можно двигать, держа за уголок мышью.

Для однозначных нелинейных характеристик q’(a) = 0, поэтому линия J(a) - горизонтальная прямая. Но эта прямая может состоять из двух ветвей. В этом случае курсор покажет на прямой два значения параметра, что означает наличие двух режимов автоколебаний с одинаковой частотой и разной амплитудой (один из этих режим может отвечать неустойчивым колебаниям).

Примечания.

1. Для более точного попадания в точку на кривой лучше пользоваться не только курсором мыши, но и курсорными клавишами.

2. Точки кривых на графиках стоятся с определенным шагом (который в любом случае не может быть меньше точки на дисплее), курсор определяет координаты тоже неточно. Это ограничивает точность результатов расчета.

В меню окна имеется пункт для вызова графика «Нелинейный элемент».

Критерий В.А. Якубовича

На экран вводятся окна «Процесс регулирования», "Нелинейный элемент", и "Критерий автоколебательности". Последнее окно содержит рисунок, поясняющий условия возникновения автоколебаний. На статической характеристике нелинейного элемента выделяются два сектора: сектор абсолютной устойчивости и сектор абсолютной неустойчивости, которые определяются свойствами линейного элемента. Между этим секторами лежит зона автоколебаний. На рисунке b - нижняя граница амплитуды колебаний.
