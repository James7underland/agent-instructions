# Выбор варианта задачи (MVACS)

Выбор варианта задачи (для программы MVACS)

Структурную схему системы регулирования можно модифицировать, выбирая нужный вариант в каждой из трех пар альтернативных возможностей:

Объект с прямыми связямиОбъект с обратными связями

 | 

Непрерывное управлениеИмпульсное управление

 | 

Автономное управлениеНеавтономное управление

 | 

На панели выбора варианта задачи имеется переключатель "Режим проверки робастности", который можно установить только для случая автономного управления.

Чтобы выбрать задачу, нужно отметить нужные пункты (щелкнув мышью) и затем нажать

кнопку OK.

Выбранный вариант указывается буквами в правом нижнем углу схемы: S - прямые связи, R - обратные, C - непрерывное управление, I - импульсное, A - автономность, ! – режим проверки робастности.

Примечание.

Вариант "Импульсное управление и обратные связи" в программе не рассмотрен.

Режим проверки робастности

Режим проверки робастности устанавливается только для автономных систем и указывается знаком ! в углу схемы.

Если режим проверки робастности не установлен, то компенсирующие звенья определяются программой по формулам:

[рис. bm101]для прямых идля обратных связей.Для импульсных систем функции W(p) заменяются преобразованными функциями

[рис. bm104]Компенсирующие звенья пересчитываются каждый раз при изменении параметров системы.В режиме проверки робастности изменение параметров регуляторов (и периода квантования для импульсных систем) блокировано, а передаточные функции Q не пересчитываются при изменении передаточных функций объекта.Для случая прямых связей пользователь может задать новые передаточные функции Q или отменить задание этих функций (в последнем случае они заново пересчитываются программой).

Примечания.

1. Вычисление компенсирующих звеньев происходит при построении одного из графиков.

2. После изменения выбора задачи компенсирующие звенья заново вычисляются программой, даже если установлен режим проверки робастности.

3. При вводе передаточных функций Q буквенные параметры не используются.
