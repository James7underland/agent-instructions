# Ввод данных (матрицы)

Ввод данных (матрицы)

В программах ТАУ-3 принято три различных способа ввода числовых данных для проведения расчетов в зависимости от постановки задачи.

1. Главное окно программы содержит изображение структурной схемы САУ. Для каждого элемента схемы нужно передаточную функцию из числа предусмотренных в программе, а для выбранной функции - задать значения входящих в ее описание буквенных коэффициентов. Также нужно задать входные воздействия (они задаются как функции времени или, если это случайные воздействия, своими спектральными функциями). См. раздел «Формирование элементов схемы».

2. Передаточные функции звеньев структурной схемы – дробно-рациональные функции общего вида. Коэффициенты многочленов числителя и знаменателя (или корней этих многочленов) задаются в табличной форме. См. раздел «Задание передаточной функции».

3. Управляемая система описывается дифференциальными уравнениями в матричной форме, нужно ввести коэффициенты матриц. Этот способ описан в данном разделе.

При вызове пункта меню "Ввод данных" сначала появляется окно «Настройка параметров счета»,затем (после того как задан параметр "точность счета" и окно настройки закрыто) открывается окно, состоящее из трех секций:

- указание, элементы какой матрицы вводятся,

- поля для ввода элементов матрицы (или коэффициентов многочлена),

- пояснения (по поводу вводимых данных).

Чтобы ввести число, нужно щелкнуть мышью в поле ввода. Появится текстовый курсор.

Внимание! Отсутствие значения параметра равносильно нулевому значению.

Программа выявляет «ошибки ввода» данных.

В окне имеются кнопки Вперед и Назад, при помощи которых производится прокрутка вводимых параметров. Кнопка Конец закрывает окно ввода данных.

Программы ANACON2, ANACON3

Вводятся элементы матриц A, B, Q,P (для двух последних только элементы главной диагонали).

Для ANACON3 вводятся также элементы главной диагонали матрицы V (для задачи 1) и задается время регулирования T (положительное число).

Программа OPTIM2

Вводятся элементы матриц A, B и вектора X°.

Программа KALMAN

Параметры задачи, которые нужно ввести, зависят от «Выбора задачи».

Примечания.

1. Для диагональных матриц Q, P, W, и V вводятся только элементы главной диагонали.

2. Для матриц R и K задаются коэффициенты их характеристических многочленов. Старший коэффициент не вводится, он всегда равен 1.

3. Матрица D используется в режиме проверки чувствительности (см. раздел «Варианты счета»).
