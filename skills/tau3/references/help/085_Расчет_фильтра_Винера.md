# Расчет фильтра Винера

Расчет фильтра Винера

В окне приведены формулы (см. ниже), по которым рассчитывается фильтр Винера (метод Боде-Шеннона).

Описание метода см. в кн. Я.Н. Ройтенберг "Автоматическое управление", М., Наука, 1978, §26.

Приведен результат вычисления дисперсии ошибки. Если дисперсия бесконечна, или если программа не смогла ее вычислить, пишется  D = ?

Для продолжения программы закройте окно "Расчет фильтра".

Формулы для расчета

[рис. bm119]Примечания.1. Для получения функций в первых трех строках делается замена jw = p.2. Нахождение передаточная функция j(p) называется факторизацией. Корни числителя и знаменателя этой функции являются устойчивыми корнями соответственно числителя и знаменателя функции в левой части первой строки формул.3. Во второй строке формул левая часть представлена в виде суммы двух дробно-рациональных функций. Знаменатель первого слагаемого K+(p) имеет только устойчивые корни, а знаменатель второго K-(p) – только неустойчивые.

Интегралы от спектральных функций вычисляются по программе из книги К.Ю. Острема "Введение в стохастическую теорию управления", М., Мир, 1973.
