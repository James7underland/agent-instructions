# ЛАЧХ, ЛФЧХ

ЛАЧХ, ЛФЧХ

Амплитудно-частотная и фазо-частотная хактеристики могут строиться как на общем графике, так и на двух разных графиках. По оси абсцисс графики рисуются в логарифмическом масштабе. В меню этих графиков нет пункта "Выбор области". Вместо этого имеется пункт "Размер клетки", который в какой-то мере заменяет изменение масштаба по оси ординат.

Метод построения «фазо-частотной характеристики» разомкнутой системы j(w) = arg M(jw) описан в отдельном пункте.

Если кривые строятся на общем графике, то слева от графика находятся две пары кнопок-стрелок для сдвига кривых вправо-влево и вверх-вниз (в последнем случае сдвигается только кривая ЛФЧХ в пределах от -360° до +360°, каждое нажатие кнопки сдвигает график на 90°).

Программы CONTROL, CASCAD, LINSYS, NLINSYS

На одном графике строятся логарифмические амплитудно-частотная и фазо-частотная характеристики разомкнутой системы: 20 log |M(jw)|  и  j(w) = arg M(jw). Соответственно по оси ординат имеются две шкалы.

Если указать точку на графике (при этом появляется крестик-курсор), то под графиком обозначаются координаты j, w  и 20 log |M|. В некоторых случаях удобно видеть значение |M|. Если нажать курсором строку координат, то значение |M| появляется в рамочке. Повторное нажатие убирает рамочку. Указанные действия работают во всех программах, где строится кривая ЛАЧХ.

Перед тем, как построить графики, программа запрашивает значения буквенных параметров, затем (только в программах CONTROL и CASCAD) предлагает выбрать, в какой точке «разомкнуть систему».

Из меню окна можно вызвать на просмотр две таблицы: «таблицу» коэффициентов и корней передаточных функций для разомкнутой системы, «таблицу» критических частот и частот среза (последняя таблица считается не для всех программ).

Программа MVACS2

В случае автономности программа запрашивает номер сепаратной системы.

На графике строятся кривые ЛАХ формальной односвязной САУ, передаточная функция которой W(p)=B(p)/A(p) выбрана таким образом, чтобы ее характеристическое уравнение совпадало с характеристическим уравнением исследуемой двусвязной САУ:

[рис. bm12]В таблице, вызываемой из этого окна, приводятся коэффициенты характеристического уравнения замкнутой системы (или сепаратной подсистемы).В программе QPOLстроятся логарифмические характеристики формальной САУ, передаточная функция которой W(p)=B(p)/A(p) выбрана таким образом, чтобы ее характеристическое уравнение имело вид квазиполинома, приведенного выше.Программа LINSYS2 и LINSYS3Здесь графики ЛАЧХ и ЛФЧХ строятся в отдельных окнах.

Сбоку графика ЛАЧХ находятся кнопки-стрелки, которые сдвигают кривую по горизонтали.

Сбоку графика ЛФЧХ находятся две пары кнопок-стрелок, которые сдвигают кривые по вертикали и по горизонтали. Горизонтальный сдвиг происходит за счет изменения масштабного множителя M, который принимает значения 0.01, 0.1, 1, 10, 100.

Программа IDENTF

графики ЛАЧХ и ЛФЧХ строятся в отдельных окнах либо по точкам из файла logam.dat, либо на основании заданной передаточной функции. В последнем случае программа запрашивает (один раз) конечное значение и шаг изменения частот (см. «Диапазон частот») для создания массивов точек, по которым будет проводиться идентификация.

Сбоку графиков находятся кнопки-стрелки, которые сдвигают кривые по вертикали и по горизонтали, как описано выше.

В меню окон имеется пункт "Сравнение", при вызове которого рисуется график ЛАЧХ или ЛФЧХ для передаточной функции, которая приведена в окне "Расчетная п. ф.". Повторный вызов команды отменяет рисование этой кривой.

В меню окна "График ЛАЧХ" имеется пункт «Проведение прямых».
