# Процесс регулирования

Процесс регулирования

Этот график в некоторых программах может иметь другое название: "Процесс управления", "Весовая функция", "Переходная функция", "Переходный процесс" и др.

На графике "Процесс регулирования" может строиться одна или две функции времени.

Эти функции получаются при помощи численного интегрирования дифференциальных уравнений системы (по методу Рунге-Кутта). Если в системе есть запаздывания, то предыдущие значения запоминаются в буферах - накопителях. Если применяется другая схема счета, то это специально оговаривается.

Если запоминаемые данные не помещаются в буфере, выдается сообщение «Запаздывание велико для выбранного масштаба».

Время регулирования для устойчивой линейной системы оценивается по корням характеристического уравнения. В случае необходимости процесс можно «продолжить».

Перед тем, как построить график, программа запрашивает значения буквенных параметров, а затем предлагает «выбать функции» для рисования на графике.

Программа ANACON

Программа запрашивает «начальное состояние объекта».

На графике рисуются две кривые, каждая из которых может быть либо координатой оптимальной траектории, либо управлением.

До начала рисования графика программа рассчитывает матрицу регулятора R, если она не была найдена раньше. Программа предлагает выбрать метод счета: по Калману или по Летову.

В случае счета по Калману внизу окна-графика показано оптимальное значение функционала J.

Программа ANACON2, ANACON3

На графике "Процесс управления" рисуются две кривые, каждая из которых может быть координатой либо оптимальной траектории, либо оптимального управления.

До начала рисования графика программа проводит необходимые проверки и рассчитывает матрицу регулятора R, если она не была найдена раньше.

Внизу окна показано оптимальное значение функционала J.

Программа ASYMPT

В части программы "Исследование системы" строятся три графика: "Весовая функция" (реакция системы на d-функцию), "Переходная функция" (реакция системы на единичный скачок) и "Процесс регулирования" (реакция системы на входное воздействие f(t) = 1- exp(-at) ). На графике рисуются функция y(t) и одна из функций u(t) и y°(t) (выход для вырожденной системы) по выбору (см. «Выбор функций для графика»). Функции рассчитываются через обратное преобразование Лапласа, приводятся их аналитические выражения, которые можно увидеть по команде меню "«Аналитич. формулы»".

Примечания.

1. Графики не строятся, если исходная система неустойчива, о чем выдается предупреждение.

2. При построении весовой функции для системы, у которой порядок числителя равен порядку знаменателя, наличие у решения составляющей d-функции игнорируется.

Программа IDENTF

график переходной функции (реакция системы на единичный скачок) строится либо по точкам из файла transf.dat, либо по точкам, вычисленным на основании заданной передаточной функции. В последнем случае программа запрашивает конечное значение и шаг изменения времени (см. «Диапазон частот»). Эти точки рисуются на графике и соединяются плавной кривой.

В меню окна имеется пункт "Сравнение", при вызове которого рисуется график переходной функции для передаточной функции, которая приведена в окне "Идентификация" (или "Коррекция п. ф."). Повторный вызов команды отменяет рисование этой кривой.

При вызове пункта меню "Повторить" программа спрашивает:

Отмечать точки на кривой?         Да     Нет

При ответе "Нет" точки, по которым построена переходная функция, рисоваться не будут.

В меню имеется также пункт "«Аналитич. формула»".

В программе IMPULS есть пункт меню "Проверка z-пр.", который служит для проверки правильности выполнения z-преобразования. Для z-структурной схемы САР выполняется обратное z-преобразование, и значения выходного сигнала в моменты времени кратные периоду квантования T определяются с использованием получающегося разностного уравнения. Значения наносятся на график.

Повторный вызов команды отменяет рисование точек "Проверка z-преобразования".

Программы LINSYS2 и LINSYS3

На графике "Процесс регулирования" может строиться одна или две функции времени, которые выбираются из открывающегося списка.

В программе LINSYS3 функции y(t), u(t) вычисляются как свертки входных воздействий с весовыми функциями. Последние находятся при помощи обратного преобразования Фурье от амплитудно-частотных характеристик замкнутой системы. Расчет не может быть проведен, если передаточная функция замкнутой системы имеет чисто мнимые корни. Во всех расчетах используется численное интегрирование (точность невысока). Результат будет верным только для устойчивой системы. См. раздел «Процесс регулирования в программе Linsys3».

Примечание (к программе LINSYS3).

В связи с особенностями вычислений процесс может начинаться только с t=0.

Позже на графике может быть построена еще одна кривая, одноименная первой выбранной функции, но полученная при помощи аппроксимации (см. раздел «Выбор аппроксимации»).

В программе LINSYS2 может быть построен также график "Переходный процесс" (см. ниже).

Программа MVACS2

Для системы с разомкнутыми генеральными обратными связями этот раздел называется "Переходный процесс".

Программа OPTIM

На графике "Процесс управления" рисуются две кривые. Одна из них - выбранная координата оптимальной траектории, другая – оптимальное управление.

Кривые рисуются для установленных в программе значений параметров (это либо те значения, которые были введены в окне "Задание параметров объекта", либо тот набор параметров, который установлен в окне "«Зависимость...»" при помощи кнопки "выбор значения").

В меню окна "Процесс управления" нет пункта "Продолжить", но есть пункты "Дополнить" и "Сравнение с САУ".

При вызове пункта "Дополнить" снова вызывается панель выбора функции, и на графике (поверх уже имеющегося изображения) рисуется кривая, представляющая другую выбранную координату. На оси ординат обозначается последняя из нарисованных функций.

Примечание.

При любой перерисовке графика на нем остается только последняя из нарисованных функций (и оптимальное управление).

При нажатии пункта "Сравнение с САУ" на графике (пунктиром) строится еще одна пара кривых – траектория и управление замкнутой системы автоматического управления, регулятор для которой выбран в части программы "Задание регулятора".

Предварительно программа запрашивает время регулирования для САУ. При открытии панели ввода в окошке указано оптимальное время t рег, но можно указать и другое время. Затем нажмите кнопку OK.

При повторном нажатии пункта меню "Сравнение с САУ" рисование кривой сравнения отменяется.

Программа OPTIM2

На графике "Процесс управления" рисуются две кривые: выбранные координаты оптимальной траектории и оптимального управления.

В меню окна есть пункт "Дополнить", действие которого описано выше для программы OPTIM.

Программа QPOL

На графике "Переходный процесс" рисуется функция y(t) – выход замкнутой системы.

Функция рассчитывается через обратное преобразование Лапласа по найденным корням квазиполинома (программа запрашивает число корней N, которые нужно использовать, при N=0 будут использованы все найденные корни), приводится ее аналитическое выражение, которые можно увидеть по команде меню "«Аналитич. формулы»". 

В меню окна есть пункт "Аппроксимация Паде". При нажатии этого пункта на графике для сравнения строится та же функция, но вычисленная с использованием аппроксимации. Этот пункт не действует, если нет запаздывания.

При повторном нажатии этого пункта меню рисование кривой сравнения отменяется.

Программа PHASPL

Если в передаточной функции объекта есть запаздывание, то на графике указаны моменты переключения.

Программа RTLZ

В этой программе график строится в задаче "Обратное преобразов. Лапласа" и в задаче "Обратное Z-преобразов.".

1. На графике "Обратное преобразов. Лапласа" рисуется функция y(t). Функция рассчитывается через обратное преобразование Лапласа.

В меню этого окна-графика есть пункт "Z-преобразование", который может служить для проверки пункта Главного меню «Z-преобразование».

Программа запрашивает период квантования T и запаздывание t и отмечает на графике точки, полученные с использованием Z-преобразования передаточной функции. Значения T и t можно изменить, вызвав пункт меню "Повторить".

Повторный вызов команды "Z-преобразование" отменяет рисование этих точек (и отменяет задание запаздывания).

2. На графике "Обратное Z-преобразов." рисуется функция y[n] (в виде дискретных точек). Ординаты точек рассчитываются по рекуррентной формуле, которая получается из дробно-рациональной функции Z-преобразования.

В меню этого окна-графика есть пункт "Расчет по формуле". На этом графике точки y[n] рассчитываются по формуле обратного Z-преобразования, и служат для проверки этой формулы.

Повторный вызов команды " Расчет по формуле" отменяет рисование этих точек (и отменяет задание запаздывания).

Программа WATT

На графике может строиться также кривая, соответствующая линеаризованному процессу.

Переходный процесс в программе LINSYS2

Исследуется реакция системы на единичный скачок. Вне зависимости от выбора функций времени при «формированиии элементов схемы» здесь полагается  f(t) = 1  и  g(t) = 0.

Примечание.

При выходе из раздела "Переходный процесс" установленные ранее значения f(t), g(t) восстанавливаются.

На графике строится одна из функций y(t) - переходная функция, u(t) или e(t) = f(t)-y(t), которая выбирается из открывающегося списка. На графике показана также функция f(t)=1.

Основная кривая для переходного процесса строится так же, как для "процесса регулирования" (и в том же окне). По команде меню "Процесс-2" на графике эта функция строится еще раз, но по аналитическим формулам, которые получены при помощи обратного преобразования Лапласа по найденным «корням квазиполинома».

Примечание.

Случай кратных корней в этой программе не предусмотрен.

Повторный вызов команды меню отменяет рисование дополнительной кривой.

Имеется возможность увидеть аналитические выражения для функций y(t) (без учета запаздывания) и u(t). Таблица вызывается по команде меню "«Аналитич. формулы»".

Процесс управления в программе KALMAN

До начала рисования графика программа проводит необходимые проверки, рассчитывает недостающие данные.

На графике может строиться одна или две функции времени. Эти функции – элементы векторов или матриц.

Примечание.

x - вектор состояния, y - вектор выхода, u - вектор управления, z - оценка состояния x, e = x - z - ошибка оценки состояния. Для стохастических систем на графике можно строить элементы матриц K и S (см. «Выбор задачи»).

Для стохастических систем, независимо от того, какие функции рисуются на графике, идет счет дифференциального уравнения для S(t) и вычисляется матрица K(t). В момент, когда матрица K выходит на стационарный режим, выдается сообщение

Матрица K постоянна,

начиная с  t = …

и счет S прекращается.

Этот момент может не наступить в диапазоне времени, отраженном на графике. В таком случае процесс нужно «продолжить» до получения сообщения, иначе матрица K не будет считаться найденной (если она не была найдена раньше).

Примечание.

Счет уравнений ведется с определенным шагом (см. раздел «Ввод данных»), поэтому и значение момента t определяется приближенно.
