# Фазовый портрет

Фазовый портрет

Процесс регулирования строится на фазовой плоскости как зависимость между двумя из фазовых переменных x1, x2,..., xn, где  n – порядок системы.

Если порядок системы больше двух, то нужно выбрать две разные координаты плоскости, на которую будет проектироваться фазовая траектория.

Программа ANACON

Программа запрашивает «начальное состояние объекта».

До начала рисования графика программа рассчитывает матрицу регулятора R, если она не была найдена раньше. Программа предлагает выбрать метод счета: по Калману или по Летову.

В случае счета по Калману внизу окна-графика показано оптимальное значение функционала J.

Программа ANACON2, ANACON3

До начала рисования графика программа проводит необходимые проверки и рассчитывает матрицу регулятора R, если она не была найдена раньше.

Внизу окна показано оптимальное значение функционала J.

Программа OPTIM и OPTIM2

На графике строится проекция оптимальной траектории на выбранные оси координат. На кривой отмечены точки переключения.

Дальнейшее относится только к программе OPTIM.

В меню окна "Фазовый портрет" есть пункт "Сравнение с САУ". При нажатии этого пункта на графике строится (пунктиром) еще одна кривая – траектория """""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

«»

Предварительно программа запрашивает время регулирования для САУ. При открытии панели ввода в окошке указано оптимальное время t рег, но можно указать и другое время. Затем нажмите кнопку OK.

При повторном нажатии пункта меню "Сравнение с САУ" рисование кривой сравнения отменяется.

Программа PHASPL

На фазовой плоскости переменных  x1, x2  строится линия переключения (оптимальная, или заданная пользователем, или определяемая нелинейным элементом). Для неустойчивого объекта показана граница области, из которой достижимо начало координат (в случае оптимальной системы). Затем проводится фазовая траектория, начинающаяся в заданной точке.

Рисование прекращается, если:

-
точка приходит в начало координат,
-
нажата клавиша 
Esc
,

-
кривая вышла за пределы области, в которой управление определяется линией переключения,
-
нарушены ограничения

где Max = 50, или число переключений больше Max (последнее может быть и в том случае, когда траектория "зависает" на линии переключения).

В последних двух случаях будет сообщение

Начало координат не достигается

Если в передаточной функции объекта есть запаздывание, то на графике указаны точки переключения.

Если, отметив точку на графике, нажать кнопку 
Пуск
, то из этой точки проводится фазовая траектория (поверх уже имеющегося изображения).

Примечание.

При изменении размеров графика и при команде "Повторить" на графике остается только последняя из проведенных траекторий.
