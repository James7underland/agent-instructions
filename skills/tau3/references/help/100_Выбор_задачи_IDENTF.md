Ввод данных (экспериментальных кривых) из файлов

Для идентификации передаточной функции W(p) по АФХ или по переходной функции графики вводятся соответственно из файлов amplph.dat и transf.dat.

В каждой строке файла amplph.dat три числа: частота w, вещественная и мнимая части W(jw). Частоты идут в возрастающем """""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

Для идентификации передаточной функции W(p) по ЛАЧХ графики ЛАЧХ и ЛФЧХ и вводятся соответственно из файла logam.dat.

В каждой строке файла три числа - частота w, значения 20 log |W(jw)| и arg W(jw), частоты в порядке возрастания.

Числа в строках разделяются пробелами. В каждом файле должно быть не меньше 10 и не более 50 строк.

Если нет одного из файла данных, то программа выдаст сообщение.

Определение данных по заданной передаточной функции

По заданной передаточной функции строятся графики, но известными считаются только отдельные точки этих графиков. К этим точкам можно добавить погрешность, которая распределена по нормальному закону с нулевым математическим ожиданием и дисперсией, задаваемой вместе с коэффициентами передаточной функции. Эти дисперсии обозначаются Dафх , Dпф , Dлах  и Dлфх соответственно для АФХ, переходной функции и логарифмических характеристик.

При любом способе ввода данных заданные точки наносятся на графики и соединяются плавными кривыми.

Записать данные в файл

Если графики были рассчитаны по заданной передаточной функции, то можно их записать в файлы (amplph.dat и transf.dat или logam.dat), используя пункт меню "Записать данные в файл".

При идентификации W(p) по АФХ или по переходной функции на графиках рисуется как АФХ, так и переходная функция, но для нахождения передаточной функции используется только одна из этих функций, а другая служит только для контроля. Исключение из этого правила: коэффициент усиления K0 программа всегда берет из АФХ, а запаздывание t - из переходной функции.

Точно так же при идентификации W(p) по ЛАЧХ на графиках рисуется как ЛАЧХ, так и ЛФЧХ, но для нахождения передаточной функции используется только ЛАЧХ, а другая характеристика служит только для контроля. Исключение из этого правила: коэффициент усиления K0 программа находит из ЛАЧХ, а запаздывание t - из ЛФЧХ.

По поводу методов счета см. раздел «Идентификация».
