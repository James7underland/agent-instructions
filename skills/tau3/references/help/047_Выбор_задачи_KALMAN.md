Матрица K в детерминированном варианте находится  из условия заданного качества матрицы  A-KC  (задается характеристический многочлен), а в стохастическом варианте - из условия  наилучшего подавления помех (фильтр Калмана).

При решении этих задач используется принцип разделения, согласно которому подсистемы регулирования и наблюдения рассчитываются независимо друг от друга.

Задача модального управления. Выбрать регулятор  u = - Rx  таким образом, чтобы матрица замкнутой системы  A - BR  имела заданный характеристический многочлен.

Для решения задачи использован алгоритм из книги Ю.М. Андреева “Управление конечномерными линейными объектами”, М., Наука, 1976.

Этот же метод использован для нахождения матрицы K в детерминированном варианте.

Другие задачи решаются с использованием методов из книги Х. Квакернаак, Р. Сиван “Линейные оптимальные системы управления”, Мир, М., 1977 (автор методов Р.Е. Калман).
