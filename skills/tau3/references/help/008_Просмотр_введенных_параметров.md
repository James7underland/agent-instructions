# Просмотр введенных параметров

Просмотр введенных параметров

Просмотр параметров организован аналогично разделу «Формирование элементов схемы» со следующими отличиями:

- в окне "Элемент схемы" нет полосы прокрутки и показан выбранный тип элемента,

- в окнах "Параметры" отсутствует возможность ввода.

Для просмотра параметров нажмите букву на схеме, чтобы выбрать передаточную функцию или входное воздействие, параметры которых нужно посмотреть.

Чтобы выйти из режима "Просмотр параметров", нужно закрыть окно "Элемент схемы" или вызвать любой другой пункт Главного меню.
