# Программа CONTROL

Программа CONTROL

Система автоматического регулирования

Программа предназначена для исследования САР, структурная схема которой изображена в Главном окне. На схеме:

W - объект,

R - регулятор,

G, H - обратные связи,

N - нелинейный элемент,

f - задающее воздействие,

g, v, z – возмущающие воздействия,

y - выходной сигнал,

h, u, x - дополнительные точки, выход из которых может отслеживаться при построении процесса регулирования.

Нелинейность в системе может отсутствовать (это устанавливается в разделе "Формирование элементов схемы") несмотря на наличие звена N на схеме. Если система действительно нелинейная, об этом сообщает пометка NL (nonlinear) в правом нижнем углу схемы.

Программа не запрещает ввод отрицательных значений коэффициентов передаточных функций, но если это будет сделано, то на схеме появится пометка NG (negative).
