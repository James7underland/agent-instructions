# Многооконный интерфейс

Многооконный интерфейс

В каждый момент работы программы на экране находится одно или несколько окон.

Окно - прямоугольный участок экрана, имеющий в верхней части заголовок, нажимая на который мышью, можно это окно перемещать.

В левом верхнем углу окна может быть кнопка вызова меню, в верхнем правом углу - кнопки минимизации окна (до размеров пиктограммы), раскрытия окна на весь экран (или восстановления нормального размера), закрытия окна.

Закрыть окно можно также, нажав пункт меню окна "Закрыть" (если такой имеется), или нажимая комбинацию клавиш Alt+F4. В некоторых случаях окно нельзя закрыть, пока не закончится счет или не будет исправлена «ошибка ввода» (и в ряде других случаях).

Размер некоторых окон можно изменить, потянув за рамку курсором мыши.

В каждый момент только одно из окон может быть активным. Окно активизируются щелчком мыши. Некоторые окна сохраняют активность до тех пор, пока пользователь не выполнит определенное, обусловленное ситуацией действие и не нажмет на кнопку (модальные окна).

Работа программы управляется системой «меню».

При вызове программы на экране появляется заставка, содержащая ее название и кнопку OK, которую нужно нажать, чтобы продолжить работу (нажмите ключ F10, если Вы хотите выйти из программы). Затем появляется Главное окно, в котором изображена структурная схема САУ или записаны условия решаемой в программе задачи. Главное окно программы содержит Главное меню. Закрытие Главного окна означает окончание программы.

Основная работа программы выполняется в окнах-графиках.

Перед началом работы программа может задать ряд вопросов (например, о «начальных значениях параметров»).

Для продолжения работы вызовите Главное меню.
