# Известные ловушки (читать перед каждой задачей)

## PowerShell 5.1 и кодировки
1. **Скрипты .ps1 — только UTF-8 с BOM.** Без BOM кириллица превращается в «РЎС…РµРјР°», и парсер падает на скобках.
   - `[IO.File]::ReadAllText(f, UTF8)` **съедает BOM**. Записывать обратно через `New-Object Text.UTF8Encoding $true`.
   - Инструмент Edit сохраняет BOM, если он был.
   - После правок проверять: первые байты `239,187,191` и `[Management.Automation.Language.Parser]::ParseFile(...)` — 0 ошибок.
2. **Имена переменных и ключи хеш-таблиц нечувствительны к регистру.**
   - `$L`/`$l`, `$LY`/`$ly`, `$S`/`$s`, `$M`/`$m` — одна переменная. Ключи `N6` и `n6` — один ключ; так получилась диагональная линия.
   - 25.09.2026: параметр `[string]$Layout` и переменная `$LAYOUT` — одна переменная. JSON привёлся к строке, схема собралась без технологии: 2 слоя, 0 приклеенных линий. Теперь параметр называется `-LayoutFile`.
   - Правило: уникальные длинные имена (`$LAYOUT`, `$SH`, `$mst`), id номеров обрывов — `b*` и `pb*`.
3. `param(...)` должен быть **первым оператором** скрипта: до него только комментарии.
4. Для кириллицы в выводе Python из Bash — `PYTHONIOENCODING=utf-8`.

## Visio COM
5. `Fonts.ItemU` не существует — `Fonts.Item('Arial')`.
6. Текст с полями вставлять **с конца строки**: `for i = n-1 … 0`, иначе смещаются позиции.
7. Динамические соединители делают петли и обходы. Вместо них — **полилинии, приклеенные к точкам соединения** (`GlueTo`). У точек соединения не задавать направление.
8. Контейнер при `AddMember(x, 0)` расширяется на весь лист (захватил номера). Нужен флаг **2**.
9. Масштабированная копия мастера (для легенды) искажается — значки легенды рисовать вручную.
10. Удалённое поле `Prop.Fail` ломало `verify2` — проверочные скрипты синхронизировать с мастерами.
11. Файл, открытый у пользователя в Visio, заблокирован.
    - Сохранять под другим именем или закрыть немодифицированный документ через `GetActiveObject`, затем открыть заново.
    - Документ с несохранёнными правками пользователя **не закрывать**.
12. `Документ1.vsdx` (рамка) никогда не изменять: только копировать. Сверять хеш до и после.

## Источники и инструменты
13. Фото с iPhone (.HEIC) Read не открывает. Конвертировать через WPF `BitmapDecoder` (PowerShell) в JPG в scratchpad.
14. PDF ГОСТов из папки ФСА имеют **текстовый слой**; таблицы 1 и 3 ГОСТ 21.208 и рисунки — картинки. Готовые PNG лежат в `assets/gost-img/`, новые рендерить `pymupdf` (`get_pixmap(dpi=100)`).
15. WebFetch на PDF не распознаёт текст, но **сохраняет файл** в `tool-results/webfetch-*.pdf`. Дальше — `pymupdf`: текст (у старых ГОСТ 2.7xx текст битый, только картинки) и рендер страниц.
    - Прямые PDF: `files.stroyinf.ru/Data2/1/4294848/42948488NN.pdf`:
      - 54 — ГОСТ 2.790;
      - 55 — 2.789;
      - 56 — 2.788;
      - 58 — 2.785;
      - 59 — 2.782;
      - 2.793 — `…/4294849/4294849135.pdf`.
16. Встроенный браузер плохо отдаёт скриншоты длинных картинок (таймауты, пустые кадры). Для сканов ГОСТ — WebFetch плюс pymupdf.

16a. **PDF чертежей из AutoCAD или Ghostscript** (например, `Колонна К-1 — копия.pdf`): текст превращён в кривые, `get_text()` пустой, рисунков сотни.
   - Как читать: обзор страницы на 40 dpi, затем сетка 4×3 фрагментов через `get_pixmap(dpi=110…150, clip=Rect)`.
   - Табличные листы (перечень сигналов, регламент) текст обычно сохраняют.

## Требования преподавателя против ГОСТ (не «исправлять» обратно)
17. Шток ИМ — **5 мм** (по ГОСТ 21.208 табл. 3 — 10 мм).
18. Линии связи **сплошные** (по ГОСТ 21.408 табл. Б.1 электрический сигнал — штриховой).
19. Трубы и аппараты — **1,5 пт** (по ГОСТ 21.408 п. 4.3 — тонкой линией). Линии контуров — 0,75 пт.
20. Порядок функций **I R C A S** (FIRCA, PIRCAS). По рис. 1 ГОСТ 21.208 порядок иной.
21. Позиции **N-k** (1-1, 1-2), а не 1а, 1б.
22. Температурный контур — **TE → TIRC → TY → ИМ** (без TT).
23. ИМ электрические: **стрелок на штоке нет**, «I/P» у xY не писать.
    - Уточнение 26.09.2026 (quizyforu-eng): если привод пневматический, ИМ — квадрат 5×5 мм, у xY пишется «E/P». Это не ошибка. См. `reference-sheet.md`, п. 3.
24. Места отбора — **строго как на эскизе** (FE 7-1 — на всасе Н-6). Лишних труб не дорисовывать.
25. Номера обрывов — **сквозные по колонкам подвала** (26.09.2026, quizyforu-eng). У контура только измерения или ДУ — один номер. Не «исправлять» обратно на 2k−1 / 2k: см. `reference-sheet.md`, п. 1.

## Visio COM и PowerShell — дополнение 26.09.2026 (quizyforu-eng)
26. **`Documents.OpenEx` в InvisibleApp зависает навсегда** (без ошибки и без диалога).
    - Причина: путь пришёл из `Join-Path` без приведения к строке, и в COM передаётся PSObject.
    - Что делать: `$f = [string](Join-Path $dir "$name.vsdx")` или обычная строка `"$dir\$name.vsdx"`. Проверено: Visio 16, PowerShell 5.1, Windows 11.
27. **Переменная, объявленная как `[double]$r = 0` на уровне скрипта, сохраняет тип.**
    - Симптом: позже `foreach ($r in $rows)` падает с ошибкой «Object[] → Double».
    - Что делать: давать типизированным переменным уникальные имена (`$bbL`, `$bbB`…).
28. **Лог прогресса нельзя читать через `tail -f`.**
    - Причина: `tail -f` держит файл, и `Add-Content` падает.
    - Что делать: писать через `[IO.File]::Open($f, 'Append', 'Write', 'ReadWrite')`.
29. **После упавшего запуска остаётся невидимый VISIO.EXE и держит выходной файл.**
    - Что делать: завершать только свои процессы — по PID или по пустому `MainWindowTitle` и времени запуска.
    - Никогда не завершать все VISIO подряд: закроется Visio пользователя вместе с несохранёнными правками.

## Инженерная геометрия и программная компоновка (Visio P&ID)
30. **Расчет сопряжения штуцеров с круглыми корпусами.**
    - Нельзя подводить штуцер к `CX ± R` при `Y ≠ CY`: будет разрыв 1–2 мм. Координата контакта рассчитывается строго: `X = CX ± [Math]::Sqrt([Math]::Max(0, R*R - (Y - CY)*(Y - CY)))`.
31. **Точки подключения шевронов-стрелок.**
    - Правый шеврон (`direction="right"`): тыл на `X`. Левый шеврон (`direction="left"`): тыл на `X + W`.
32. **Габарит привода МИМ регулирующего клапана.**
    - Верх купола привода: `vy - 6.2 мм`. Запрещено проводить параллельные линии в диапазоне `vy - 7 мм .. vy`. Сигнал подводить строго в вершину `(vx, vy - 6.2)`.
33. **Отводы из днищ аппаратов.**
    - Донный штуцер обязан опуститься ниже нижней дуги днища, прежде чем поворачивать горизонтально, иначе линия разрезает сосуд изнутри.
34. **Обязательная визуальная верификация 300 DPI.**
    - Всегда проверять экспорт 300 DPI визуально: слепые скрипты на COM-интерфейсе оставляют наложения текста и пересечения символов КИПиА.
