# Visio: конвейер сборки ФСА и знания про COM

Проверено: Visio 16.0 (русская локаль), PowerShell 5.1, Python 3.14 (matplotlib, pymupdf), Windows 11. Эталон прогона — `ФСА_ректификация_v2`, повторён из скилла 25.09.2026: 47 из 47 линий приклеены.

## Конвейер
```
фото или эскиз ──► таблица оборудования и контуров (вручную, в чате)
            ──► layout.py (копия scripts/layout_example.py, правится раздел PROCESS и LOOPS)
                 python layout.py <рабочая_папка>   → layout.json, preview.png, "NO COLLISIONS"
            ──► смотреть preview.png (Read) → править координаты → повторять до чистого результата
            ──► build_fsa.ps1 -LayoutFile <раб>\layout.json -OutDir <папка ФСА> -Name <имя> -Title "<Установка …>" -Code "<шифр>"
                 → <имя>.vsdx, <имя>.pdf, ГОСТ_21.208_КИП.vssx (трафарет пересоздаётся рядом)
            ──► verify.ps1 -Dir <папка> -Name <имя>        (размеры приборов, состав контуров, приклейка)
                verify_lines.ps1 -Dir <папка> -Name <имя>  (толщины по слоям, шток ИМ)
            ──► PDF → PNG (pymupdf, 150–200 dpi) → посмотреть глазами фрагменты
```
- Рабочая папка — scratchpad сессии. layout.py, layout.json и превью в папку пользователя не класть.
- Рамка: `Документ1.vsdx` (стр. 2 — А3 со штампом). Скрипт **копирует** её, исходник не трогает. До и после сверять хеш.
- Если пользователь держит `.vsdx` открытым в Visio, файл заблокирован. Тогда сохранять под новым именем (`_v3`) или закрыть **немодифицированный** документ через `GetActiveObject('Visio.Application')` и после сборки открыть заново. Изменённый — не трогать, спросить.

## API layout.py (координаты в мм, начало — левый нижний угол листа)
| Функция | Смысл |
|---|---|
| `inst(id, kind, x, y, letters, pos, loop, param, device, note, npos)` | Прибор. `kind`: `field` — круг без черты (xE), `panel` — круг с чертой (xT, xY), `ctrl` — прямоугольник 18×10 с чертой (регулятор с длинным кодом). `note` — H/L/I/P справа. `sym[id]['inline']=True` — FE в разрыве трубы |
| `valve(id, x, y, pos, loop, act, pos_side)` | Клапан с ИМ, центр бабочки в (x, y). `act`: `up`/`down`/`left`/`right` — куда смотрит ИМ |
| `equip(id, kind, x, y, pos, w, h, flipx, txt)` | `pump` Ø12, `hex` Ø16, `column` w×h, `drum` w×h, `reb` w×h |
| `pipe(pts, arrow=True, lw=0.35)` | Трубопровод (ломаная, стрелка на конце). lw 0.35 → 1,5 пт |
| `plines.append(dict(pts=…))` + `dots.append((x, y))` | Линия отбора от прибора к трубе или аппарату + точка соединения |
| `sig(a, ai, b, bi, route, via, mid)` | Линия связи между точками соединения. `route`: `S` прямо, `VH`, `HV`, `VHV`, `HVH` (с `mid`), либо `via=[(x, y), …]` |
| `num(id, x, y, n)` | Номер обрыва (выносная линия к нему — через `sig`) |
| `label(x, y, text, size, align, angle)` | Надпись (подписи потоков) |
| `LOOPS = [(контур, id_датчика, 'R C A S I A2 DU', '…м³/ч')]` | Подвал: какие точки ставить. R — регистрация, C — стабилизация, A — сигнализация ПЛК, S — блокировка, I — индикация, A2 — сигнализация АРМ, DU — дистанционное управление |

**Точки соединения** (`cnx`):
- прибор Ø10: 0 — верх, 1 — низ, 2 — лево, 3 — право, 4 и 5 — лево-верх и право-верх (±4,33; +2,5), 6 и 7 — лево-низ и право-низ;
- `ctrl` 18×10: то же, с ±9;
- клапан: 0 и 1 — концы бабочки (±3,5; 0), 2 — низ корпуса (0; −1,75), 3 — **верх ИМ** (0; 10), 4 и 5 — бока ИМ (±2,5; 7,5), всё поворачивается вместе с `act`. `vcnx(id, 'body'|'far'|'act_l'|'act_r'|'act_u'|'act_d')` — выбор по смыслу;
- номер: 0 — верх, 1 — низ, 2 — лево, 3 — право.

`check()` находит:
- перекрытия символов;
- линии связи через приборы;
- наложение надписей;
- пересечения «сигнал — сигнал» и «сигнал — труба».
Цель — **NO COLLISIONS**. Пересечение сигнала с изображением аппарата ГОСТ разрешает, но преподаватель просит избегать.

## Документ
- Страница «Рамка А3» — **фоновая**, слой «Рамка» заблокирован. На ней же слой «Штамп».
  - Поля: Title, Subject (свойства документа), PageNumber, NumberOfPages.
  - Обозначение документа — текст `-Code`, повторено в доп. графе с поворотом на 180°.
- Страница «ФСА»: 420×297 мм, масштаб 1:1, `LineJumpCode = 0` (без перескоков), фон — «Рамка А3».
- Слои: Трубопроводы, Оборудование, Регулирующие органы, КИП, Линии связи, Контур 1…N, Надписи, Подвал, Таблица.
- Подвал — **контейнер** (`User.msvStructureType = "Container"`, `ContainerProperties.AddMember(shape, 2)` — флаг 2 = не расширять контейнер). Таблица контуров строится **из Shape Data** приборов и группируется. Легенда нарисована вручную (масштабирование мастеров искажает).
- Линии связи — полилинии `DrawPolyline(arr, 8)`, концы приклеены `GlueTo(shape.CellsSRC(7, idx, 0))` к точкам соединения.
- Экспорт: `ExportAsFixedFormat(1, pdf, 1, 0)` — PDF, печать, весь документ.

## Приёмы COM (PowerShell)
- `New-Object -ComObject Visio.InvisibleApp` — без окна; `$app.AlertResponse = 1`; в `finally` — `$app.Quit()`.
- Культура потока `en-US`, иначе формулы с десятичной точкой ломаются.
- Длины — дюймы: `mm()` = /25,4, либо формулы `"3.5 mm"` через `CellsU(...).FormulaU`.
- Трафарет:
  1. `Documents.AddEx('', 1, 512, 0)` (visMSDefault, docked stencil);
  2. фигура строится на временной странице;
  3. `Masters.Drop(shape, 0, 0)`;
  4. `SaveAsEx(path, 0)`.
- Разделы ShapeSheet:
  - 243 — Prop (Shape Data);
  - 242 — User;
  - 240 — Actions;
  - 7 — Connection points (`AddRow(7, -2, 153)`);
  - 10 — Geometry (`DeleteSection` + `AddSection`, строки 137…144).
- Поля в тексте:
  - `Characters.AddCustomFieldU(formula, 37)` для Prop;
  - `AddField(category, code, 0)` для полей документа;
  - **вставлять с конца строки**, иначе позиции сдвигаются.
- Шрифт: `Fonts.Item('Arial').ID` (у коллекции нет `ItemU`).
- Группа из фигур: `CreateSelection(0)`, `Select(x, 2)`, `.Group()`.
- Слои: `Page.Layers.Add(name)`, `layer.Add(shape, 0)`. Блокировка слоя — `layer.CellsC(7).FormulaU = '1'`.
- Толщины задаются строкой `'1.5 pt'` / `'0.75 pt'` в `LineWeight`.

## Проверка результата
- `verify.ps1`:
  - мастера трафарета;
  - слои;
  - состав каждого контура (Letters + Pos);
  - размеры приборов (10×10, 18×10);
  - число приклеенных линий (обоими концами).
- `verify_lines.ps1`: толщины по слоям (трубопроводы 1,5 пт, линии связи 0,75 пт) и длина штока ИМ (5 мм).
- Визуально: PDF → PNG через `pymupdf` (`page.get_pixmap(dpi=200, clip=Rect)`); смотреть отдельно технологию, подвал, штамп.
