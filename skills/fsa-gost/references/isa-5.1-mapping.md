# ГОСТ 21.208-2013 ↔ ANSI/ISA-5.1 (P&ID) — соответствие

ГОСТ 21.208-2013 по буквам в основном гармонизирован с ISA-5.1 и ISO 14617-6 / IEC 62424. Методички ТПУ (Громаков)
иногда требуют **две ФСА**: по ГОСТ и по ANSI/ISA-5.1. Эта таблица помогает перевести одну в другую.

## Графика
| Смысл | ГОСТ 21.208 | ISA-5.1 |
|---|---|---|
| Прибор по месту (field) | круг Ø10, без черты | круг, без черты |
| Прибор на щите, доступен оператору | круг с **одной** горизонтальной чертой | круг с чертой — главный щит (primary location); **пунктирная** черта — за щитом (not accessible); **две** черты — вспомогательный щит |
| Функция РСУ, SCADA, видеокадр (shared display) | прямоугольник «функциональный блок» или круг с чертой в прямоугольнике «ПЛК» | **круг в квадрате** |
| Функция ПЛК или компьютера | прямоугольник | **ромб в квадрате** (PLC) или шестиугольник (computer function) |
| ПАЗ / SIS | квадрат в ромбе (Z) | ромб в квадрате, буквы с Z (SIS), в ISA-5.1-2009 — отдельный ромб |
| ИМ (актюатор) | кружок Ø5 на штоке | полукруг (диафрагма), прямоугольник (соленоид), «M» в кружке (мотор) |
| Положение при отказе | стрелка на штоке ↑ (НО) / ↓ (НЗ) | подпись **FO / FC / FL** (fail open, closed, locked) |
| Электрический сигнал | штриховая линия | штриховая |
| Пневматический сигнал | сплошная (импульсная трубка) | линия с двойными косыми засечками // |
| Программная связь, шина данных | линия с кружками | линия с кружками (communication link) |
| Импульсная линия (process connection) | сплошная тонкая | сплошная тонкая |

## Буквы (первая буква и функции)
Совпадают: A (анализ / сигнализация), B (пламя), C (регулирование), D (перепад), E (напряжение / чувствительный элемент), F (расход / соотношение), H (ручное / верхний предел), I (ток / показание), J (мощность / обегание), K (время / станция управления), L (уровень / нижний предел), M (среднее), P (давление), Q (количество / интегрирование), R (радиоактивность / регистрация), S (скорость / переключатель), T (температура / преобразователь — в ISA «transmit»), U (многопараметрический), V (вибрация; в ISA как функция — клапан, заслонка), W (вес), X (резерв), Y (событие / реле, вычислитель, **I/P-преобразователь**), Z (положение / привод, ИМ).

Отличия в употреблении:
- **Клапан** в ISA кодируется буквами: FV, TV, PV, LV (V = valve), ИМ входит в тот же тег. В ГОСТ у клапана с ИМ **только позиция** (1-5), без букв.
- В ISA регулятор — **FIC / TIC** (C после I). В ГОСТ порядок — по рис. 1: I, R, C, A, S → **FIRCA**. ISA: FIC + FAH / FAL отдельными тегами тревог (или «FAHL»).
- В ISA переключатели: **FSH / FSL**; сигнализация: **FAH, FAL, FAHH**; в ГОСТ H и L пишутся **справа** от знака.
- **Тег ISA**: `FIC-101` (номер петли 101: площадка 1, петля 01). ГОСТ: позиция N-k или Nа, Nб по спецификации.
- Датчик расхода: ISA — FE (orifice) + FT. Так же в ГОСТ.
- Преобразователь I/P: ISA — **FY** или **I/P** рядом. В ГОСТ — xY с надписью «I/P» справа (табл. А.1, конверсия).

## Пример: контур расхода в двух стандартах
- **ГОСТ** (как у преподавателя): FE 1-1 (в разрыве трубы) → FT 1-2 (круг с чертой) → **FIRCA 1-3** (прямоугольник 18×10 с чертой) → FY 1-4 → ИМ 1-5 (кружок Ø5 на штоке 5 мм) → клапан.
- **ISA**: FE-101 → FT-101 → **FIC-101** (круг в квадрате, РСУ) + FAL-101 → FY-101 (I/P) → **FV-101** (клапан с диафрагменным приводом, FC).
