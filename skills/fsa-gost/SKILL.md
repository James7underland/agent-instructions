# ФСА по ГОСТ 21.208/21.408 — рабочий процесс

Рабочая папка пользователя: `<work_dir>\ФСА`.
Скилл лежит в `...\ФСА\Скилл fsa-gost\`; `<скилл>` — junction на эту папку.
Рамка А3 со штампом — `...\Комп графика\Документ1.vsdx`, стр. 2. **Никогда не изменять**, только копировать.

## В начале каждой задачи
1. Прочитать `references/known-issues.md` (обязательно) и хвост `references/session-log.md`.
2. Для оформления — `references/teacher-rules.md`: правила преподавателя; при расхождении с ГОСТ **действуют они**.
   Затем `references/reference-sheet.md` — правила от 26.09.2026 (сквозная нумерация обрывов, где показывать регулятор, пневматический ИМ, NS, контуры измерения); они уточняют teacher-rules. Эталон всех элементов — `assets/Эталоны_ФСА_А0.pdf`.
3. По задаче:
   - `gost-21.208-2013.md` — буквы, УГО, размеры, порядок букв, приложения А и Б;
   - `gost-21.408-2013.md` — развёрнутый и упрощённый способ, прямоугольники, обрывы, линии табл. Б.1, пример В.1;
   - `eskd-equipment-symbols.md` — арматура, колонны, теплообменники, насосы, окраска труб, форматы, штамп, линии, шрифты;
   - `typical-control-schemes.md` — что и чем регулировать для аппаратов разных типов, функции в подвале;
   - `instruments-catalog.md` — что скрывается за FE, FT, ИМ, ПЛК; методы измерения, марки, сигналы; спецификация;
   - `industrial-example-k1.md` — разбор рабочего проекта вакуумной колонны К-1: обозначения РСУ и ПАЗ, резервирование «2 из 3», Σ/3, коррекция f(T,P,F), типовые схемы насосов и арматуры, перечень сигналов; что из этого брать в учебную ФСА. Фрагменты — `assets/example-k1/*.png`;
   - `isa-5.1-mapping.md` — перевод в ANSI/ISA (если нужна вторая схема «по ANSI»);
   - `visio-automation.md` — конвейер, API `layout.py`, мастера трафарета, приёмы COM;
   - `raw/*.txt` — полные тексты ГОСТов для grep; `assets/gost-img/*.png` — картинки таблиц и примеров.

## Правила безопасности
- `Документ1.vsdx` — только `Copy-Item`, до и после сверить `Get-FileHash`.
- Готовые файлы пользователя (`*.vsdx`, `*.pdf`) не перезаписывать без спроса: новая версия — новое имя (`_v2`, `_v3`) или явное согласие.
- Файл открыт в Visio пользователя → не закрывать документ с несохранёнными правками. Немодифицированный можно закрыть через `GetActiveObject` и после сборки открыть снова.
- Промежуточные файлы (layout.py, json, png) — в scratchpad, не в папку пользователя.

## Порядок работы (фото → ФСА)
1. **Разбор исходника.** HEIC конвертировать в JPG (WPF `BitmapDecoder`) и рассмотреть по частям. Составить в чате таблицы:
   - оборудование (Н, Т, К, КХ, Е, И…);
   - потоки (откуда и куда, подписи);
   - контуры: параметр, место отбора, какой клапан двигает.
   Неясное (линия к ИМ без кружка, непонятные пометки) — спросить пользователя одним вопросом с вариантами.
2. **Состав контуров** — по `teacher-rules.md` §5: расход и давление FE→FT→xIRC(A)→xY→ИМ (N-1…N-5), температура TE→TIRC→TY→ИМ, уровень LE→LT→LIRC(A)→LY→ИМ. Функции регулятора (R, C, A, S; H/L справа) согласовать с подвалом.
3. **Компоновка**: скопировать `scripts/layout_example.py` в scratchpad как `layout.py`, переписать раздел PROCESS и `LOOPS`.
   - Запуск: `python layout.py <scratch>` → добиться **NO COLLISIONS**, посмотреть `preview.png`.
   - Приёмы: ИМ вниз (`act='down'`), контур «П» над или под трубой, FE в разрыве, TE, PE, LE — рядом с линией отбора и точкой.
4. **Сборка**:
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File "<skill>\scripts\build_fsa.ps1" -LayoutFile "<scratch>\layout.json" -OutDir "<ФСА>" -Name "ФСА_<объект>" -Title "Установка <…>" -Code "ФСА-0N-АТХ"
   ```
   Скрипт строит трафарет, рамку на фоне, технологию, подвал-контейнер, таблицу контуров из Shape Data, легенду, штамп с полями, PDF.
5. **Проверка**:
   - `scripts/verify.ps1 -Dir <ФСА> -Name <имя>` и `scripts/verify_lines.ps1 …`: размеры, состав контуров, все линии приклеены, толщины 1,5 и 0,75 пт, шток 5 мм;
   - PDF → PNG (pymupdf, 200 dpi) — посмотреть технологию, подвал, штамп;
   - пройти чек-лист `teacher-rules.md` §12.
6. **Сдача**: открыть `.vsdx` пользователю (`Start-Process`), приложить PDF. Кратко перечислить контуры и что осталось на решение пользователя: числа пределов «…м³/ч», фамилии в штампе.

## Ответы на вопросы (без рисования)
- «Что значит буква …» → `gost-21.208-2013.md`, табл. 2 и порядок букв. Отдельно указать различия с ГОСТ 21.404-85, если пользователь цитирует старые методички.
- «Какие контуры поставить на …» → `typical-control-schemes.md`, затем предложить таблицу контуров.
- «Какой датчик или ИМ выбрать» → `instruments-catalog.md`; марки — как ориентир, с оговоркой проверить у производителя.

## Скрипты (`scripts/`)
| Файл | Что делает |
|---|---|
| `layout_example.py` | Эталонная компоновка ректификации (7 контуров) + API (`inst`, `valve`, `equip`, `pipe`, `sig`, `num`, `label`, `LOOPS`) + проверка коллизий + превью |
| `build_fsa.ps1` | Сборка Visio по layout.json. Параметры: `-LayoutFile -OutDir -Name -Title -Code -Frame`. **UTF-8 с BOM** |
| `verify.ps1` | Трафарет, слои, состав контуров, размеры, приклейка |
| `verify_lines.ps1` | Толщины линий по слоям, длина штока ИМ |
| `build_reference_a0.ps1` | Эталонный лист А0 со всеми элементами. Параметры: `-Frame` (рамка А3 кафедры), `-OutDir`, `-Anonymize` (без логотипа и дат). **UTF-8 с BOM** |
