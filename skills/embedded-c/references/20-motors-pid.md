# 20. Моторы и движение (кратко)

## Типы приводов
- **Соленоид:** вкл/выкл (замки, клапаны). **Пьезо / вибромотор:** тактильная обратная связь, звук.
- **Шаговый:** точное положение без обратной связи (открытый контур), держит позицию (и ест ток в покое).
  Несколько линий, последовательность коммутации — из даташита.
- **Коллекторный DC:** дёшев. Скорость ∝ напряжению (ШИМ), момент ∝ току. Точно остановить трудно,
  нужна обратная связь. Реверс — через H-мост.
- **Бесколлекторный (BLDC):** долговечный, эффективный, тихий. Нужна коммутация (контроллер).
- **Сервопривод:** мотор плюс обратная связь плюс контроллер (у хобби-серво 3 провода и ШИМ-импульс 1–2 мс).

## Положение
- Абсолютный датчик — просто прочитай. Относительный (энкодер, шаги) — сначала **хоминг**: медленно ехать
  к датчику «дома», это ноль, дальше считать.
- Энкодеры: линейные и круговые, оптические. Импульсы считает аппаратный счётчик МК (раздел «Counter/Timer»),
  а не прерывание на каждый импульс.
- **Концевые выключатели** на опасных краях — обязательно.

## Электрика — что должен знать программист
- **Никогда** не подключай мотор к ножке МК напрямую: ШИМ идёт через транзистор (MOSFET) или драйвер.
- Пусковой ток (inrush) и ток заклинивания велики. Отдельное питание для мотора и МК, развязка конденсаторами.
  Иначе просадка питания даст brownout-сбросы и странные аварии, особенно на подсевшей батарее.
- При остановке мотор возвращает энергию. Нужны снабберные или обратные диоды (в H-мосту они уже есть).
- Источник должен держать ≈ 3× номинальный ток нагрузки.
- Мотор — главный потребитель в бюджете питания. Драйверы греются.

## Программа — меры безопасности
- Проверяй знак и диапазон команды ШИМ: отрицательная скважность или ошибка переполнения = «детали
  летят по комнате».
- Watchdog и безопасное состояние (мотор выключен) при любом сбое.
- Сначала нижние уровни (включить-выключить, направление), потом профили.
- Отладочный UART в прерываниях может сорвать тайминги коммутации и сжечь транзисторы.

## PID-регулятор
Ошибка `e = setpoint − measured`.
- **P** = Kp·e: чем дальше, тем сильнее. Одного P бывает мало: остаётся статическая ошибка, возможны колебания.
- **I** = Ki·Σe: убирает статическую ошибку, но накапливает «инерцию» и перерегулирование.
  **Ограничивай интеграл** (anti-windup).
- **D** = Kd·(e − e_prev): гасит перерегулирование, но чувствителен к шуму. Сглаживай производную.
- Выход = P + I + D → **насыщение** в допустимый диапазон ШИМ.
- Настройка (tuning): сначала P, потом D, потом при необходимости I. Методы (Циглер — Николс) плюс эксперимент.
  Это долго.
- В fixed-point: коэффициенты в Q-формате, промежуточные суммы в 32 или 64 битах, насыщение.

```c
typedef struct {
    int32_t kp_q8, ki_q8, kd_q8;      /* gains in Q23.8 */
    int32_t integ, integ_min, integ_max;
    int32_t prev_err;
    int32_t out_min, out_max;
} pid_ctrl_t;

int32_t pid_step(pid_ctrl_t *p, int32_t setpoint, int32_t measured)
{
    int32_t err = setpoint - measured;
    p->integ += err;
    if (p->integ > p->integ_max) { p->integ = p->integ_max; }   /* anti-windup */
    if (p->integ < p->integ_min) { p->integ = p->integ_min; }
    int64_t out = (int64_t)p->kp_q8 * err
                + (int64_t)p->ki_q8 * p->integ
                + (int64_t)p->kd_q8 * (err - p->prev_err);
    p->prev_err = err;
    out /= 256;                                                   /* back from Q8, rounds toward zero */
    if (out > p->out_max) { out = p->out_max; }
    if (out < p->out_min) { out = p->out_min; }
    return (int32_t)out;
}
```
PID вызывается с **постоянным** периодом (по тику), иначе I и D теряют смысл.

## Профили движения
Разгон и торможение до максимума (треугольный профиль) — быстро, но рывок изнашивает механику. Трапецеидальный:
разгон → постоянная скорость → торможение. S-кривая: плавное изменение ускорения, минимальный рывок
(jerk = производная ускорения). Профиль задаётся **скоростью** во времени: скорость
управляется напряжением проще, чем положение. У производителей МК есть готовые библиотеки управления моторами.

## ESP8266
`analogWrite()` — программный ШИМ (см. `05`), годится для DC-мотора через MOSFET или драйвер (DRV8833,
TB6612). Для точной коммутации ШИМ ESP8266 не лучший выбор. Библиотека `Servo` для хобби-серво.
Мотор плюс Wi-Fi на одном питании D1 mini — частая причина перезагрузок: нужно отдельное питание.
