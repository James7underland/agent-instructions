# 09. Кнопки, антидребезг, матрицы

## Дребезг
Механический контакт при нажатии и отпускании несколько миллисекунд «звенит»: много переходов 0/1, плюс
промежуточные аналоговые уровни. Прерывание по фронту на таком сигнале даёт пачку ложных срабатываний
и напрасную нагрузку. **Правило:** кнопки опрашивай периодически (по тику) и фильтруй программно, либо ставь
RC-фильтр и триггер Шмитта. Время дребезга смотри в даташите кнопки. Не определяй его на глаз
по одной партии: другая партия может звенеть дольше.

## Алгоритм «N одинаковых отсчётов подряд»
Опрос с периодом T. Состояние меняется, только если сырое значение отличается от устойчивого N раз подряд.
Время реакции ≈ N × T. Пример: дребезг ≤ 12,5 мс, хотим реагировать на нажатие ≥ 50 мс → T = 10 мс, N = 5
(консервативно) или N = 3.

Переменные: сырое значение, счётчик, устойчивое (отфильтрованное) значение, флаг «изменилось».
Счётчик может быть несимметричным: реагировать на нажатие быстро, а на отпускание медленно.

```c
typedef struct {
    uint8_t stable;        /* debounced level: 0/1 */
    uint8_t count;         /* consecutive samples differing from stable */
    uint8_t threshold;     /* N */
} debounce_t;

/* Call every T ms with the raw pin level. Returns 1 when stable level changed. */
int debounce_update(debounce_t *d, uint8_t raw)
{
    if (raw == d->stable) {
        d->count = 0;
        return 0;
    }
    if (++d->count >= d->threshold) {
        d->stable = raw;
        d->count = 0;
        return 1;
    }
    return 0;
}
```
Событие «нажатие» — изменение в активный уровень. «Клик» обычно фиксируют **по отпусканию**, так
удержание не повторяет действие. Кнопка на землю с pull-up — активный низкий уровень.

Эргономика: реакция > 250 мс ощущается вялой, 100 мс — заметно, < 50 мс — мгновенно.

## Если всё-таки прерывание
Используй прерывание только чтобы **разбудить** МК или запустить опрос. Дальше тот же программный фильтр по тику.
Альтернатива — запретить прерывание кнопки на время дребезга (например, 20 мс) и включить его снова по таймеру.

## Матрица клавиатуры
- **Строки × столбцы:** M×N кнопок на M+N линиях. Строки — выходы с высоким уровнем, столбцы — входы с pull-up.
  По очереди опускаешь строку в 0 и читаешь столбцы: нажатая кнопка даёт 0. Нужен постоянный опрос,
  прерывание по изменению не работает. При нескольких нажатиях одновременно бывают «фантомы» — лечатся диодами.
- **Charlieplexing:** N линий дают N²−N кнопок или светодиодов (с диодами). Каждая линия по очереди
  становится выходом, остальные читаются. Логика сложнее, обычно это автомат.
- Те же приёмы работают для вывода: мультиплексированные светодиоды и 7-сегментные индикаторы
  (обновление ≥ 30 Гц, иначе мерцает, а каждый сегмент горит 1/N времени).

## ESP8266 (D1 mini)
- Кнопку подключай между выводом и GND, `pinMode(pin, INPUT_PULLUP)`: нажата = `LOW`.
- Подходят D1 (GPIO5), D2 (GPIO4), D5–D7 (GPIO14/12/13). **Нельзя** кнопку на GND на D3 (GPIO0) и D4 (GPIO2):
  нажатие при включении сорвёт загрузку. D8 (GPIO15) должен быть LOW при старте.
- Опрос в `loop()` раз в 5–10 мс по `millis()` плюс `debounce_update()`. Прерывание с `IRAM_ATTR` — только
  если нужно ловить короткие импульсы или просыпаться.
