# Оглавление конспектов embedded-c

Источник: Elecia White, «Making Embedded Systems», 2-е изд. (O'Reilly, 2024). Конспекты пересказывают книгу
своими словами. Книга не привязана к конкретному процессору, поэтому идеи здесь переложены на общий C99,
а в конце каждого раздела есть пометка **ESP8266**: как это выглядит на Wemos D1 mini (Arduino + PlatformIO).

| Файл | Глава | О чём |
|---|---|---|
| `01-architecture.md` | 1, 2, 4 | слои, HAL, драйверы, интерфейсы модулей, адаптер/фасад, DI, «ООП на C», версия прошивки |
| `02-bringup-tests-errors.md` | 3 | даташиты, схемы, тесты железа (POST/юнит/bring-up), командный интерфейс, коды ошибок |
| `03-registers-gpio.md` | 4 | регистры, `volatile`, read-modify-write, SET/CLR и W1C, GPIO, подтяжки, board-header |
| `04-interrupts.md` | 5 | как работает прерывание, вектор, латентность, реентерабельность, критические секции |
| `isr-rules.md` | 4–6, 13 | **короткий свод правил ISR** |
| `05-timers-pwm-tick.md` | 4, 5 | таймер (прескалер/сравнение), ШИМ, системный тик, переполнение счётчика времени |
| `06-main-loop-scheduling.md` | 5, 6 | варианты главного цикла, флаги событий, мини-планировщик, гонки, инверсия приоритетов |
| `07-state-machines.md` | 6 | конечные автоматы: `switch`, скрытые переходы, по событиям, табличный |

| `18-debugging-faults.md` | 9 | баги оптимизации, hard fault, core dump, red zones, стек |
| `19-connected-ota.md` | 10 | протоколы, версии, CRC, безопасность, загрузчик, OTA, телеметрия |
