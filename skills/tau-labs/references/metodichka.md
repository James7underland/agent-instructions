## Общие требования к оформлению (с. 5–6)
- Перед работой — конспект: название, цель, краткая теория, ход работы. Отчёт = конспект + расчёты + графики + выводы.
- Формулы в явном виде, выкладки до конца, **без кода и обозначений математических пакетов**.
- Графики: линейный масштаб — не меньше А5, логарифмический — не меньше А4; оси подписаны с единицами,
  начало координат отмечено, есть масштабная и координатная сетки; декада = 10 клеток; ЛАЧХ и ЛФЧХ — на одном
  графике; АФЧХ — одинаковый масштаб по осям; экспериментальные точки — только точками, без проекций на оси.
- Грубые недочёты оформления → работу не принимают к защите.

## ЛР-2. Колебательное звено (с. 17–23, CONTROL)
- W(p) = K/(T²p² + 2ξTp + 1), 0 < ξ < 1; K, T и диапазон ξ задаёт преподаватель (ξ в программе — переменная A).
- CONTROL: R=1, G=0, H=0, f(t)=1 → переходная h(t); АЧХ (замкн. раздел); для ЛАЧХ/ЛФЧХ и АФХ — H=1 и разрыв в
  точке h; на АФХ 10–12 равномерных точек с разметкой частот (диапазон/шаг одинаковы для всех ξ).
- Отчёт: W(p), дифф. уравнение, аналитические выражения АФХ/АЧХ/ЛЧХ/h(t), **семейства** характеристик по ξ
  (удобно в Mathcad). Вопросы: виды воздействий, временные/частотные характеристики, влияние ξ.

## ЛР-3. Критерий Найквиста, запаздывание (с. 24–31, CONTROL)
- Вариант А — статическая система: 1/(T1p+1) · 1/(T2p+1) · K/(T3p+1); вариант Б — астатическая: 1/p вместо первого.
- Kкр по алгебраическому критерию и по Найквисту (|W(jω1)| при φ = −π: Kкр = K/|W(jω1)|); для астатической — дуга
  бесконечного радиуса на графике.
- Запаздывание (вариант А): K = (0.4…0.45)·Kкр, τ = 0 и ещё 3–4 значения (шаг ≈ (0.15…0.2)·T1), семейство АФХ с
  одинаковой разметкой частот; τкр = (π − |φ(ωк)|)/ωк при |W(jωк)| = 1 (угол в радианах). Запасы по фазе и амплитуде.

## ЛР-4. Показатели качества САР (с. 32–40, CONTROL)
- Схема: R = 1/(T1p+1), W = K/((T2p+1)(T3p+1)), T1 > T2 > T3 — от преподавателя.
- Предварительно: Kкр; Ki = 0.1…0.4·Kкр шаг 0.05·Kкр; hуст = Ki/(1+Ki), трубка ±5 % hуст.
- Для каждого K: M (по АЧХ замкнутой), η (степень устойчивости), μ (колебательность) из таблицы корней;
  δ (стат. ошибка), σ (перерегулирование), tp по переходной. Графики от K; σ = f(M), σ = f(μ).
- Выбрать K при M = 1.2…1.5 → переходная; замена R на 1/p (астатическая), подобрать K на то же M, сравнить.

## ЛР-5. Оптимальный ПИ-регулятор (с. 41–50, CONTROL)
- R(p) = Kp(Tи p + 1)/(Tи p); минимум J1 = Tи/(Kp·Ko) при M ≤ Mзад → максимум Kp/Tи.
- Tи от 0.5·To.max до 2.5·To.max с постоянным шагом; для каждого подбором Kp при M = Mзад; график Kp/Tи = f(Tи),
  максимум → оптимум; переходная при оптимуме + ещё 4 при Tи = 1.5, 2, 1/1.5, 1/2 от оптимума (σ, tp).

## ЛР-6. Многосвязная САУ (с. 51–61, CONTROL + MVACS2)
- Объект 2×2: Wij = Kij/(aij p² + bij p + 1) (коэфф. от преподавателя); регуляторы: а) два П; б) П + ПИ.
- Часть 1: настроить каждый контур отдельно (M = 1.3…1.5), затем в MVACS2 «Неавтономное управление»:
  характеристическое уравнение, корни, μ, переходные при (f1=1, f2=0) и (f1=0, f2=1); сравнить.
- Часть 2: компенсаторы Q12 = −W12/W11, Q21 = −W21/W22, эквивалентные W11э = W11 − W12W21/W22,
  W22э = W22 − W12W21/W11; перенастроить регуляторы, переходные в автономной системе, сравнить с частью 1.
