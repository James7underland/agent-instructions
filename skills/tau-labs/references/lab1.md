# ЛР-1. Экспериментальное определение частотных характеристик динамического звена

Методичка: Великанов Д.Н., Мартынова А.Ю. «ТАУ. Часть 1. Линейные системы», 2019, с. 7–16.
Программа: ТАУ-3 → LINSYS («Разомкнутая система», «Периодический сигнал» → «Установившийся процесс»).

## Объект и формулы
W(p) = K / (a2·p² + a1·p + 1) (a0 = 1), вход u = Um·cos(ωt).
- Периоды: T0 ≈ (80…100)·√a2 (≈ «ω = 0»), T1 ≈ (12…13)·√a2, Ti+1 = (0.8…0.85)·Ti; 12–13 измерений
  (студенты делают 13–15, в образцах 15: T0…T14).
- Измеряется курсором: Xm i (амплитуда выхода), ΔTi (сдвиг выхода относительно входа по времени) → графы 1–3.
- Расчёт: ωi = 2π/Ti; A(ωi) = Xm i/Um; φ(ωi) = ±ΔTi/Ti·360° (выход отстаёт → «−»); L(ωi) = 20·lg A(ωi) [дБ].
- Аналитика: U(ω) = K(1 − a2ω²)/D, V(ω) = −K·a1·ω/D, D = (1 − a2ω²)² + a1²ω²; A = K/√D;
  φ = −arctg(a1ω/(1 − a2ω²)) при ω < 1/√a2, φ = −180° − arctg(a1ω/(1 − a2ω²)) при ω > 1/√a2.
  ξ = a1/(2√a2), ω0 = 1/√a2 (φ = −90°), ωр = ω0·√(1 − 2ξ²), Amax = K/(2ξ√(1 − ξ²)), M = Amax/K.
- Графики (методичка, с. 15): АФЧХ с разметкой частот, АЧХ, ФЧХ, ЛАЧХ+ЛФЧХ на одном графике; точки из
  таблицы 1 соединяются аналитическими кривыми. АФЧХ — одинаковый масштаб по осям. Оси подписаны,
  сетка обязательна; лог. масштаб — декада = 10 клеток (с. 5–6).

## Лист Mathcad студентов (`assets/lab1_template.xmcd`; графики из него в отчёт больше не идут — см. tauplot)
Регионы: Um, a2, a1, a0, K; векторы T, Xm, ΔT; ω := 2π/T; A := Xm/Um; φ := −ΔT/T·360; L := 20·log(A);
W(p) → символьно; A1(w) := |W(i·w)|; **график АЧХ** (A от ω точками + A1(w)); W(i·w) → complex;
U(w), V(w) — вписаны числами из символьного результата; φ1(w) — программа с ветками по знаку U;
**график ФЧХ**; W1 := cos(φ°) + i·sin(φ°) (единичные векторы); **АФЧХ** (Im(W1·A) от Re(W1·A) точками +
Im(W(i·w)) от Re(W(i·w))); L1(w) := 20·log(A1(w)); **ЛАЧХ+ЛФЧХ** (L1, L слева; φ1, φ справа, лог. ось X).
Кривые — QuickPlot по `w` (w не определена): диапазон берётся из пределов оси X, поэтому пределы важны.
Пределы и сетка в графиках заданы вручную (пример 2.9/0.85/2/0.8: АЧХ 0…4.2 × 0…4.8, 42×24 деления) —
lab1.py пересчитывает их под вариант.

## Ошибки в тетради-образце (не повторять)
- L(ω7) записан как −14,12 в таблице и −1,412 в расчёте (верно −1,412).
- У L(ωi) единицы «рад/с» — должно быть дБ.
- В листе Mathcad строка `L2(w) := 20·log(φ1(w))` — логарифм фазы, бессмыслица (скрипт её удаляет).
- На распечатке АФЧХ нет разметки частот, хотя методичка требует → теперь ставится автоматически (tauplot).
- Подписи Mathcad под осями («ω, w», «Re(W1·A), Re(W(i·w))») вместо «ω, рад/с» — преподаватель принимал.
