Каталог скилла — папка с этим `SKILL.md` (ниже пути относительно неё). Методичка и образцы — в папке лабы пользователя

`...\ТАУ лабы\5 семестр\Лаб-N\Отчёты\<Фамилия>\`, а не в папку скилла и не во временную папку.
Эталон итогового оформления (согласован с пользователем 03–04.10.2026) — «образец 3»: вариант a2 = 2,8, a1 = 0,9,
K = 0,9, Um = 1,5 (его шаги и клетки приведены ниже).

## Как сдаётся лаба (что генерируем)
Отчёт у этого преподавателя = **рукописная тетрадь** (тему, цель, теорию, ход работы студент пишет сам из методички;
плюс исходные данные, расчёты, таблица 1, выводы) + **распечатка графиков** (альбомный А4, «Рисунок N – …»)
+ при необходимости печатный титул. В папке человека — только то, что сдаётся:

| файл | что внутри |
|---|---|
| `<Фамилия>_ЛР1_тетрадь.docx` | заголовок («Лабораторная работа № 1», тема, «Выполнил: …»), затем **только** исходные данные, расчёты (цепочка периодов, ω/A/φ/L с подстановкой), таблица 1, аналитические выражения — все формулы формулами Word; без пояснений, выводов и вопросов |
| `<Фамилия>_ЛР1_графики.docx` | 4 рисунка в натуральную величину (+ титул с `--title-page`) |
| `<Фамилия>_ЛР1.xmcd` | расчётный лист Mathcad 13 (пересчитан, 0 ошибок), автор = студент |
| `служебное/` | `data.json` (все числа и геометрия графиков), `plots/*.png`, `контрольные_вопросы.docx` (ответы для защиты) — пользователю, не преподавателю |
| с `--lach-variants` | `<Фамилия>_ЛР1_графики_разные_нули.docx`, `…_графики_общий_ноль_дробный_шаг.docx` (комплекты, где другой только рисунок 4) и `<Фамилия>_ЛР1_ЛАФЧХ_6_вариантов.docx` — см. «ЛАЧХ+ЛФЧХ», варианты |

## Ничего «машинного» в сдаваемых файлах (важно)
Пользователь явно просил: никаких подписей, что делал не человек. Поэтому:
- в тексте тетради нет пометок вроде «что здесь», «пример:», «рекомендуется», «сгенерировано»;
- docx: автор/последний редактор = студент, пустые comments (python-docx по умолчанию пишет «generated by
  python-docx»), `app.xml` — «Microsoft Office Word» вместо «Microsoft Macintosh Word» (`save_docx`);
- xmcd: в шаблоне был e-mail автора образца и его `documentID` — заменяются на имя студента и свои ID
  (`set_sheet_identity`, `-Meta` в mc.ps1, правка `revisedBy` после сохранения);
- PNG без метаданных Software; в файлах вариантов графиков нет пометок, какой вариант какой.
  Новые генераторы — так же: проверяй `docProps/core.xml`, `app.xml`, `<metadata>`.

## Числа: разные люди — разные числа, точность 3 знака
- **Вариант** (a2, a1, K, Um) выдаёт преподаватель — спроси у пользователя (или возьми из листа/фото человека).
  Нет варианта / «придумай» — случайный правдоподобный (a2 2–4, a1 0.6–1.2, ξ 0.15–0.33, K 1–3, Um 0.5–1.6).
- **«Почерк»** от ФИО (seed = crc32 имени): T0 = (80…100)·τ, T1 = (12…13)·τ, q = 0.80…0.85, 13–15 точек.
  Одинаковое ФИО → те же числа. Другие числа тому же человеку → `--seed N`.
- **Измерения**: теория + шум ≈0.3 %; фаза строго убывает, A монотонна до/после пика.
- **Точность (по умолчанию, `--dec 3`)**: τ, T, Xm, ΔT, ω, A, φ, L — 3 знака после запятой; периоды цепочкой
  (T2 = 0,8·20,913 = 16,73), A, φ, L считаются из уже округлённых величин, поэтому каждая строка расчёта сходится
  на калькуляторе (20 lg 0,011 = −39,172). **В таблице 1 — ровно 3 знака** (16,730; 0,040; минус «−»),
  **в расчётах тетради незначащие нули убраны** (16,73; 0,04; 0,3). `--dec 0` — прежнее округление «как с экрана»
  (сотые/тысячные/3 значащие).
- **Никогда не копируй чужие Xm/ΔT** из образцов (второй образец `lab_1_tay.xmcd` ходит по группе под разными именами).

## Графики — строятся с нуля (`scripts/tauplot.py`), правила для всех лабораторных
Экспорт графиков Mathcad не используем: там неквадратные клетки и подписи выражений («Re(W1·A), Re(W(i·w))»)
вместо подписей осей. Всё ниже — требования методички (с. 5–6) и пользователя, все обязательны.

### Общее для всех рисунков
0. **ГЛАВНОЕ ПРАВИЛО (пользователь, 05.10.2026): каждое деление на каждой оси подписано — всегда, на всех
   графиках, ни одно число не пропускается** (линейные оси — каждая линия сетки; обе шкалы ЛАФЧХ, включая 0°).
   **Исключение — логарифмическая ось ω ЛАФЧХ: только декады и края диапазона** (0,03; 0,1; 1; 6), промежуточные
   линии 2…9 без чисел — пользователь попросил вернуть так же 05.10.2026. Как: `crossed_axes(...,
   all_numbers=True)` во всех графиках; широкие числа — мельче шрифтом (9,5 → 7 pt, зазор между соседними ≥ 1,5 мм),
   через линию — только если не влезает и 7 pt; подпись оси не вытесняет числа, а уходит за их ряд (АЧХ: «ω, рад/с»
   под рядом чисел); число правой шкалы на линии стрелки оси ω — над стрелкой; подписи частот и выноски обходят
   числа (`reserve_numbers`). Проверять глазами на PNG: все ли линии подписаны.
1. **Формат Crossed** (как в Mathcad): рамки нет, оси проходят через 0 (или по краю сетки, если 0 вне
   диапазона), на концах осей **стрелки** за пределы сетки, **подписи осей — у концов стрелок**
   («ω, рад/с», «A(ω)», «φ(ω), град», «L(ω), дБ», «Re W(jω)», «Im W(jω)»), **числа — вдоль осей**
   (`Sheet.crossed_axes`). Стрелки короткие (6–7 мм), подпись горизонтальной оси — у конца стрелки
   (`xarrow=7`), с той стороны оси, где нет чисел, иначе — за рядом чисел (у ЛАЧХ подпись у правого края сетки).
2. **Сетка — целое число клеток**, клетка может быть дробной (9,64 мм), масштаб «1 клетка = шаг»; картинка
   вставляется в Word **в натуральную величину** (`Mm(width_mm)`). Проверка: PDF → `page.get_image_info()` →
   размер совпадает с `width_mm × height_mm` из `data.json` (точность 0,05 мм).
3. **Лист**: альбомный А4, поля 5 мм (в образце `Doc1123.docx` 0 мм — принтер обрежет), рисунок ≤ 287 × 190 мм
   + подпись «Рисунок N – …». Абзац с картинкой — одинарный интервал, новая страница через `page_break_before`.
4. **Легенда — только формулы**: «A(ω)» / «A(ωᵢ)», «φ(ω)» / «φ(ωᵢ)», «L(ω)», «L(ωᵢ)» — без слов «расчёт»,
   «эксперимент»; у АФЧХ легенды нет.
5. **Кривые гладкие** (тысячи точек; АФЧХ — ω по логарифмической сетке 1e-4…1e3 + ω = 0), точки — маркерами.

### АЧХ и ФЧХ — строго на весь лист (287 × 190 мм)
Диапазон = данные, округлённые до шага (≤ 1 пустой клетки): АЧХ — до пика кривой, ω — до последней точки,
ФЧХ — ровно −180…0°. `plan_exact`: самый мелкий «круглый» шаг с клеткой ≥ 7 мм, клетка = место / число клеток
(у образца 3 0,2 рад/с × 0,1 → 9,64 × 9,72 мм; ФЧХ 0,2 рад/с × 10°). Легенда ФЧХ — справа по центру.

### АФЧХ — НЕ на весь лист
- **Квадратная клетка, один шаг по Re и Im** (`plan_square_exact(..., fill=False)`), масштаб максимальный, вокруг
  кривой **1–2 свободные клетки** (запас 1, сверху 2 + округление до шага; больше — только если подписи частот не
  влезли); рисунок по ширине уже листа (у образца 3 191 × 190 мм, клетка 8,5 мм, шаг 0,1).
- **Все деления осей подписаны** (п. 0): `reserve_numbers` занимает их места (с запасом `NUM_PAD` = 0,6 × 0,35 мм)
  до раскладки подписей частот, `crossed_axes(..., all_numbers=True)` ставит все.
- **Разметка частот** «ω₁ = 0,300» (индекс — номер строки таблицы 1, три знака) + «ω = 0» у точки K;
  `Sheet.place_labels` — подписи и выноски не пересекают кривую, оси, точки, числа и друг друга.
  **«Гроздь» у начала координат** (≥ 3 точек ближе 8 мм, хвост ω → ∞) — `stack_labels`: столбиком внутри петли
  правее и ниже нуля, выноски веером (ближняя к нулю точка — верхняя подпись), их линии — препятствия для
  остальных. Если прямая выноска задевает число оси Im (точки и числа — левее оси), выноски всех подписей идут с
  изломом лесенкой: полого под осью Re правее оси Im, потом к подписи (вложенные, не пересекаются).
  `afch.unplaced` должен быть пуст.

### ЛАЧХ + ЛФЧХ — один график на весь лист
- **Ось ω обрезана по точкам**: от линии сетки m·10^k перед первой точкой до линии после последней (`log_nice`),
  например 0,03 … 6; подписаны только декады внутри и оба края (0,03; 0,1; 1; 6) — все линии 2…9 подписывать НЕ
  надо (пробовали 05.10.2026, пользователь вернул); сетка на всю ширину, все декады одной ширины. Ось ω — по линии
  L = 0 со стрелкой, её числа — по нижнему краю сетки.
- **Подписана каждая линия обеих шкал**, деления обеих шкал — на одних линиях сетки; число фазы на линии L = 0
  (при общем нуле — 0°) стоит чуть выше стрелки оси ω.
- **Основной вариант (`lach_mode="nice"`) — нули шкал на одной линии, «хорошие» шаги на клетку: 1|2 дБ и 5|10°.**
  z клеток ниже нуля: z·шаг_L ≥ |L_min| и z·шаг_φ ≥ 180° (фаза может уйти ниже −180°, если иначе не сходится);
  из пар — с наименьшей долей пустых клеток (уход фазы ниже −180° — вдвое дороже), клетка ≥ 4,5 мм.
  у образца 3 2 дБ / 10°: −42…+6 дБ, −210…+30°, клетка 7,3 мм. На 30 вариантах фаза снизу −180…−210°.
- Почему не «1 дБ»: при общем нуле и ЛАЧХ до −41 дБ это 48 клеток по 3,2 мм и 3,75° на клетку — пользователь
  смотрел и выбрал 2 дБ / 10°.
- **Варианты** (`--lach-variants`, для выбора; другой только рисунок 4):
  - `split` (`…_графики_разные_нули.docx`) — нули на разной высоте, обе шкалы с нижней линии (L_min по шагу и
    −180°), шаги 1|2 дБ и 5|10°: у образца 3 −42…+6 дБ и −180…+60°;
  - `exact` (`…_графики_общий_ноль_дробный_шаг.docx`) — нули совпадают, фаза ровно от −180°, 10° на клетку,
    шаг дБ — наименьший из 1/2/2,5/4/5/10 (у образца 3 2,5: −45…+7,5 дБ, −180…+30°);
  - `<Фамилия>_ЛР1_ЛАФЧХ_6_вариантов.docx` — 6 листов: nice, split, exact с точками измерений, затем те же три с
    **точками, подогнанными к расчётным кривым** (`fitted(d)`: теоретические L, φ на тех же ωᵢ); у всех подпись
    «Рисунок 4 – …», без пометок, какой лист какой (порядок сообщить пользователю в ответе). Подогнанные точки
    не совпадают с таблицей 1 — предупредить.

## Формулы в Word (`scripts/wordmath.py`)
Все формулы в тетради — настоящие формулы Word (OMML): LaTeX → MathML (`latex2mathml`) → OMML (`MML2OMML.XSL`
из Office). `eq(paragraph, r"...")`, числа — `tex_num(x)` (запятая как `{,}`). Грабли конвертера: `\,` и `\quad`
пропадают — пробелы только `\ `; `\operatorname{}` даёт курсив — функции как `\mathrm{arctg}\ `, `\lg\ `;
число перед `^{\circ}` — в фигурных скобках (иначе «−169, 689°»); градусы в заголовке таблицы — словом «град».
Проверка: Word COM `Document.OMaths.Count` > 0 (у ЛР-1 — 97).

## Рабочий процесс (ЛР-1)

   ```
   python "<скилл>/scripts/lab1.py" check "<Лаб-1>/Отчёты/Иванов/служебное/data.json"
   ```
   Один человек ≈ 40 с (с `--lach-variants` ≈ 60 с; графики ≈ 3–11 с, остальное — Mathcad).
4. Перед пересборкой проверь, что docx человека не открыты в Word (файлы `~$…docx` рядом) — иначе

5. Проверь: `Mathcad ошибок: 0`; открой `служебное/plots/*.png` (точки на кривых, подписи частот на месте, все

6. Отдай пользователю путь к папке и кратко: вариант, T0/q/число точек, шаги и клетки графиков.
   Напомни, что тему/цель/теорию/ход работы и выводы студент пишет в тетрадь сам.
