# Лабы по ТАУ — отчёты «под человека»

Каталог скилла — папка с этим `SKILL.md` (ниже пути относительно неё). Методичка и образцы пользователя:
`<папка_лабораторной_работы>` (`Мет_ТАУ_лин(ЛР)_19.pdf`, фото тетради, `lab1.xmcd`,
`vlad_tay.xmcd`, `Doc1123.docx` с графиками). Результаты для людей класть рядом с лабой:
`<папка_лабы>/Отчёты/<Фамилия>/`, а не в папку скилла и не во временную папку.

## Как сдаётся лаба (что генерируем)
Отчёт у этого преподавателя = **рукописная тетрадь** (тему, цель, теорию, ход работы студент пишет сам из методички;
плюс исходные данные, расчёты, таблица 1, выводы) + **распечатка графиков** (альбомный А4, «Рисунок N – …»)
+ при необходимости печатный титул. В папке человека — только то, что сдаётся:

| файл | что внутри |
|---|---|
| `<Фамилия>_ЛР1_тетрадь.docx` | заголовок («Лабораторная работа № 1», тема, «Выполнил: …»), затем **только** исходные данные, расчёты (цепочка периодов, ω/A/φ/L с подстановкой), таблица 1, аналитические выражения — все формулы формулами Word; без пояснений, выводов и вопросов |
| `<Фамилия>_ЛР1_графики.docx` | 4 рисунка в натуральную величину (+ титул с `--title-page`) |
| `<Фамилия>_ЛР1.xmcd` | расчётный лист Mathcad 13 (пересчитан, 0 ошибок), автор = студент |
| `служебное/` | `data.json` (все числа и геометрия графиков), `plots/*.png`, `контрольные_вопросы.docx` (ответы для защиты) — пользователю, не преподавателю |

## Ничего «машинного» в сдаваемых файлах (важно)
Пользователь явно просил: никаких подписей, что делал не человек. Поэтому:
- в тексте тетради нет пометок вроде «что здесь», «пример:», «рекомендуется», «сгенерировано»;
- docx: автор/последний редактор = студент, пустые comments (python-docx по умолчанию пишет «generated by
  python-docx»), `app.xml` — «Microsoft Office Word» вместо «Microsoft Macintosh Word» (`save_docx`);
- xmcd: в шаблоне был e-mail автора образца и его `documentID` — заменяются на имя студента и свои ID
  (`set_sheet_identity`, `-Meta` в mc.ps1, правка `revisedBy` после сохранения);
- PNG без метаданных Software. Новые генераторы — так же: проверяй `docProps/core.xml`, `app.xml`, `<metadata>`.

## Разные люди — разные числа
- **Вариант** (a2, a1, K, Um) выдаёт преподаватель — спроси у пользователя (или возьми из листа/фото человека).
  Нет варианта / «придумай» — случайный правдоподобный (a2 2–4, a1 0.6–1.2, ξ 0.15–0.33, K 1–3, Um 0.5–1.6).
- **«Почерк»** от ФИО (seed = crc32 имени): T0 = (80…100)·τ, T1 = (12…13)·τ, q = 0.80…0.85, 13–15 точек.
- **Измерения**: теория + шум ≈0.3 % + округление отсчёта курсором; фаза строго убывает, A монотонна до/после пика.
- Одинаковое ФИО → те же числа. Другие числа тому же человеку → `--seed N`.
- **Никогда не копируй чужие Xm/ΔT** из образцов (напр. `vlad_tay.xmcd` = копия `lab_1_tay.xmcd`).

## Графики — строятся с нуля (`scripts/tauplot.py`), правила для всех лабораторных
Экспорт графиков Mathcad не используем: там неквадратные клетки и подписи выражений («Re(W1·A), Re(W(i·w))»)
вместо подписей осей. Требования (методичка с. 5–6 + пожелания пользователя, все обязательны):
1. **Формат Crossed** (как в Mathcad): рамки нет, оси проходят через 0 (или по краю сетки, если 0 вне
   диапазона), на концах осей **стрелки** за пределы сетки, **подписи осей — рядом с концами стрелок**
   («ω, рад/с», «A(ω)», «φ(ω), град», «L(ω), дБ», «Re W(jω)», «Im W(jω)»), **числа — вдоль осей**
   (`Sheet.crossed_axes`). Число, которое легло бы на кривую/точку/подпись частоты, не ставится.
2. **Миллиметровка**: сетка = целое число клеток, клетка = целое число мм (5–12), картинка вставляется в Word
   **в натуральную величину** (`Mm(width_mm)`). Проверка: PDF → `page.get_image_info()` → размер совпадает с
   `width_mm × height_mm` из `data.json` (точность 0,02 мм).
3. **АФЧХ/годографы — квадратная клетка и один шаг по Re и Im** (`plan_square`), **без легенды**.
4. **Разметка частот на АФЧХ** в виде «ω₁ = 0,293» (индекс — номер строки таблицы 1, три знака) (и подписи кривых «L(ω)», «φ(ω)» на ЛАЧХ) — `Sheet.place_labels`, вызывать ДО
   `crossed_axes`: подписи и выноски не пересекают кривую, оси, точки и друг друга; у начала координат —
   веером с выносками; выноски не пересекаются друг с другом и не проходят через чужие подписи (несколько
   порядков раскладки + повтор с бо́льшим запасом клеток). `afch.unplaced` должен быть пуст (проверено на 60 вариантах).
5. **Легенда — только формулы**: «A(ω)» / «A(ωᵢ)», «φ(ω)» / «φ(ωᵢ)», «L(ω)», «L(ωᵢ)»… — без слов
   «расчёт», «эксперимент».
6. **ЛАЧХ+ЛФЧХ на одном графике**, общая ось ω (декада = 10 клеток), **0 левой шкалы и 0 правой — на одной
   горизонтали**: z делений ниже нуля (z·шаг_φ = 180°, шаг_φ 10/15/20/30°), столько же делений у L; шаг L —
   наименьший из 1/2/2,5/4/5/10 дБ, при котором точки помещаются. Ось ω — по нулевой линии со стрелкой, её
   числа — по нижнему краю сетки (у нулевой линии тесно от кривых), **подписываются только декады** (0,01; 0,1; 1; 10).
7. **Кривые гладкие** (тысячи точек; АФЧХ — ω по логарифмической сетке 1e-4…1e3 + ω = 0), точки — маркерами.
8. **Место — рационально, без пустой сетки**: диапазон осей = данные, округлённые до шага (не больше одной пустой
   клетки: АЧХ — до пика кривой, ω — до последней точки, ФЧХ — ровно −180…0°); клетка — целые мм, как можно крупнее,
   чтобы кривая заняла максимум листа (`plan_fill`: из «круглых» шагов, дающих ≥ 92 % от самого крупного рисунка,
   — самый мелкий). Лист **не добивается пустыми клетками**: если в одном направлении место осталось (у АФЧХ из-за
   квадратной клетки — всегда), рисунок там просто уже. АФЧХ — `plan_square_fill`: максимальный масштаб при
   квадратной клетке, запас вокруг кривой минимальный (1 клетка, сверху 2), больше — только если подписи частот
   не влезли. ЛАЧХ — декады целиком (просьба пользователя), шкалы по вертикали без клеток над пиком.
9. **Лист**: альбомный А4, поля 5 мм со всех сторон (в образце `Doc1123.docx` 0 мм — принтер обрежет), рисунок
   ≤ 287 × 190 мм + подпись «Рисунок N – …». Абзац с картинкой — одинарный интервал, новая страница через
   `page_break_before`. Проверка: PDF → 4 страницы, от рисунка и подписи до краёв листа ≥ 5 мм.

## Формулы в Word (`scripts/wordmath.py`)
Все формулы в тетради — настоящие формулы Word (OMML): LaTeX → MathML (`latex2mathml`) → OMML (`MML2OMML.XSL`
из Office). `eq(paragraph, r"...")`, числа — `tex_num(x)` (запятая как `{,}`). Грабли конвертера: `\,` и `\quad`
пропадают — пробелы только `\ `; `\operatorname{}` даёт курсив — функции как `\mathrm{arctg}\ `, `\lg\ `;
градусы в заголовке таблицы — словом «град». Проверка: Word COM `Document.OMaths.Count` > 0.

## Рабочий процесс (ЛР-1)
1. Прочитай `references/known-issues.md`; для ЛР-1 — `references/lab1.md`. Другая лаба → `references/metodichka.md`
   и раздел «Расширение».
2. Собери данные: ФИО, группа, вариант, нужен ли титул и кто проверяет. Несколько человек → CSV
   `name;group;a2;a1;K;Um[;seed]`.
3. Запуск (Mathcad 13 + скилл `mathcad13` нужны только для .xmcd; без них `--no-mathcad`):
   ```
   python "<скилл>/scripts/lab1.py" make --name "Иванов И.И." --group АТ-23-01 --a2 2.9 --a1 0.85 --K 2 --Um 0.8 --out "<Лаб-1>/Отчёты" [--title-page --teacher "Мартынова А.Ю."]
   python "<скилл>/scripts/lab1.py" batch people.csv --out "<Лаб-1>/Отчёты" [--title-page]
   python "<скилл>/scripts/lab1.py" check "<Лаб-1>/Отчёты/Иванов/служебное/data.json"
   ```
   Один человек ≈ 15–20 с.
4. Проверь: `Mathcad ошибок: 0`; открой `служебное/plots/*.png` (точки на кривых, подписи частот на месте);
   Word → PDF → PNG страниц и размеры картинок в PDF; метаданные (см. выше).
5. Отдай пользователю путь к папке и кратко: вариант, T0/q/число точек, размер клетки графиков.
   Напомни, что тему/цель/теорию/ход работы и выводы студент пишет в тетрадь сам.

## Расширение на ЛР-2…6
Конспект всех работ — `references/metodichka.md`. Для новой лабы N:
1. Взять у пользователя образцы (фото тетради, .xmcd, docx) → что пишется руками, что печатается.
2. `scripts/labN.py` по образцу `lab1.py`: числа («эксперимент» в CONTROL/MVACS2 считать теоретически — скилл
   `tau3`, `check.py`; шум как в ЛР-1), графики — только через `tauplot` по правилам выше (семейства кривых —
   разными цветами/типами линий, подписи кривых через `place_labels`), тетрадь — только данные/расчёты/таблицы/
   выражения, метаданные — как в разделе «Ничего машинного».
3. `references/labN.md`, строка в таблице, упоминание в description.
