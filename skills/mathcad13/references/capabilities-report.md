# Проверка возможностей Mathcad 13 (раунды 2026-09-24 и 2026-09-25)

Окружение: Windows 11 Pro (x64), Mathcad 13.0.3 в `C:\Program Files (x86)\Mathsoft\Mathcad 13`, .NET 1.1
установлен, 32-битный PowerShell 5.1, Python 3.14 (+ python-docx, lxml, Pillow, PyMuPDF; без pywin32),
MS Word и Excel есть (COM). Библиотеки расширений в `mpl\`: Data Analysis, Signal, Image, Wavelets.
Тестовые листы: `examples/beam.txt`, лист «features» (139 регионов) и раунд 2 —
`...\Mathcad 13 Claude\Примеры\Тесты раунд 2\` (r2_solvers, r2_minerr, r2_files, r2_plots, r2_format, r2_text, чужие\).

✔ — работает; ⚠ — работает с оговорками; ✘ — не работает / нет в MC13.
