# Грабли Simulink (MATLAB R2025b, Windows 11)

Формат: **симптом** → причина → что делать. Новое дописывать в конец нужного раздела.

## Запуск MATLAB в пакетном режиме
- **`matlab -batch` не находит файлы / «Unable to find file»** → из Git Bash в команду попали пути `/c/Users/...` →
  в MATLAB только пути Windows (`C:\Users\...`). Проще всего запускать через `scripts/mlrun.py` (сам переводит пути).
- **Кириллица в выводе — «кракозябры»** → консольный вывод MATLAB в cp866 → `| iconv -f cp866 -t utf-8`
  или `mlrun.py` (перекодирует сам).
- **Правка .m/.py через heredoc или `sed` в Git Bash портит `\n` в строках fprintf/sprintf** (`'...\n'` становится
  настоящим переводом строки → «Character vector is not terminated properly») → код с обратными слешами править
  только инструментами Write/Edit, не `cat <<EOF`, не `sed`, не `python -c "..."` из bash.
- **Графики MATLAB тёмные** (тёмная тема R2025b) → в начале скрипта
  `s = settings; s.matlab.appearance.figure.GraphicsTheme.TemporaryValue = 'light';` и всё равно явно
  задавать `fig.Color = 'w'`, `ax.Color = 'w'`.
- **Прогон завис или долго идёт** → запускать длинные расчёты в фоне с логом; убивать только свои процессы
  MATLAB (`Get-CimInstance Win32_Process -Filter "Name='MATLAB.exe'"` → по командной строке `-batch ...`).
  Открытый пользователем MATLAB (без `-batch`) не трогать.

## Построение модели программно
- **`add_line` → «Index exceeds array bounds» у подсистемы** → у подсистемы ещё нет портов (их создают In1/Out1
  внутри) → сначала заполнить подсистему, потом соединять её снаружи.
- **Линии идут вплотную к блокам, пересекаются** → `add_line(sys, 'A/1', 'B/1', 'autorouting', 'on')` рисует
  как попало → ломаные по реальным координатам портов (`slPort`, `slWire`), обратная связь — ниже контура
  с запасом ≥ 40 px, ветвления — отдельными `add_line` из точки на линии.
- **Сумматор: входы сверху/снизу, линии петляют** → круглый сумматор `IconShape = round`, `Inputs = '|+-'` или
  `'|++'`: первый вход слева (180°), второй снизу (270°). Знак «|» — пропуск позиции сверху.
- **На снимке модели пропадает «s» в `1/(5.2s+1)`** → печать сразу в PNG (`print -s -dpng`) теряет символы →
  печатать в PDF (`slPrint`) и переводить в PNG `scripts/crop_pdf.py` (обрезка полей, 300 dpi).
- **Подписи на снимке мелкие** → `FontSize = 16` для всех блоков и линий перед печатью (`slPrint` делает сам).
- **Transfer Fcn не принимает вектор** («Invalid dimension ... Input Port 1») → вход Transfer Fcn только скалярный;
  несколько вариантов настроек = несколько прогонов модели (SimulationInput), а не векторный сигнал.
- **Пользователь открывает модель и жмёт Run — ошибки** («Error evaluating expression 'Tstop' ... Unrecognized
  function or variable», «The expression ... in 'mdl/П1(ω)' has a syntax error» у Fcn) → параметры блоков —
  имена переменных, а значения передавались только из скрипта (SimulationInput) → **каждая сданная модель
  должна запускаться сама**: значения по умолчанию класть в Model Workspace
  (`hws = get_param(mdl,'ModelWorkspace'); assignin(hws,'P1',2.57)` до `save_system`), а в скриптах
  переопределять их там же: `in.setVariable('P1', v, 'Workspace', mdl)` — переменная Model Workspace
  заслоняет базовую, и `setVariable` без `'Workspace'` молча не подействует. Проверка перед сдачей:
  свежий MATLAB, `load_system` + `sim(mdl)` без подготовки — без ошибок.
- **Legacy XY Graph (sfunxy) убран** (с R2021b в R2025b только новый XY Graph на базе SDI) → в модели можно
  поставить для наглядности, но картинку для отчёта строить по сигналам журнала (см. ниже).

## Графики из Simulink (Scope, Simulation Data Inspector)
- **Scope нельзя выгрузить в фигуру программно** → в R2025b Scope веб-окно (`sltimescope`), «Print to Figure»
  работает только из его меню; в `findall(0,'Type','figure')` окна нет → графики берём из Simulation Data
  Inspector: `Simulink.sdi.snapshot('from','custom','to','figure','settings',snap)` (`scripts/matlab/sdiFigure.m`).
  Это тоже вывод Simulink и умеет совмещать прогоны одной модели с разными параметрами.
- **Снимок SDI пустой (оси есть, линий нет)** → в настройках SDI у графика сохранён вид «xy» (хоть раз вызывали
  `Simulink.sdi.setVisualization(1,1,'xy')` — настройка живёт между сеансами) → перед снимком
  `Simulink.sdi.setSubPlotLayout(n,1)` и `setVisualization(r,1,'timeplot')` для каждой строки (sdiFigure делает).
- **Линий на снимке нет сразу после `snapshot`** → SDI дорисовывает асинхронно (первый снимок до 10 с) → ждать
  в цикле `pause(0.5); drawnow` до появления линий, сверяя их с данными сигналов (sdiFigure, таймаут 60 с).
- **Сигнал блока Step (g, f) не находится среди линий** → SDI рисует его объектом `Stair`, а не `Line` →
  искать `findall(ax,'Type','line')` и `findall(ax,'Type','stair')`.
- **XY-график в SDI не заполнить программно** («Unable to plot signal ... on XY visualization»; у CustomSnapshot
  нет XY) → XY строить `plot` по сигналам из `out.logsout` той же модели и оформлять так же (crossAxes).
- **Старые прогоны пропадают из SDI** → автоархив → `Simulink.sdi.setAutoArchiveMode(false)`, в начале
  `Simulink.sdi.clear`. ID прогона после `sim`: `ids = Simulink.sdi.getAllRunIDs; ids(end)`.
- **Предупреждение «Exported image displays axes toolbar»** → `ax.Toolbar.Visible = 'off'` (prepFig).
- **Подписи `{\itt}, с` выводятся буквально** → у осей снимка SDI интерпретатор `none` → `'Interpreter','tex'`
  у каждого `text` (crossAxes ставит).
- **В подписях с TeX-разметкой пробелы вдвое шире** («t,  с», «m  =  0») → особенность интерпретатора tex →
  заменять пробел на U+2004 (пробел 1/3 em) в строках, где есть `{ } _ ^ \` (commaFig делает).
- **Деления шкалы «съехали» (1,2; 0,7; 0,2; −0,3)** → при расширении пределов шаг взят из автоделений, а начало
  не кратно шагу → деления задавать явно: `round((y1:s:y2)/s)*s` (niceY, fitLegend).
- **Легенда закрывает кривую** (незатухающие колебания во всю ширину) → `putLegend`/`fitLegend`: пока под рамкой
  легенды есть точки кривых, сетка расширяется на деление в сторону легенды.
- **Легенда лежит на оси t, хотя её сдвигали** → после сдвига `commaFig` меняет текст легенды, она
  пересчитывает размер и «съезжает» → сдвиг с оси делать последним шагом перед экспортом (`legendOffAxis`).
- **Пробелы вокруг `\psi`, `\approx` в tex широкие даже с U+2004** → писать слитно: `(\psi\approx0,75)`.
- **На оси «5,5511e-17» вместо 0** → `num2str(round(v, 9))`.
- **`XColor = 'none'` не убирает сетку** — это и нужно: встроенные шкалы скрыты, сетка остаётся, оси и числа
  рисует crossAxes.

## Обработка результатов
- **Маркеры амплитуд висят над пиками кривой** → амплитуды считались от среднего хвоста (у незатухающих колебаний
  среднее ≠ 0), а маркеры ставились на уровне амплитуды, а не значения x → амплитуды считать от теоретического
  установившегося значения, маркер ставить в точке кривой `(t_пик, x(t_пик))`.
- **Установившееся значение по среднему хвоста врёт на границе устойчивости** → брать теоретическое: с
  И-составляющей `x∞ = g`, у П-регулятора `x∞ = k(П1·g + f)/(1 + k·П1)`.
- **Точка «П-регулятора» на линии равного затухания получила П2 ≈ 5e-5** → конечный шаг сетки частот; такой
  «ПИ» с крошечной И-составляющей даёт статическую ошибку 0 и t_рег = ∞ → точки на осях обнулять явно
  (П1 = 0 у точки 1, П2 = 0 у точки 3).
- **Размер «T = …» между пиками нарисован посередине колебаний** → брался уровень амплитуды относительно
  среднего → размерная линия над двумя соседними пиками: выносные линии от пиков вверх, стрелки на обоих концах.
