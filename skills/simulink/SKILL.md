# Simulink — рабочий процесс

MATLAB R2025b с Simulink — папка установки (по умолчанию `C:\Program Files\MATLAB\R2025b`; проверка: `python scripts/mlrun.py --info`;
другая папка — переменная `MATLAB_ROOT`). Работаем только в пакетном режиме: модель строится и
прогоняется кодом, картинки выгружаются файлами. Каталог скилла — папка с этим `SKILL.md` (пути ниже
относительно неё). Рабочие файлы — в папке задачи пользователя, не в папке скилла.

## В начале задачи
1. `python "<скилл>/scripts/mlrun.py" --info` — есть ли MATLAB и Simulink.
2. Прочитай `references/known-issues.md` (обязательно) и последние записи `references/session-log.md`.
3. По задаче: модель из кода → `references/model-api.md`; графики для отчёта → `references/graphs.md`.

## Запуск MATLAB
```bash
python "<скилл>/scripts/mlrun.py" --cd "<папка задачи>" --timeout 1800 --log run.txt "build_model(pwd); lab_sim(pwd)"
```
`mlrun.py` переводит пути в формат Windows, добавляет `scripts/matlab` скилла в path, перекодирует вывод из cp866.
Длинные расчёты (минуты) — в фоне, с логом. Код `.m` писать и править только Write/Edit (heredoc и sed в Git Bash
портят `\n`). Свои процессы MATLAB можно завершать, открытый пользователем MATLAB — нет.

## Модель из кода — правила читаемости
- Основной контур на одной горизонтали, между блоками ≥ 80 px; обратная связь ниже контура с запасом;
  вспомогательные подсистемы (показатели качества) — над контуром, без пересечений линий.
- Линии — ломаными по координатам портов (`slPort`, `slWire`), не autorouting. Ветвление — отдельной линией
  из точки на существующей линии.
- Сумматоры круглые: `Inputs '|+-'` / `'|++'` → входы слева (180°) и снизу (270°), `ShowName off`.
- Подсистема: `slNewSubsystem`, внутри In1/Out1 с именами сигналов; соединять снаружи только после заполнения.
- Имена линий = обозначения сигналов (для САР: g — задание, e — ошибка, u — регулирующее воздействие,
  f — возмущение, y — вход объекта, x — выход); они же имена в журнале (`slLog`).
- Параметры блоков — именами переменных (`P1`, `tau`, `Tstop`) → все опыты одной моделью через SimulationInput.
  **Модель обязана запускаться кнопкой Run сама по себе** (пользователь откроет и запустит её в Simulink):
  значения по умолчанию — в Model Workspace, скрипты переопределяют их `setVariable(..., 'Workspace', mdl)`.
  Перед сдачей — `load_system` + `sim(mdl)` в свежем MATLAB без подготовки.
- Снимок модели: `slPrint(sys, 'x.pdf')` (FontSize 16) → `python scripts/crop_pdf.py x.pdf` → PNG 300 dpi.
  Если на модели Display — перед печатью прогнать её с нужными значениями в базовой рабочей области.

## Графики — только из Simulink, оформленные для отчёта
Требования и порядок вызовов — `references/graphs.md`. Коротко:
1. Каждый прогон `sim(in)` записывает сигналы журнала в Simulation Data Inspector; ID прогона —
   `ids = Simulink.sdi.getAllRunIDs; ids(end)`. В начале: `Simulink.sdi.clear; setAutoArchiveMode(false)`.
2. `sdiFigure(series, nRows, W, H)` — снимок SDI (нужные сигналы нужных прогонов на общих осях) в фигуру MATLAB;
   каждая линия сверяется с данными сигнала. Scope R2025b веб-окно и в фигуру программно не выгружается.
3. `prepFig` → стиль кривых → `niceY` → `putLegend` → `crossAxes` → дорисовки → `commaFig` → `legendOffAxis` → `exportgraphics`.
   Оси жирные через ноль, стрелки на концах, подписи у стрелок, числа по краям сетки, запятые.
4. XY-графики (параметр от параметра): считает модель (Clock как аргумент, Fcn, Stop Simulation), рисуем
   `plot` по её `logsout`, оформляем тем же `crossAxes`.
5. **Каждый PNG открыть и проверить глазами** (чек-лист в graphs.md): особенно дорисованные маркеры, размерные
   и выносные линии, подписи — они ошибались чаще всего.

## Инструменты (`scripts/`)
| Файл | Назначение |
|---|---|
| `mlrun.py` | запуск `matlab -batch` из любой оболочки, `--info` |
| `crop_pdf.py` | PDF снимка модели → обрезанный PNG |
| `matlab/slPort.m`, `slWire.m`, `slNewSubsystem.m`, `slLog.m`, `slPrint.m` | построение и печать модели |
| `matlab/sdiFigure.m` | снимок Simulation Data Inspector → фигура, линии сверены с сигналами |
| `matlab/prepFig.m`, `niceY.m`, `putLegend.m`, `fitLegend.m`, `crossAxes.m`, `commaFig.m`, `legendOffAxis.m`, `dimArrow.m` | оформление графика |
Пример целиком — `examples/demo_loop.m` (модель контура, два прогона, график из SDI, снимок модели):
`python scripts/mlrun.py --cd examples "demo_loop(pwd)"`.

Готовый большой пример — генератор отчёта ЛР1 по АТП (есть только локально у автора скилла, в репозитории его нет):
`matlab\build_model.m`, `lab1_sim.m`, `runcase.m`, `build_lines_model.m`, `lab1_lines.m`; инструкция
`Инструкция — отчёт ЛР1 АТП.md`. Если он есть у вас — путь уточните у пользователя.

## Пополнение скилла (обязательно в конце задачи)
- Новая грабля → `references/known-issues.md` (симптом → причина → что делать).
- Новый блок/приём построения → `references/model-api.md`; новое требование к графикам → `references/graphs.md`.
- Строка в `references/session-log.md`: дата, задача, что сделано, что нового.
- Правка общих `.m` из `scripts/matlab` → прогнать `examples/demo_loop.m` и посмотреть картинки.
