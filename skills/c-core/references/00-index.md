# Оглавление конспектов c-core

Источник: Kernighan & Ritchie, «The C Programming Language», 2-е изд. (ANSI C / C89).
Конспекты пересказывают книгу своими словами и дополняют её тем, что появилось в C99 и
важно для микроконтроллеров. Такие места помечены **(C99)** или **(МК)**.

| Файл | Глава K&R | О чём |
|---|---|---|
| `01-types-constants.md` | 1, 2.1–2.4, A.2, A.4, B.11 | типы и их размеры, `<stdint.h>`, константы и суффиксы, `char`, `enum`, `const` |
| `02-operators-expressions.md` | 2.5–2.12, A.6, A.7 | арифметика, **неявные преобразования**, логические операторы, `++`/`--`, `?:`, приоритеты, порядок вычисления |
| `03-control-flow.md` | 3, A.9 | `if`/`else`, `switch`, циклы, `break`/`continue`, `goto` для очистки |
| `04-functions-scope.md` | 4.1–4.10, A.10, A.11 | прототипы, `extern`/`static`, заголовки, области видимости, инициализация, рекурсия |
| `05-preprocessor.md` | 4.11, A.12 | `#include`, макросы и их ловушки, `#`/`##`, условная компиляция, include guard |
| `06-pointers-arrays.md` | 5.1–5.4, 5.7–5.9, A.7.7 | указатели, связь с массивами, адресная арифметика, многомерные массивы |
| `07-strings.md` | 1.9, 5.5, 7.8, B.2, B.3 | строки, `'\0'`, `<string.h>`, `<ctype.h>`, безопасное копирование |
| `08-function-pointers-declarations.md` | 5.6, 5.10–5.12, 6.7 | массивы указателей, указатели на функции, чтение сложных объявлений, `typedef` |
| `09-structs-unions-bitfields.md` | 6, A.8.3 | структуры, выравнивание, объединения, битовые поля |
| `10-bit-operations.md` | 2.9, 6.9 | маски, set/clear/toggle, извлечение полей, сдвиги |
| `11-stdlib-io.md` | 7, 8, B | `printf`/`scanf`, файлы, `malloc`/`free`, `<stdlib.h>`, `<assert.h>`, что годится для МК |
| `12-style.md` | всё | стиль из K&R и его дополнения |
| `undefined-behavior.md` | A, B + стандарт C99 | **сводка UB, unspecified и implementation-defined поведения** с упором на МК |

Порядок чтения при ревью кода: `undefined-behavior.md`, затем `02`, `06`, `10`.
