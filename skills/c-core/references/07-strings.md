# 07. Строки

## Представление
Строка в C — массив `char`, который заканчивается нулевым символом `'\0'`. Длина нигде не хранится:
`strlen` считает символы до `'\0'`, это O(n). Под строку длиной n нужен буфер n+1.

- `char a[] = "text";` — **массив** из 5 байт, его можно менять.
- `char *p = "text";` — **указатель** на строковый литерал. Изменять литерал — UB: на МК он может
  лежать во flash. **Правило:** пиши `const char *p = "text";`.
- Соседние литералы склеиваются при компиляции: `"abc" "def"` == `"abcdef"`.
- `'x'` — это число (код символа), `"x"` — массив из двух байт.

**Ловушка:** `p = "new";` меняет только указатель. `a = "new";` — ошибка: массиву присваивать нельзя.
Копировать содержимое нужно функциями.

## Функции `<string.h>` и их подводные камни
| Функция | Что делает | Ловушка |
|---|---|---|
| `strlen(s)` | длина без `'\0'`, тип `size_t` | UB, если `'\0'` нет. `strlen(s) - 1` при пустой строке — огромное число |
| `strcpy(d, s)` | копирует вместе с `'\0'` | не знает размера `d`, это переполнение буфера |
| `strncpy(d, s, n)` | копирует не больше n | **не ставит `'\0'`**, если `strlen(s) >= n`; при коротком `s` добивает нулями до n (медленно) |
| `strcat(d, s)` | дописывает в конец | не знает размера `d` |
| `strncat(d, s, n)` | дописывает не больше n символов **плюс `'\0'`** | n — это не размер буфера `d`, а остаток |
| `strcmp(a, b)` | <0, 0, >0 | возвращает не только -1/0/1. Сравнивай с 0, а не с 1 |
| `strchr`/`strrchr`/`strstr` | поиск, возвращают указатель или `NULL` | проверяй `NULL` |
| `strtok(s, delim)` | разбивает на токены, **портит `s`** | хранит внутреннее состояние, не реентерабельна, нельзя вызывать из ISR и из двух мест одновременно |
| `memcpy(d, s, n)` | копирует n байт | UB при перекрытии, тогда нужен `memmove` |
| `memset(d, c, n)` | заполняет байтом | заполняет **байтами**: `memset(arr, 1, sizeof arr)` для `int` даст 0x01010101 |
| `memcmp` | сравнивает байты | структуры с padding сравнивать так нельзя |

**Правило безопасного копирования:** всегда знай размер буфера назначения и передавай его.
Самый простой надёжный способ **(C99)** — `snprintf`, он всегда ставит `'\0'`, если размер > 0:
```c
char name[16];
snprintf(name, sizeof name, "%s", src);            /* truncates safely */

int n = snprintf(line, sizeof line, "T=%d.%d", t / 10, t % 10);
if (n < 0 || (size_t)n >= sizeof line) { /* truncated or error */ }
```
Своя простая функция без неожиданностей:
```c
/* Copies at most size-1 chars and always terminates. Returns source length. */
size_t str_copy(char *dst, size_t size, const char *src)
{
    size_t i = 0;
    if (size > 0) {
        for (; i + 1 < size && src[i] != '\0'; i++) {
            dst[i] = src[i];
        }
        dst[i] = '\0';
    }
    while (src[i] != '\0') {
        i++;
    }
    return i;
}
```

## Чтение строк
- `gets` **никогда**: она не знает размера буфера. В C11 её удалили.
- `fgets(buf, size, fp)` читает не больше size-1 символов, **оставляет `'\n'`** и ставит `'\0'`.
  Проверяй `NULL`. Отрезать перевод строки: `buf[strcspn(buf, "\r\n")] = '\0';`.
- (МК) Для UART своя функция читает байты в буфер до `'\n'` и всегда проверяет границу.
  См. пример командного протокола в скилле `esp8266-pio`.

## Преобразования число ↔ строка
- `atoi`/`atof` не сообщают об ошибках: `"abc"` даёт 0. **Правило:** используй `strtol`/`strtoul`
  с `endptr` и `errno`:
```c
#include <errno.h>
#include <stdlib.h>

int parse_u16(const char *s, uint16_t *out)
{
    char *end;
    unsigned long v;
    errno = 0;
    v = strtoul(s, &end, 10);
    if (end == s || *end != '\0' || errno == ERANGE || v > 0xFFFFu) {
        return -1;
    }
    *out = (uint16_t)v;
    return 0;
}
```
**Ловушка:** `strtoul("-1")` вернёт `ULONG_MAX` без ошибки, минус считается допустимым. Если отрицательные числа
недопустимы, проверяй первый символ сам.
- Число в строку: `snprintf`. В K&R функция `itoa` написана вручную, в стандартной библиотеке её нет.
  Её версия ломается на `INT_MIN`, потому что `-INT_MIN` — переполнение.

## `<ctype.h>`
`isdigit`, `isalpha`, `isalnum`, `isspace`, `isupper`, `islower`, `isxdigit`, `isprint`, `toupper`, `tolower`.
Не зависят от кодировки, лучше ручных сравнений `c >= 'a'`. Только цифры `'0'..'9'` гарантированно идут подряд,
поэтому `c - '0'` переносимо.

**Ловушка (UB):** аргумент должен быть `EOF` или значением `unsigned char`. Если `char` знаковый,
русская буква или байт 0xFF отрицательны, и это UB. **Правило:** `isdigit((unsigned char)c)`.
