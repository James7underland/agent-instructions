# 10. Битовые операции

Операторы: `&` (И), `|` (ИЛИ), `^` (исключающее ИЛИ), `~` (инверсия), `<<`, `>>`. Работают только с целыми.

## Главные правила
1. **Биты — только в беззнаковых типах** (`uint8_t`, `uint16_t`, `uint32_t`, `unsigned`).
   Сдвиг знакового числа вправо зависит от реализации, влево — легко даёт UB.
2. **Литерал маски — беззнаковый и достаточно широкий:** `1u << n`, `1UL << n`, `UINT32_C(1) << n`.
   `1 << 31` при 32-битном `int` — это UB: единица попадает в знаковый бит. `1 << 15` при 16-битном `int` (AVR)
   тоже UB.
3. Сдвиг на число бит `>=` ширины типа (после продвижения) или на отрицательное число — **UB**.
   `x << 32` для `uint32_t` не даёт 0. На многих процессорах сдвиг берётся по модулю 32, то есть это `x`.
4. Операнды `uint8_t` и `uint16_t` перед операцией превращаются в `int`. Результат `~` и `<<` приводи
   обратно к нужному типу явно.
5. Битовые операторы **младше сравнений**: `(reg & MASK) == 0`, скобки обязательны.
6. Не путай `&` с `&&` и `|` с `||`: если `x = 1`, а `y = 2`, то `x & y == 0`, но `x && y == 1`.

## Идиомы
```c
#include <stdint.h>

#define BIT_U32(n)          (1UL << (n))   /* not BIT(): ESP8266 SDK already defines BIT */

#define BIT_SET(reg, n)     ((reg) |=  BIT_U32(n))
#define BIT_CLEAR(reg, n)   ((reg) &= ~BIT_U32(n))
#define BIT_TOGGLE(reg, n)  ((reg) ^=  BIT_U32(n))
#define BIT_READ(reg, n)    (((reg) >> (n)) & 1UL)

/* Mask of n low bits: works for n in 0..31 without UB. */
#define MASK_LOW(n)         ((n) >= 32u ? 0xFFFFFFFFUL : (BIT_U32(n) - 1UL))

/* Extract a field of 'width' bits starting at bit 'pos' (bit 0 = LSB). */
static inline uint32_t field_get(uint32_t x, unsigned pos, unsigned width)
{
    return (x >> pos) & MASK_LOW(width);
}

/* Replace the field with 'val', leaving other bits unchanged. */
static inline uint32_t field_set(uint32_t x, unsigned pos, unsigned width, uint32_t val)
{
    uint32_t m = MASK_LOW(width) << pos;
    return (x & ~m) | ((val << pos) & m);
}
```
В K&R пример `getbits` строит маску как `~(~0 << n)`. Здесь `~0` — знаковый `int` -1, а сдвиг
отрицательного значения влево в C99 — UB. На практике это работает, но правильнее `~(~0u << n)` при `n < 32`.

Другие полезные приёмы:
- `x & (x - 1)` сбрасывает младшую единицу. Отсюда быстрый подсчёт единиц и проверка «степень двойки»:
  `x && !(x & (x - 1))`.
- `x & -x` (для беззнакового `x`) выделяет младшую единицу.
- Остаток по степени двойки: `x & (N - 1)` вместо `x % N`, **только** если `N` — степень двойки и `x` беззнаковый.
  Так работает кольцевой буфер.
- `x & ~077` обнуляет младшие 6 бит **независимо от ширины** `x`. `x & 0177700` так не умеет.
- Проверка «оба бита сброшены»: `(flags & (A | B)) == 0`. «Хотя бы один установлен»: `(flags & (A | B)) != 0`.
  «Оба установлены»: `(flags & (A | B)) == (A | B)`.

## Имена макросов
Короткие «очевидные» имена (`BIT`, `REG_SET_BIT`, `MIN`, `MAX`, `SET`) уже заняты в SDK производителей.
Например, в ESP8266 SDK (`c_types.h`) есть `BIT(nr)` и `REG_SET_BIT`, и компилятор выдаст «redefined».
**Правило:** у макросов модуля должен быть префикс (`BIT_U32`, `RA_SET_BIT`), проверяй при сборке под целевую платформу.

## Маски: `#define` или `enum`
Маски — степени двойки: `enum { F_READY = 1u << 0, F_ERROR = 1u << 1 };`. Значения `enum` имеют тип `int`,
поэтому бит 31 так задать нельзя. Для 32-битных регистров бери `#define ... (1UL << 31)`.

## Порядок байт (endianness)
ESP8266, AVR, ARM Cortex-M и x86 работают в little-endian: младший байт лежит по младшему адресу.
Сетевые протоколы и многие датчики используют big-endian. **Правило:** порядок байт не должен зависеть
от платформы, собирай значения сдвигами:
```c
uint16_t be16(const uint8_t *p) { return (uint16_t)(((uint16_t)p[0] << 8) | p[1]); }
void put_be16(uint8_t *p, uint16_t v) { p[0] = (uint8_t)(v >> 8); p[1] = (uint8_t)v; }
```

## Ловушки (МК)
- **Чтение-модификация-запись не атомарна.** `PORT |= BIT_U32(3);` компилируется в три действия: чтение, ИЛИ, запись.
  Если прерывание в промежутке меняет тот же регистр или переменную, его изменение потеряется.
  Помогают регистры SET/CLR («запись 1 устанавливает/сбрасывает бит») или критическая секция. См. `embedded-c`.
- **Регистры с W1C-флагами** (Write-1-to-Clear): `REG |= FLAG_A;` сбросит **все** установленные флаги,
  потому что они читаются как 1 и записываются обратно как 1. Пиши просто `REG = FLAG_A;`.
- **`~` на узком типе:** `uint8_t m = 0x01; reg8 &= ~m;` сработает, потому что лишние биты отрежутся при
  присваивании. Но `uint8_t v = 0xFE; if (~v == 0x01)` не сработает: `~v` — это `int` `0xFFFFFF01`.
  Нужно `(uint8_t)~v == 0x01`.
