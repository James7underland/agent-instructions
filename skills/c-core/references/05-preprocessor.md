# 05. Препроцессор и заголовки

Препроцессор работает до компиляции и обрабатывает текст как последовательность токенов.
Порядок фаз такой: склейка строк по `\` в конце строки → разбиение на токены, комментарии заменяются пробелом →
директивы и макросы → склейка соседних строковых литералов.

## #include
- `#include <file.h>` ищет в системных путях. `#include "file.h"` сначала ищет рядом с исходником,
  потом в системных путях.
- Подключение — это текстовая вставка. Если заголовок изменился, все зависимые `.c` пересобираются.

## Include guard (обязательно в каждом `.h`)
```c
#ifndef UART_DRV_H
#define UART_DRV_H
/* ... declarations ... */
#endif /* UART_DRV_H */
```
Имя guard-макроса делай уникальным: модуль плюс `_H`. Имена на `_` и заглавную букву зарезервированы.
Вариант `#pragma once` поддерживают GCC и Clang, но он не стандартный.

## Макросы-константы
`#define NAME текст` — простая подстановка до конца файла. Замена не происходит внутри строк
и в частях других имён. Точку с запятой в конце не ставят.

**Правило:** для чисел предпочитай `enum` или `static const`. Если нужен `#define`, заключай значение в скобки
и указывай суффикс типа: `#define BUF_SIZE (64u)`, `#define TICK_HZ (1000UL)`.

**Ловушка:** `#define N 10;` — точка с запятой попадёт в каждое выражение: `int a[N];` превратится в `int a[10;];`.
**Ловушка:** `#define SUM a + b`, а потом `2 * SUM` раскроется в `2 * a + b`.

## Макросы с параметрами
`#define MAX(A, B) ((A) > (B) ? (A) : (B))`. Между именем макроса и `(` не должно быть пробела.

**Правила:**
1. Каждый параметр оборачивай в скобки, всё тело — тоже.
2. Если макрос вычисляет параметр больше одного раза, не передавай выражения с побочными эффектами:
   `MAX(i++, j++)` увеличит одно из значений дважды. Лучше `static inline`-функция **(C99)**: у неё есть
   проверка типов и нет двойного вычисления.
3. Макрос из нескольких операторов оборачивай в `do { ... } while (0)`. Тогда он безопасен в `if`/`else`.

```c
#define SQUARE_BAD(x)  x * x                 /* SQUARE_BAD(a+1) -> a+1*a+1 */
#define SQUARE(x)      ((x) * (x))           /* still evaluates x twice */

#define SWAP_U8(a, b)  do { uint8_t t_ = (a); (a) = (b); (b) = t_; } while (0)

static inline uint32_t min_u32(uint32_t a, uint32_t b) { return a < b ? a : b; }
```

**Ловушка:** многострочный макрос без `do { } while (0)`:
```c
#define RESET_ALL() a = 0; b = 0
if (x) RESET_ALL();     /* b = 0 runs always */
```

## Операторы `#` и `##`
- `#param` превращает аргумент в строковый литерал: `#define DBG(e) printf(#e " = %d\n", (e))`.
- `a ## b` склеивает токены: `REG(PORT, A)` → `PORTA`. Аргументы рядом с `#` и `##` **не раскрываются**.
  Чтобы сначала раскрыть их, нужен вспомогательный уровень макросов:
```c
#define CAT_(a, b)  a ## b
#define CAT(a, b)   CAT_(a, b)      /* expands a and b first */
#define STR_(x)     #x
#define STR(x)      STR_(x)         /* STR(__LINE__) -> "42" */
```

## Условная компиляция
`#if`, `#elif`, `#else`, `#endif`, `#ifdef`, `#ifndef`, `defined(NAME)`.
В `#if` допустимы только целые константные выражения: **нельзя** `sizeof`, приведения типов и константы `enum`.
Неизвестные имена в `#if` тихо заменяются на 0. Опечатка в имени макроса молча отключит код.
Флаг `-Wundef` предупреждает об этом.

```c
#if defined(ARDUINO_ARCH_ESP8266)
#  define LED_PIN 2
#elif defined(__AVR__)
#  define LED_PIN 13
#else
#  error "Unsupported target"
#endif
```

**Правило:** `#error` ставь для недопустимых конфигураций, чтобы сборка падала сразу, а не работала неправильно.
**(C11)** Проверку во время компиляции даёт `_Static_assert(sizeof(frame_t) == 8, "frame layout");`.
В C99 её заменяет трюк с массивом отрицательного размера.

## Предопределённые имена
`__FILE__`, `__LINE__`, `__DATE__`, `__TIME__`, `__STDC__`, **(C99)** `__STDC_VERSION__`, `__func__`
(это переменная, а не макрос). Полезны в логах и `assert`.

## Прочее
- `#undef NAME` отменяет определение.
- `#pragma` зависит от компилятора. Незнакомые прагмы игнорируются.
- Триграфы вроде `??/` заменяются **до всего остального**. Строка `"??/"` превратится в `"\"`.
  В GCC триграфы по умолчанию выключены, но с флагом `-std=c99` **включены**. `-Wtrigraphs` предупреждает о них.
