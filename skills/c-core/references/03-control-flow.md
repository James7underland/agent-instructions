# 03. Управляющие конструкции

## Операторы и блоки
`;` завершает оператор. `{ }` объединяет несколько операторов в один. После `}` точка с запятой не нужна,
кроме `struct`, `union` и `enum`, где она обязательна.

## if / else
`else` относится к **ближайшему** `if` без `else`. Отступы компилятор не читает.

**Ловушка (dangling else):**
```c
if (n > 0)
    for (i = 0; i < n; i++)
        if (s[i] > 0)
            return i;
else                     /* belongs to the inner if, not to "n > 0" */
    report_error();
```
**Правило:** всегда ставь фигурные скобки у `if`, `else`, `for`, `while`, `do`, даже вокруг одной строки.
Так ломается меньше, когда потом добавляешь вторую строку.

**Ловушка:** лишняя `;` после условия: `if (flag); do_it();` — `do_it` выполнится всегда.
То же с `for (...);` и `while (...);`. Пустое тело пиши явно: `{ }` или `;` на отдельной строке с комментарием.

**Правило:** цепочку `else if` заканчивай `else`, даже если там только обработка «невозможного» случая.

## switch
Сравнивает целое выражение с константами `case`. Метки — это просто точки входа:
без `break` выполнение **проваливается** в следующий `case`.

**Правило:**
- каждый `case` заканчивай `break`, `return` или явным комментарием `/* fall through */`;
- всегда пиши `default:`, даже если в нём только сообщение об ошибке;
- `break` ставь и в последней ветке, это защита на будущее;
- в `switch` по `enum` включай `-Wswitch-enum`/`-Wswitch`, чтобы компилятор напоминал о новых значениях.

**Ловушка:** переменную, объявленную внутри `case` без своего блока, другой `case` может перепрыгнуть
без инициализации. Нужна локальная переменная — оборачивай ветку в `{ }`.

```c
switch (state) {
case ST_IDLE:
    if (button_pressed()) {
        state = ST_RUN;
    }
    break;
case ST_RUN: {
    uint16_t t = read_timer();   /* own block for local variable */
    if (t > LIMIT) {
        state = ST_IDLE;
    }
    break;
}
default:
    state = ST_IDLE;             /* recover from corrupted state */
    break;
}
```

## Циклы
- `while (cond)` и `for (init; cond; step)` проверяют условие **до** тела. При пустых входных данных тело
  не выполняется ни разу — это правильное граничное поведение.
- `for (;;)` — бесконечный цикл, так пишется главный цикл прошивки.
- `do { } while (cond);` выполняется минимум один раз. Нужен редко, например чтобы вывести хотя бы одну цифру числа.
  Фигурные скобки ставь всегда, чтобы `while` не приняли за начало нового цикла.

**Ловушка:** беззнаковый счётчик в обратном цикле: `for (unsigned i = n - 1; i >= 0; i--)` — бесконечный цикл,
потому что `i >= 0` всегда истинно. Правильно так: `for (size_t i = n; i-- > 0; )`.

**Ловушка:** при `n == 0` выражение `n - 1` для `size_t` даёт огромное число. Проверяй пустые входные данные.

**Ловушка:** `for (uint8_t i = 0; i < 300; i++)` — бесконечный цикл: `i` не может достичь 300.
Тип счётчика должен вмещать границу.

**Правило:** в `for` клади только управление циклом. Не прячь в заголовок посторонние вычисления.

## break / continue
`break` выходит из ближайшего цикла **или** `switch`. `continue` переходит к следующей итерации
ближайшего цикла, в `for` — к шагу. Внутри `switch`, который стоит в цикле, `continue` относится к циклу.

**Ловушка:** `break` внутри `switch` внутри цикла выходит только из `switch`, а не из цикла.

## goto
Почти всегда без него можно обойтись. Два оправданных случая:
выйти из нескольких вложенных циклов и собрать очистку ресурсов в одном месте в конце функции.

```c
int init_all(void)
{
    if (uart_init() != 0) goto fail_uart;
    if (spi_init()  != 0) goto fail_spi;
    return 0;

fail_spi:
    uart_deinit();
fail_uart:
    return -1;
}
```

**Ловушка:** переход `goto` внутрь блока пропускает инициализацию его автоматических переменных.
Прыгать можно только вперёд и наружу.
