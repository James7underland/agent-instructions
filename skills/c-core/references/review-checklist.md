# Чек-лист ревью кода на C

Для каждого пункта: ✅ / ❌ (файл:строка, что не так) / —. Ссылки ведут на конспекты с объяснением.
Для прошивок дополнительно пройди `embedded-c/references/review-checklist.md`.

## Сборка
- [ ] `-std=c99 -Wall -Wextra -Wpedantic` без предупреждений. Желательно `-Wconversion -Wshadow -Wstrict-prototypes`.
- [ ] Проверено и с `-O0`, и с `-O2` (UB часто проявляется только с оптимизацией).

## Типы и числа (`01`, `02`, `undefined-behavior.md`)
- [ ] Для данных, протоколов и регистров — типы фиксированной ширины (`uint8_t`...). Нет предположений о размере `int`/`long`.
- [ ] Нет смешения знаковых и беззнаковых в сравнениях и арифметике (`-Wsign-compare`).
- [ ] Умножение и сложение, которые могут выйти за диапазон, выполняются в типе нужной ширины **до** операции (`(uint32_t)a * b`).
- [ ] Нет знакового переполнения, деления на 0, `INT_MIN / -1`, `abs(INT_MIN)`.
- [ ] Результаты `~` и `<<` на узких типах приведены обратно к нужному типу.
- [ ] Литералы с суффиксами (`UL`, `u`, `f`), нет восьмеричных «для выравнивания» (`010`).
- [ ] `float` не сравнивается через `==`. Константы `float` — с суффиксом `f`.
- [ ] Преобразование float → целое не выходит за диапазон.

## Выражения (`02`)
- [ ] Не больше одного побочного эффекта на переменную в выражении. Нет зависимости от порядка вычисления аргументов.
- [ ] Скобки вокруг `& | ^ << >>` в сравнениях и арифметике. Нет `a < b < c`, нет `if (x = y)` без двойных скобок.
- [ ] `*p++` и `(*p)++` использованы по назначению.

## Управление (`03`)
- [ ] Скобки у всех `if/else/for/while`. Нет лишней `;` после условия.
- [ ] В каждом `switch` есть `default`, у каждого `case` — `break`/`return` или комментарий `fall through`.
- [ ] Счётчики циклов нужного типа (нет `uint8_t i < 300`), обратные циклы на беззнаковых корректны.
- [ ] Граничные случаи: пустой ввод, 0 элементов, один элемент, максимум.

## Функции и модули (`04`, `05`)
- [ ] Прототипы у всех функций, `(void)` для функций без параметров. Всё внутреннее — `static`.
- [ ] `.h`: include guard, самодостаточен, только `extern`-объявления (нет определений переменных). `.c` включает свой `.h` первым.
- [ ] Все пути функции возвращают значение. Возвращаемые ошибки проверяются.
- [ ] Макросы: скобки вокруг параметров и тела, `do { } while (0)`, нет аргументов с побочными эффектами. Лучше `static inline`.
- [ ] Нет неограниченной рекурсии и больших локальных массивов (стек МК).

## Указатели и массивы (`06`, `08`)
- [ ] Каждый доступ к массиву в пределах границ. Длина передаётся вместе с указателем (`size_t len`).
- [ ] `sizeof` не применяется к параметру-«массиву» (это указатель).
- [ ] Указатели проверяются на `NULL`, инициализируются, после `free` зануляются. Нет возврата адреса локальной переменной.
- [ ] Нет приведения `uint8_t *` к более широкому типу для чтения (выравнивание и strict aliasing). Многобайтовые значения собираются сдвигами или через `memcpy`.
- [ ] Указатель на функцию вызывается с точно совпадающим типом. Перед вызовом проверяется на `NULL`.
- [ ] `const` у указателей, по которым только читают.

## Строки (`07`)
- [ ] Нет `gets`, `strcpy`/`strcat`/`sprintf` в буфер неизвестного размера. Используется `snprintf` или копирование с размером.
- [ ] `strncpy` не используется как «безопасный» (или `'\0'` ставится вручную).
- [ ] Строковые литералы — через `const char *`, не изменяются.
- [ ] `atoi/atof` заменены на `strtol/strtoul/strtod` с проверкой `endptr` и `errno`.
- [ ] Аргументы `isxxx()/toxxx()` приведены к `unsigned char`.
- [ ] Формат `printf/scanf` соответствует типам (`PRIu32`, `%zu`, `%lu` с приведением). `printf(s)` → `printf("%s", s)`.

## Структуры и биты (`09`, `10`)
- [ ] Структуры не сравниваются `memcmp` и не передаются «как есть» по каналу связи или во flash (padding, порядок байт).
- [ ] Битовые поля не используются для регистров и внешних форматов. `int`-битовые поля объявлены `unsigned`.
- [ ] Маски беззнаковые и достаточной ширины (`1UL << n`). Сдвиг меньше ширины типа.

## Библиотека и память (`11`)
- [ ] Результаты `malloc`, `fopen`, `fgets`, `scanf` проверяются. `realloc` — через временный указатель.
- [ ] Нет утечек и двойного `free`. Освобождение списков через сохранённый `next`.
- [ ] `assert` без побочных эффектов, используется для инвариантов, а не для входных данных.
- [ ] На МК: нет `malloc` после старта, нет `printf` с `%f`, нет `String` (Arduino) в долгоживущем коде.

## Стиль (`12`)
- [ ] Нет магических чисел. Имена говорят о смысле, у публичных функций модуля есть префикс.
- [ ] Комментарии объясняют «почему». У публичного API описаны параметры, возврат, ограничения.
