# Известные ловушки и найденные ошибки (c-core)

Пополняется после каждой задачи: что сломалось, почему, как правильно.

## Источник (PDF-копия K&R в папке «Язык C»)
- Это HTML-версия книги (freebooks.by.ru), распечатанная в PDF, и в её коде есть **опечатки**, которых нет в
  бумажной книге. Код из этой копии нельзя брать дословно:
  - `binsearch` (гл. 3.3): `high = mid + 1` вместо `mid - 1` — бесконечный цикл;
  - подсчёт слов (гл. 1.5.4) и пропуск пробелов (гл. 3.5): `c = '\t'` вместо `c == '\t'`;
  - `strlen` (гл. 2.3): переменная `i` не инициализирована;
  - `strcpy` с указателями (гл. 5.5): лишняя переменная `i`, в `getint` `for (...; isdigit(c), c = getch())` вместо `;`;
  - в `swap(void *v[], int i, int j;)` лишняя `;`, `struct maxpt = {...}` без имени типа, `putcher` и т. п.
- `getbits` (гл. 2.9) строит маску `~(~0 << n)`: `~0` — это знаковый `-1`, сдвиг отрицательного влево
  в C99 — UB. Правильно `~(~0u << n)` при `n < 32`.
- В гл. 5.11 `strcmp` приводится к `int (*)(void *, void *)` для своего `qsort`. Вызов через несовместимый
  тип указателя на функцию — UB. Пиши обёртку с правильной сигнатурой.
- Книга описывает C89: округление деления отрицательных «зависит от машины» (в C99 — к нулю), `gets`
  ещё существует (в C11 удалён), нет `<stdint.h>`, `snprintf`, `//`, `bool`, объявлений в `for`.

## Проверено компилятором (GCC 16.1, MinGW-w64 UCRT)
- `-Wextra` ловит `~u8 == 0x01` («comparison of promoted bitwise complement of an unsigned value with
  constant») и `char c = 0xF0; c == 0xF0` («comparison is always false due to limited range»). Не отключай `-Wextra`.
- В режиме `-std=c99` **триграфы включены**: `"??/"` превращается в `"\"`, и строка ломается.
  В `-std=gnu99` выключены. Не пиши `??` в строках подряд.
- На MinGW (Windows) `sizeof(long) == 4`, на Linux x86-64 — 8. `long` не годится для 64-битных значений,
  используй `int64_t`/`long long`.
- `char` на x86 знаковый.

## Названия
- Суффикс `_t` зарезервирован POSIX. Конфликт реальный: тип регулятора `pid_t` совпадает с POSIX `pid_t`
  из `<sys/types.h>`. Давай уникальные имена с префиксом модуля (`pid_ctrl_t`).
