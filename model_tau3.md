# Моделирование в программном комплексе ТАУ-3 (`model_tau3.md`)

> Модуль прикладного слоя для автоматизации расчетов и снятия характеристик систем управления в учебном пакете «ТАУ-3» (24 Win32-программы: LINSYS, CONTROL, MVACS2, KALMAN, OPTIM и др.).
> Путеводитель по библиотеке — [`README.md`](README.md).
> Полная рабочая реализация и инструментарий скилла — [`skills/tau3/SKILL.md`](skills/tau3/SKILL.md).

---

## 1. Назначение и сфера применения

Модуль подключается при решении задач:
- Расчет и исследование линейных и нелинейных систем автоматического управления в учебном пакете «ТАУ-3» (разработка Лозинского/Берщанского);
- Программное управление 24 прикладными программами комплекса через сообщения Win32 API (`scripts/tau.py`) без захвата мыши и фокуса пользователя;
- Автоматизированный ввод передаточных функций, матриц пространства состояний и параметров звеньев;
- Чтение, парсинг и формирование файлов вариантов (`.VRT`) напрямую скриптами (`scripts/vrt.py`);
- Построение переходных и весовых функций, ЛАЧХ/ЛФЧХ, годографов Найквиста, корневых годографов, таблиц Рауса и фазовых портретов со снятием снимков экранов (`.png`);
- Независимая верификация результатов расчетов на Python с использованием библиотеки NumPy (`scripts/check.py`).

---

## 2. Состав пакета программ ТАУ-3

Комплекс объединяет 24 специализированных модуля по направлениям ТАУ:
- **Линейные непрерывные системы:** LINSYS (базовый анализ), LINSYS2, LINSYS3 (многоконтурные схемы), CONTROL (структурные схемы), ASYMPT (асимптотические ЛАЧХ), CASCAD (каскадные схемы).
- **Дискретные и импульсные системы:** IMPULS (импульсные САУ), MVACS2 (многомерные дискретные системы).
- **Нелинейные системы и фазовое пространство:** NLINSYS (гармоническая линеаризация), PHASPL (фазовые портреты релейных систем).
- **Оптимизация и матричные методы:** OPTIM, OPTIM2 (параметрическая оптимизация), KALMAN (фильтр Калмана), ANACON, ANACON2, ANACON3 (модальное управление, LQR-регуляторы).
- **Идентификация и спектральный анализ:** IDENTF (идентификация передаточных функций), SPECTR (спектральные плотности), RTLZ (реализация звеньев), PRONI (метод Прони).

## 3. Инструментарий автоматизации

Скрипты взаимодействия сосредоточены в [`skills/tau3/scripts/`](skills/tau3/):

| Инструмент | Назначение |
|---|---|
| [`tau.py`](skills/tau3/scripts/tau.py) | Драйвер графического интерфейса Win32: запуск процессов, навигация по меню, заполнение таблиц, захват окон, закрытие |
| [`vrt.py`](skills/tau3/scripts/vrt.py) | Прямое чтение и генерация файлов вариантов `.VRT` для передаточных функций и структурных схем |
| [`check.py`](skills/tau3/scripts/check.py) | Независимый расчет передаточных функций, корней, переходных процессов, ЛАЧХ и критериев устойчивости (NumPy) |
| [`crawl.py`](skills/tau3/scripts/crawl.py) / `summarize.py` | Автоматический обход всех окон и пунктов меню для составления карты интерфейса |
| [`dfm.py`](skills/tau3/scripts/dfm.py) / `hlp.py` | Декомпиляторы форм Delphi и справочных файлов WinHelp (`.HLP`) |

### Правила безопасности:
1. Исходный эталонный каталог пакета `TAY_3` неприкосновенен; запуск программ производится строго из рабочей изолированной копии.
2. При наличии активной GUI-сессии пользователя повторный запуск той же программы не выполняется во избежание конфликта разделяемых VRT-файлов.
